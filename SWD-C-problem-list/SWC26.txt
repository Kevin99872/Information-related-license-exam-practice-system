電腦軟體設計丙級 練習題 SWC26  判斷字串是否全部由數字組成

難度：中等

== 題目 ==
輸入一行文字，判斷其是否全部由數字字元 (0-9) 組成，做為基本輸入格式驗證。

輸入說明：一行文字 (可能為空行)。
輸出說明：全部由數字組成輸出 Yes，否則 (含空字串) 輸出 No。

== 參考解法 (Python) ==
s = input()
print("Yes" if s.isdigit() else "No")

== 範例 1 輸入 ==
12345
== 範例 1 輸出 ==
Yes

== 範例 2 輸入 ==
12a45
== 範例 2 輸出 ==
No

== 範例 3 輸入 ==
-123
== 範例 3 輸出 ==
No
