電腦軟體設計丙級 練習題 SWC32  印出倒直角三角形星號圖案

難度：簡單

== 題目 ==
輸入正整數 n，印出由星號組成的倒直角三角形，第一行 n 個星號，之後每行遞減 1 個，最後一行 1 個星號。

輸入說明：一行一個正整數 n (1<=n<=30)。
輸出說明：n 行星號圖案。

== 參考解法 (Python) ==
n = int(input())
for i in range(n, 0, -1):
    print('*' * i)

== 範例 1 輸入 ==
4
== 範例 1 輸出 ==
****
***
**
*

== 範例 2 輸入 ==
2
== 範例 2 輸出 ==
**
*
