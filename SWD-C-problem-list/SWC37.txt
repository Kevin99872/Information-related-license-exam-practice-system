電腦軟體設計丙級 練習題 SWC37  計算圓面積與周長

難度：簡單

== 題目 ==
輸入圓的半徑 r，計算圓的面積與周長 (圓周率取 3.14159)。

輸入說明：一行一個數字，半徑 r。
輸出說明：一行，面積與周長，皆取到小數點後兩位，以空白分隔。

== 參考解法 (Python) ==
r = float(input())
pi = 3.14159
area = pi * r * r
circ = 2 * pi * r
print(f"{area:.2f} {circ:.2f}")

== 範例 1 輸入 ==
5
== 範例 1 輸出 ==
78.54 31.42

== 範例 2 輸入 ==
1
== 範例 2 輸出 ==
3.14 6.28
