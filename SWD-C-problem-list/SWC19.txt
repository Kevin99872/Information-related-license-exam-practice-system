電腦軟體設計丙級 練習題 SWC19  計算陣列中偶數的個數

難度：簡單

== 題目 ==
輸入 n 個整數，統計其中偶數的個數。

輸入說明：第一行一個整數 n；第二行 n 個整數。
輸出說明：偶數的個數。

== 參考解法 (Python) ==
n = int(input())
a = list(map(int, input().split()))
print(sum(1 for x in a if x % 2 == 0))

== 範例 1 輸入 ==
6
1 2 3 4 5 6
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
3
1 3 5
== 範例 2 輸出 ==
0
