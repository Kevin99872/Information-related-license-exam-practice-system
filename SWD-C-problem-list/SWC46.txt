電腦軟體設計丙級 練習題 SWC46  購物滿額折扣計算

難度：中等

== 題目 ==
輸入消費金額，依下列規則計算實際應付金額：金額達 2000 元 (含) 打 8 折；達 1000 元 (含) 但未滿 2000 元打 9 折；未滿 1000 元不打折。

輸入說明：一行一個整數，消費金額 amount。
輸出說明：實際應付金額 (無條件捨去小數，取整數)。

== 參考解法 (Python) ==
amount = int(input())
if amount >= 2000:
    pay = amount * 0.8
elif amount >= 1000:
    pay = amount * 0.9
else:
    pay = amount
print(int(pay))

== 範例 1 輸入 ==
2500
== 範例 1 輸出 ==
2000

== 範例 2 輸入 ==
1500
== 範例 2 輸出 ==
1350

== 範例 3 輸入 ==
500
== 範例 3 輸出 ==
500
