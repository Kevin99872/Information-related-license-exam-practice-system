電腦軟體設計丙級 練習題 SWC38  依年齡輸出所屬階段

難度：中等

== 題目 ==
輸入年齡，依下列規則輸出所屬階段：未滿 13 歲為 兒童；13 歲以上未滿 18 歲為 青少年；18 歲以上未滿 65 歲為 成人；65 歲以上為 老年。

輸入說明：一行一個整數，年齡 a (0<=a<=120)。
輸出說明：兒童、青少年、成人 或 老年。

== 參考解法 (Python) ==
a = int(input())
if a < 13:
    print("兒童")
elif a < 18:
    print("青少年")
elif a < 65:
    print("成人")
else:
    print("老年")

== 範例 1 輸入 ==
10
== 範例 1 輸出 ==
兒童

== 範例 2 輸入 ==
15
== 範例 2 輸出 ==
青少年

== 範例 3 輸入 ==
30
== 範例 3 輸出 ==
成人

== 範例 4 輸入 ==
70
== 範例 4 輸出 ==
老年
