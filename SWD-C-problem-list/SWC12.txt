電腦軟體設計丙級 練習題 SWC12  判斷倍數關係

難度：簡單

== 題目 ==
輸入兩個整數 n 與 m，判斷 n 是否為 m 的倍數。

輸入說明：一行兩個整數 n 與 m (m<>0)。
輸出說明：n 為 m 的倍數輸出 Yes，否則輸出 No。

== 參考解法 (Python) ==
n, m = map(int, input().split())
print("Yes" if n % m == 0 else "No")

== 範例 1 輸入 ==
15 5
== 範例 1 輸出 ==
Yes

== 範例 2 輸入 ==
14 5
== 範例 2 輸出 ==
No

== 範例 3 輸入 ==
0 7
== 範例 3 輸出 ==
Yes
