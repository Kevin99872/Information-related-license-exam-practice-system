電腦軟體設計丙級 練習題 SWC29  簡易密碼強度檢查

難度：困難

== 題目 ==
輸入一個密碼字串，依下列 4 項條件評估密碼強度：
(1) 長度至少 8 個字元；(2) 至少包含一個小寫字母；(3) 至少包含一個大寫字母；(4) 至少包含一個數字。
符合全部 4 項條件視為「強」；符合 2 或 3 項視為「中」；符合 0 或 1 項視為「弱」。

輸入說明：一行密碼字串 (不含空白)。
輸出說明：強、中 或 弱。

== 參考解法 (Python) ==
s = input()
c1 = len(s) >= 8
c2 = any(ch.islower() for ch in s)
c3 = any(ch.isupper() for ch in s)
c4 = any(ch.isdigit() for ch in s)
cnt = sum([c1, c2, c3, c4])
if cnt == 4:
    print("強")
elif cnt >= 2:
    print("中")
else:
    print("弱")

== 範例 1 輸入 ==
Abc12345
== 範例 1 輸出 ==
強

== 範例 2 輸入 ==
abc123
== 範例 2 輸出 ==
中

== 範例 3 輸入 ==
abcdefg
== 範例 3 輸出 ==
弱
