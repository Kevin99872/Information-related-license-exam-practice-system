電腦軟體設計丙級 練習題 SWC53  凱撒密碼位移加密

難度：困難

== 題目 ==
輸入一個只由小寫英文字母組成的字串，以及位移量 k，將字串中每個字母往後位移 k 個字母 (超過 z 則從 a 重新算起)，輸出加密後的字串。

輸入說明：第一行為只含小寫英文字母的字串；第二行為整數 k (0<=k<=25)。
輸出說明：加密後的字串。

== 參考解法 (Python) ==
s = input().strip()
k = int(input())
res = []
for ch in s:
    res.append(chr((ord(ch) - ord('a') + k) % 26 + ord('a')))
print(''.join(res))

== 範例 1 輸入 ==
abc
3
== 範例 1 輸出 ==
def

== 範例 2 輸入 ==
xyz
3
== 範例 2 輸出 ==
abc

== 範例 3 輸入 ==
hello
5
== 範例 3 輸出 ==
mjqqt
