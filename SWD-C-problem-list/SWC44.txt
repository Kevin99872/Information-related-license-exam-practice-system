電腦軟體設計丙級 練習題 SWC44  計算平均成績並轉換為等第

難度：中等

== 題目 ==
輸入 n 個學生的成績 (0-100 的整數)，計算平均分數 (四捨五入取整數) 並轉換為等第：
90 分以上為 A；80~89 為 B；70~79 為 C；60~69 為 D；60 分以下為 F。

輸入說明：第一行一個整數 n；第二行 n 個成績。
輸出說明：一行，平均分數 與 等第，以空白分隔。

== 參考解法 (Python) ==
n = int(input())
a = list(map(int, input().split()))
avg = round(sum(a) / n)
if avg >= 90:
    g = "A"
elif avg >= 80:
    g = "B"
elif avg >= 70:
    g = "C"
elif avg >= 60:
    g = "D"
else:
    g = "F"
print(avg, g)

== 範例 1 輸入 ==
3
90 80 70
== 範例 1 輸出 ==
80 B

== 範例 2 輸入 ==
4
100 100 50 50
== 範例 2 輸出 ==
75 C
