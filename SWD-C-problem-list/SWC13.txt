電腦軟體設計丙級 練習題 SWC13  列出1到n之間3的倍數

難度：簡單

== 題目 ==
輸入正整數 n，列出 1 到 n 之間所有 3 的倍數。

輸入說明：一行一個正整數 n。
輸出說明：1 到 n 之間 3 的倍數，由小到大以空白分隔；若無則輸出 none。

== 參考解法 (Python) ==
n = int(input())
res = [i for i in range(1, n + 1) if i % 3 == 0]
print(' '.join(map(str, res)) if res else "none")

== 範例 1 輸入 ==
10
== 範例 1 輸出 ==
3 6 9

== 範例 2 輸入 ==
2
== 範例 2 輸出 ==
none

== 範例 3 輸入 ==
15
== 範例 3 輸出 ==
3 6 9 12 15
