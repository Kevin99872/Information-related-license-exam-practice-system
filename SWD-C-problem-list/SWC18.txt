電腦軟體設計丙級 練習題 SWC18  計算陣列中正數、負數與零的個數

難度：中等

== 題目 ==
輸入 n 個整數，分別統計其中正數、負數與零的個數。

輸入說明：第一行一個整數 n；第二行 n 個整數。
輸出說明：一行，依序輸出 正數個數 負數個數 零的個數，以空白分隔。

== 參考解法 (Python) ==
n = int(input())
a = list(map(int, input().split()))
pos = sum(1 for x in a if x > 0)
neg = sum(1 for x in a if x < 0)
zero = sum(1 for x in a if x == 0)
print(pos, neg, zero)

== 範例 1 輸入 ==
5
1 -2 0 3 -4
== 範例 1 輸出 ==
2 2 1

== 範例 2 輸入 ==
4
0 0 5 -5
== 範例 2 輸出 ==
1 1 2
