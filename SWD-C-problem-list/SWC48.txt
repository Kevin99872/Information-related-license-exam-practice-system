電腦軟體設計丙級 練習題 SWC48  小數轉換為百分比格式輸出

難度：簡單

== 題目 ==
輸入一個 0 到 1 之間的小數，將其轉換為百分比格式輸出。

輸入說明：一行一個小數 x (0<=x<=1)。
輸出說明：百分比字串，取到小數點後一位，並在結尾加上 % 符號。

== 參考解法 (Python) ==
x = float(input())
print(f"{x * 100:.1f}%")

== 範例 1 輸入 ==
0.5
== 範例 1 輸出 ==
50.0%

== 範例 2 輸入 ==
0.256
== 範例 2 輸出 ==
25.6%

== 範例 3 輸入 ==
1
== 範例 3 輸出 ==
100.0%
