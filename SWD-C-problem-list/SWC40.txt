電腦軟體設計丙級 練習題 SWC40  計算平面上兩點的距離

難度：中等

== 題目 ==
輸入平面上兩點座標 (x1,y1) 與 (x2,y2)，計算兩點之間的距離。

輸入說明：一行四個數字 x1 y1 x2 y2，以空白分隔。
輸出說明：兩點距離，取到小數點後兩位。

== 參考解法 (Python) ==
x1, y1, x2, y2 = map(float, input().split())
d = ((x2 - x1) ** 2 + (y2 - y1) ** 2) ** 0.5
print(f"{d:.2f}")

== 範例 1 輸入 ==
0 0 3 4
== 範例 1 輸出 ==
5.00

== 範例 2 輸入 ==
0 0 1 1
== 範例 2 輸出 ==
1.41
