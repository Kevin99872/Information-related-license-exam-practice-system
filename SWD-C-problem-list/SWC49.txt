電腦軟體設計丙級 練習題 SWC49  總秒數轉換為時分秒格式

難度：中等

== 題目 ==
輸入一個非負整數代表總秒數，將其轉換為「時:分:秒」格式 (分與秒需補零至兩位數，時不補零)。

輸入說明：一行一個非負整數 s (0<=s<=359999)。
輸出說明：格式為 H:MM:SS 的時間字串。

== 參考解法 (Python) ==
s = int(input())
h = s // 3600
m = (s % 3600) // 60
sec = s % 60
print(f"{h}:{m:02d}:{sec:02d}")

== 範例 1 輸入 ==
3661
== 範例 1 輸出 ==
1:01:01

== 範例 2 輸入 ==
59
== 範例 2 輸出 ==
0:00:59

== 範例 3 輸入 ==
7325
== 範例 3 輸出 ==
2:02:05
