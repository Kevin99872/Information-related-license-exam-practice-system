電腦軟體設計丙級 練習題 SWC41  列出1到n之間所有質數

難度：困難

== 題目 ==
輸入正整數 n，列出 1 到 n 之間所有的質數 (以試除法判斷)。

輸入說明：一行一個正整數 n (2<=n<=1000)。
輸出說明：1 到 n 之間所有質數，由小到大以空白分隔。

== 參考解法 (Python) ==
n = int(input())
res = []
for i in range(2, n + 1):
    is_p = True
    for j in range(2, int(i ** 0.5) + 1):
        if i % j == 0:
            is_p = False
            break
    if is_p:
        res.append(i)
print(' '.join(map(str, res)))

== 範例 1 輸入 ==
20
== 範例 1 輸出 ==
2 3 5 7 11 13 17 19

== 範例 2 輸入 ==
2
== 範例 2 輸出 ==
2
