電腦軟體設計丙級 練習題 SWC35  BMI計算與分類

難度：中等

== 題目 ==
輸入體重 (公斤) 與身高 (公尺)，計算 BMI 值 (BMI = 體重 / 身高^2) 並依下表分類：
BMI < 18.5 為 過輕；18.5 <= BMI < 24 為 正常；24 <= BMI < 27 為 過重；BMI >= 27 為 肥胖。

輸入說明：一行兩個數字：體重 與 身高，以空白分隔。
輸出說明：一行，BMI 值 (取到小數點後兩位) 與分類，以空白分隔。

== 參考解法 (Python) ==
w, h = map(float, input().split())
bmi = w / (h * h)
if bmi < 18.5:
    cat = "過輕"
elif bmi < 24:
    cat = "正常"
elif bmi < 27:
    cat = "過重"
else:
    cat = "肥胖"
print(f"{bmi:.2f} {cat}")

== 範例 1 輸入 ==
70 1.75
== 範例 1 輸出 ==
22.86 正常

== 範例 2 輸入 ==
45 1.7
== 範例 2 輸出 ==
15.57 過輕

== 範例 3 輸入 ==
85 1.7
== 範例 3 輸出 ==
29.41 肥胖
