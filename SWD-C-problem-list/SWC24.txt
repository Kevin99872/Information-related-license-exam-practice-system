電腦軟體設計丙級 練習題 SWC24  計算字串中母音字母的個數

難度：簡單

== 題目 ==
輸入一行文字，計算其中母音字母 (a, e, i, o, u，不分大小寫) 的個數。

輸入說明：一行文字。
輸出說明：母音字母的個數。

== 參考解法 (Python) ==
s = input()
print(sum(1 for c in s if c.lower() in "aeiou"))

== 範例 1 輸入 ==
Hello World
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
xyz
== 範例 2 輸出 ==
0

== 範例 3 輸入 ==
Programming
== 範例 3 輸出 ==
3
