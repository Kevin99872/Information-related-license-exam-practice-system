電腦軟體設計丙級 練習題 SWC10  計算多位數字的位數和

難度：中等

== 題目 ==
輸入一個正整數 n，計算其各位數字的總和。

輸入說明：一行一個正整數 n (1<=n<=10^15)。
輸出說明：n 每一位數字的總和。

== 參考解法 (Python) ==
s = input().strip()
print(sum(int(ch) for ch in s if ch.isdigit()))

== 範例 1 輸入 ==
12345
== 範例 1 輸出 ==
15

== 範例 2 輸入 ==
9999
== 範例 2 輸出 ==
36

== 範例 3 輸入 ==
100
== 範例 3 輸出 ==
1
