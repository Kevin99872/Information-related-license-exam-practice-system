電腦軟體設計丙級 練習題 SWC36  攝氏轉華氏溫度

難度：簡單

== 題目 ==
輸入攝氏溫度，轉換為華氏溫度 (F = C * 9/5 + 32)。

輸入說明：一行一個數字，攝氏溫度 C。
輸出說明：華氏溫度，取到小數點後一位。

== 參考解法 (Python) ==
c = float(input())
f = c * 9 / 5 + 32
print(f"{f:.1f}")

== 範例 1 輸入 ==
0
== 範例 1 輸出 ==
32.0

== 範例 2 輸入 ==
100
== 範例 2 輸出 ==
212.0

== 範例 3 輸入 ==
37
== 範例 3 輸出 ==
98.6
