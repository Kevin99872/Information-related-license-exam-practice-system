電腦軟體設計丙級 練習題 SWC39  判斷三邊長是否可以構成三角形

難度：中等

== 題目 ==
輸入三個正整數作為三角形的三邊長，判斷是否能構成三角形 (任兩邊之和必須大於第三邊)。

輸入說明：一行三個正整數 a、b、c。
輸出說明：能構成三角形輸出 Yes，否則輸出 No。

== 參考解法 (Python) ==
a, b, c = map(int, input().split())
print("Yes" if a + b > c and a + c > b and b + c > a else "No")

== 範例 1 輸入 ==
3 4 5
== 範例 1 輸出 ==
Yes

== 範例 2 輸入 ==
1 2 3
== 範例 2 輸出 ==
No

== 範例 3 輸入 ==
5 5 5
== 範例 3 輸出 ==
Yes
