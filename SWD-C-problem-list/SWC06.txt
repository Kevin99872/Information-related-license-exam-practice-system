電腦軟體設計丙級 練習題 SWC06  計算1到n的偶數總和

難度：簡單

== 題目 ==
輸入正整數 n，計算 1 到 n 之間所有偶數的總和。

輸入說明：一行一個正整數 n (1<=n<=100000)。
輸出說明：1 到 n 之間偶數的總和。

== 參考解法 (Python) ==
n = int(input())
print(sum(i for i in range(1, n + 1) if i % 2 == 0))

== 範例 1 輸入 ==
10
== 範例 1 輸出 ==
30

== 範例 2 輸入 ==
6
== 範例 2 輸出 ==
12

== 範例 3 輸入 ==
1
== 範例 3 輸出 ==
0
