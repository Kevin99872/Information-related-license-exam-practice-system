電腦軟體設計丙級 練習題 SWC17  計算n個整數的總和與平均

難度：簡單

== 題目 ==
輸入 n 個整數，計算其總和與平均值 (平均取到小數點後兩位)。

輸入說明：第一行一個整數 n；第二行 n 個整數。
輸出說明：一行，依序輸出 總和 平均，以空白分隔。

== 參考解法 (Python) ==
n = int(input())
a = list(map(int, input().split()))
print(f"{sum(a)} {sum(a) / n:.2f}")

== 範例 1 輸入 ==
4
1 2 3 4
== 範例 1 輸出 ==
10 2.50

== 範例 2 輸入 ==
3
5 5 5
== 範例 2 輸出 ==
15 5.00
