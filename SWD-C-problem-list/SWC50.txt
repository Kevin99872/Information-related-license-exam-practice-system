電腦軟體設計丙級 練習題 SWC50  輸入月份輸出對應天數

難度：中等

== 題目 ==
輸入月份 (1-12)，輸出該月份的天數 (2 月固定以 28 天計算，不考慮閏年)。

輸入說明：一行一個整數，月份 m (1<=m<=12)。
輸出說明：該月份的天數。

== 參考解法 (Python) ==
m = int(input())
days = {1: 31, 2: 28, 3: 31, 4: 30, 5: 31, 6: 30,
        7: 31, 8: 31, 9: 30, 10: 31, 11: 30, 12: 31}
print(days[m])

== 範例 1 輸入 ==
2
== 範例 1 輸出 ==
28

== 範例 2 輸入 ==
4
== 範例 2 輸出 ==
30

== 範例 3 輸入 ==
1
== 範例 3 輸出 ==
31
