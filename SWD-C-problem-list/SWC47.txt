電腦軟體設計丙級 練習題 SWC47  ATM提款判斷

難度：中等

== 題目 ==
輸入帳戶餘額、提款金額與手續費，判斷是否能成功提款 (餘額須大於等於「提款金額+手續費」)。

輸入說明：一行三個整數 balance、amount 與 fee。
輸出說明：可成功提款則輸出「交易成功」與提款後的餘額 (以空白分隔)；否則輸出「餘額不足」。

== 參考解法 (Python) ==
balance, amount, fee = map(int, input().split())
if balance >= amount + fee:
    print(f"交易成功 {balance - amount - fee}")
else:
    print("餘額不足")

== 範例 1 輸入 ==
1000 500 10
== 範例 1 輸出 ==
交易成功 490

== 範例 2 輸入 ==
1000 990 20
== 範例 2 輸出 ==
餘額不足
