電腦軟體設計丙級 練習題 SWC02  判斷正數、負數或零

難度：簡單

== 題目 ==
輸入一個整數 n，判斷其為正數、負數或零。

輸入說明：一行一個整數 n。
輸出說明：正數輸出 正數；負數輸出 負數；為 0 輸出 零。

== 參考解法 (Python) ==
n = int(input())
if n > 0:
    print("正數")
elif n < 0:
    print("負數")
else:
    print("零")

== 範例 1 輸入 ==
5
== 範例 1 輸出 ==
正數

== 範例 2 輸入 ==
-3
== 範例 2 輸出 ==
負數

== 範例 3 輸入 ==
0
== 範例 3 輸出 ==
零
