電腦軟體設計丙級 練習題 SWC33  印出數字堆疊三角形

難度：中等

== 題目 ==
輸入正整數 n，第 i 行輸出數字 1 到 i 依序相連 (不含空白)。

輸入說明：一行一個正整數 n (1<=n<=9)。
輸出說明：n 行數字堆疊圖案。

== 參考解法 (Python) ==
n = int(input())
for i in range(1, n + 1):
    print(''.join(str(d) for d in range(1, i + 1)))

== 範例 1 輸入 ==
4
== 範例 1 輸出 ==
1
12
123
1234

== 範例 2 輸入 ==
1
== 範例 2 輸出 ==
1
