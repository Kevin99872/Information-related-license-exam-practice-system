電腦軟體設計丙級 練習題 SWC55  座標點所在象限判斷

難度：中等

== 題目 ==
輸入平面座標 (x, y)，判斷該點所在的象限；若座標軸上，需分別判斷是否為原點、x 軸上或 y 軸上。

輸入說明：一行兩個整數 x 與 y。
輸出說明：象限一、象限二、象限三、象限四、原點、x軸上 或 y軸上。

== 參考解法 (Python) ==
x, y = map(int, input().split())
if x == 0 and y == 0:
    print("原點")
elif x == 0:
    print("y軸上")
elif y == 0:
    print("x軸上")
elif x > 0 and y > 0:
    print("象限一")
elif x < 0 and y > 0:
    print("象限二")
elif x < 0 and y < 0:
    print("象限三")
else:
    print("象限四")

== 範例 1 輸入 ==
3 5
== 範例 1 輸出 ==
象限一

== 範例 2 輸入 ==
-2 4
== 範例 2 輸出 ==
象限二

== 範例 3 輸入 ==
0 0
== 範例 3 輸出 ==
原點

== 範例 4 輸入 ==
5 0
== 範例 4 輸出 ==
x軸上
