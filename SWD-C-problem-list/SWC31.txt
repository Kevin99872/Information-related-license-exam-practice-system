電腦軟體設計丙級 練習題 SWC31  印出置中的正三角形星號圖案

難度：中等

== 題目 ==
輸入正整數 n，印出置中對齊的正三角形，第 i 行有 (2i-1) 個星號，前方補 (n-i) 個空白。

輸入說明：一行一個正整數 n (1<=n<=30)。
輸出說明：n 行置中對齊的星號圖案。

== 參考解法 (Python) ==
n = int(input())
for i in range(1, n + 1):
    print(' ' * (n - i) + '*' * (2 * i - 1))

== 範例 1 輸入 ==
3
== 範例 1 輸出 ==
  *
 ***
*****

== 範例 2 輸入 ==
1
== 範例 2 輸出 ==
*
