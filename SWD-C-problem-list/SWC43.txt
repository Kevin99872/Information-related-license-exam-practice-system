電腦軟體設計丙級 練習題 SWC43  找出陣列中第二大的數

難度：中等

== 題目 ==
輸入 n 個整數 (可能重複)，找出其中第二大的相異數值；若不存在 (所有數字都相同) 則輸出 none。

輸入說明：第一行一個整數 n；第二行 n 個整數。
輸出說明：第二大的相異數值，或 none。

== 參考解法 (Python) ==
n = int(input())
a = list(map(int, input().split()))
uniq = sorted(set(a), reverse=True)
print(uniq[1] if len(uniq) >= 2 else "none")

== 範例 1 輸入 ==
5
3 9 9 2 7
== 範例 1 輸出 ==
7

== 範例 2 輸入 ==
3
5 5 5
== 範例 2 輸出 ==
none
