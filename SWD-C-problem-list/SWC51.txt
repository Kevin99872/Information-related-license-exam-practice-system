電腦軟體設計丙級 練習題 SWC51  簡易四則運算計算機

難度：中等

== 題目 ==
輸入兩個整數與一個運算符號 (+ - * /)，計算並輸出結果。加、減、乘直接輸出整數結果；除法結果取到小數點後兩位；若為除法且除數為 0，輸出「除數不可為0」。

輸入說明：一行，格式為 a op b，以空白分隔 (op 為 + - * / 其中之一)。
輸出說明：運算結果，或錯誤訊息。

== 參考解法 (Python) ==
parts = input().split()
a, op, b = int(parts[0]), parts[1], int(parts[2])
if op == '+':
    print(a + b)
elif op == '-':
    print(a - b)
elif op == '*':
    print(a * b)
elif op == '/':
    if b == 0:
        print("除數不可為0")
    else:
        print(f"{a / b:.2f}")

== 範例 1 輸入 ==
3 + 5
== 範例 1 輸出 ==
8

== 範例 2 輸入 ==
10 / 0
== 範例 2 輸出 ==
除數不可為0

== 範例 3 輸入 ==
7 / 2
== 範例 3 輸出 ==
3.50
