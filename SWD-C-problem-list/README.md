# 電腦軟體設計丙級 練習題庫

本資料夾收錄 **電腦軟體設計丙級技術士**（勞動部勞動力發展署技能檢定）術科常見主題的練習題，每題附**參考解法**與**驗證過的測試資料**。丙級為入門級別（乙級的前一階），題目較 [`SWD-B-problem-list/`](../SWD-B-problem-list/)（乙級）淺顯，聚焦在基礎程式邏輯：簡單迴圈與計數、條件判斷、基礎陣列統計、基礎字串處理、基本數字性質判斷與簡易圖形/格式化輸出。

## 重要說明（請先閱讀）

- 丙級技術士的**官方術科試題屬於受版權保護的正式測驗題目**，本資料夾**並非**官方考題的重製，而是依照丙級術科**實際涵蓋的基礎程式邏輯主題**（基本流程控制、簡單迴圈、初階陣列、基礎字串處理、基本數學／數字性質、簡易格式化輸出等）自行編寫的**原創練習題**，用於在本系統中練習與自動判題。
- 本題庫刻意避開 `SWD-B-problem-list/`（乙級）已涵蓋的主題與難度（例如矩陣運算、質因數分解、二分搜尋、河內塔、約瑟夫問題、巴斯卡三角形、羅馬數字轉換、十六進位加法、完整版陣列統計等），避免與乙級題庫重複。
- 若要準備正式考試，請至 [勞動部技能檢定中心](https://www.wdasec.gov.tw/) 取得官方試題與應檢資料。

## 解法語言為什麼是 Python？

- 丙級術科實際使用 **C / C++**。但這台開發環境**未安裝可用的 C/C++ 命令列編譯器**（無 g++；MSVC 命令列環境無法運作 — 註：本環境現已安裝 g++，若需要可另外以 C++ 驗證邏輯，但本題庫沿用與乙級相同的慣例，僅提供 Python 解法），而本系統的 C++ 判題預設也依賴 `g++`。
- 因此本題庫的參考解法以 **Python** 撰寫：本機的 Python 可正常執行、本系統的判題器支援 Python，且**每一題、每一組範例都已實際執行驗證**（透過獨立的 subprocess 重新執行 `SolutionCode` 並比對 `TestInput` 產生的 stdout 與 `ExpectedOutput` 完全相符），因此**解法與測試資料保證一致、可直接自動判題**。
- 若日後安裝好可用的 C/C++ 編譯環境，可再請我補上對應語言的解法版本。

## 檔案內容

| 檔案 | 說明 |
|------|------|
| `SWD-C-problems.csv` | 可直接匯入本系統的題庫檔（UTF-8，無 BOM），含**解法程式碼**。相同 `ProblemCode` 的列會合併成同一題。 |
| `SWCxx.txt` | 各題的人類可讀版本：題目敘述 + 參考解法 + 範例輸入 / 輸出。 |
| `../scripts/generate_swdc_import_csv.py` | 將所有 `SWCxx.txt` 解析並產生 `SWD-C-problems.csv` 的產生腳本。 |

共 **55 題、141 組測試資料**，難度分佈：簡單 28（約 51%）、中等 22（約 40%）、困難 5（約 9%），整體較乙級題庫更輕量。

## 如何匯入本系統

1. 開啟應用程式，左側選單點選「匯入」。
2. 切換到「表單匯入」分頁。
3. 點「選擇 CSV / XLS / XLSX」，選擇本資料夾的 `SWD-C-problems.csv`。
4. 點「預覽 / 驗證」確認無誤後，點「匯入 / 更新」。

匯入後即可在「已載入題庫」與「題目」頁面看到 `ExamType = Software`（對應本系統內建的「電腦軟體設計 丙級技術士」考科分類）的題目。
