電腦軟體設計丙級 練習題 SWC52  找出陣列中出現次數最多的數字

難度：困難

== 題目 ==
輸入 n 個整數，找出出現次數最多的數字 (眾數)。若有多個數字出現次數相同且並列最多，輸出數值最小的那一個。

輸入說明：第一行一個整數 n；第二行 n 個整數。
輸出說明：出現次數最多的數字。

== 參考解法 (Python) ==
n = int(input())
a = list(map(int, input().split()))
freq = {}
for x in a:
    freq[x] = freq.get(x, 0) + 1
best, best_count = None, -1
for x in sorted(freq):
    if freq[x] > best_count:
        best, best_count = x, freq[x]
print(best)

== 範例 1 輸入 ==
6
1 2 2 3 3 3
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
5
4 4 5 5 1
== 範例 2 輸出 ==
4
