電腦軟體設計丙級 練習題 SWC07  計算n的階乘

難度：簡單

== 題目 ==
輸入非負整數 n，計算 n! (n 的階乘)。

輸入說明：一行一個整數 n (0<=n<=15)。
輸出說明：n 的階乘。

== 參考解法 (Python) ==
n = int(input())
r = 1
for i in range(1, n + 1):
    r *= i
print(r)

== 範例 1 輸入 ==
5
== 範例 1 輸出 ==
120

== 範例 2 輸入 ==
0
== 範例 2 輸出 ==
1

== 範例 3 輸入 ==
7
== 範例 3 輸出 ==
5040
