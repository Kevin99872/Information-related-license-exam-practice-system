電腦軟體設計丙級 練習題 SWC09  完整九九乘法表

難度：中等

== 題目 ==
輸入正整數 n (2<=n<=9)，輸出 n x n 的乘法表。

輸入說明：一行一個整數 n。
輸出說明：n 行，第 i 行依序輸出 i x 1=結果 到 i x n=結果，以空白分隔。

== 參考解法 (Python) ==
n = int(input())
for i in range(1, n + 1):
    print(' '.join(f"{i}x{j}={i * j}" for j in range(1, n + 1)))

== 範例 1 輸入 ==
3
== 範例 1 輸出 ==
1x1=1 1x2=2 1x3=3
2x1=2 2x2=4 2x3=6
3x1=3 3x2=6 3x3=9

== 範例 2 輸入 ==
5
== 範例 2 輸出 ==
1x1=1 1x2=2 1x3=3 1x4=4 1x5=5
2x1=2 2x2=4 2x3=6 2x4=8 2x5=10
3x1=3 3x2=6 3x3=9 3x4=12 3x5=15
4x1=4 4x2=8 4x3=12 4x4=16 4x5=20
5x1=5 5x2=10 5x3=15 5x4=20 5x5=25
