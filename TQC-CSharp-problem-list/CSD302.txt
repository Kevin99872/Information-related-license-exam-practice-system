TQC+ 程式語言C# CSD302  字元出現次數統計

難度：簡單
主題：字串

== 題目 ==
輸入一個字串與一個欲查詢的字元，統計該字元在字串中出現的次數。

輸入說明：第一行為字串 s（長度 1~200，不含空白）；第二行為單一字元 ch。
輸出說明：一行，字元 ch 在 s 中出現的次數。

== 參考解法 (C#) ==
using System;
using System.Linq;

class Program
{
    static void Main()
    {
        string s = Console.ReadLine() ?? "";
        string chLine = Console.ReadLine() ?? "";
        char ch = chLine[0];
        int count = s.Count(c => c == ch);
        Console.WriteLine(count);
    }
}

== 範例 1 輸入 ==
banana
a
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
mississippi
s
== 範例 2 輸出 ==
4
