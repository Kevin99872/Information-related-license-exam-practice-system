TQC+ 程式語言C# CSD507  IComparable 介面排序

難度：困難
主題：物件導向

== 題目 ==
定義 Employee 類別，含 Name 與 Salary 屬性，實作 IComparable&lt;Employee&gt; 介面，依 Salary 由小到大比較。輸入 n 筆員工資料存入 List&lt;Employee&gt;，使用 List&lt;T&gt;.Sort() 依薪資由小到大排序後，依序輸出「姓名 薪資」。

輸入說明：第一行為整數 n；接著 n 行，每行為「姓名 薪資」（薪資為整數）。
輸出說明：n 行，依薪資由小到大排序後的「姓名 薪資」。

== 參考解法 (C#) ==
using System;
using System.Collections.Generic;

class Employee : IComparable<Employee>
{
    public string Name { get; set; }
    public int Salary { get; set; }

    public Employee(string name, int salary)
    {
        Name = name;
        Salary = salary;
    }

    public int CompareTo(Employee? other)
    {
        if (other == null) return 1;
        return Salary.CompareTo(other.Salary);
    }
}

class Program
{
    static void Main()
    {
        int n = int.Parse(Console.ReadLine() ?? "0");
        List<Employee> employees = new List<Employee>();
        for (int i = 0; i < n; i++)
        {
            string[] parts = (Console.ReadLine() ?? "").Split(' ');
            employees.Add(new Employee(parts[0], int.Parse(parts[1])));
        }
        employees.Sort();
        foreach (Employee e in employees)
        {
            Console.WriteLine($"{e.Name} {e.Salary}");
        }
    }
}
