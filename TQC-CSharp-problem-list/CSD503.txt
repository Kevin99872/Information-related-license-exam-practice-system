TQC+ 程式語言C# CSD503  抽象類別計算圖形面積

難度：中等
主題：物件導向

== 題目 ==
定義抽象類別 Shape，含抽象方法 GetArea() 回傳 double。定義子類別 Circle（半徑，面積 = 3.14 * r * r）與 Rectangle（長寬，面積 = 長 * 寬），皆實作 GetArea()。輸入類別代碼與對應參數，輸出面積（保留小數點後 2 位）。

輸入說明：第一行為整數 type（1=圓形，2=矩形）；若 type=1，第二行為半徑；若 type=2，第二行為長與寬（以空白分隔）。
輸出說明：一行，格式為「面積:X」，X 為面積並保留小數點後 2 位。

== 參考解法 (C#) ==
using System;
using System.Globalization;

abstract class Shape
{
    public abstract double GetArea();
}

class Circle : Shape
{
    private double radius;

    public Circle(double radius)
    {
        this.radius = radius;
    }

    public override double GetArea()
    {
        return 3.14 * radius * radius;
    }
}

class Rectangle : Shape
{
    private double width;
    private double height;

    public Rectangle(double width, double height)
    {
        this.width = width;
        this.height = height;
    }

    public override double GetArea()
    {
        return width * height;
    }
}

class Program
{
    static void Main()
    {
        int type = int.Parse(Console.ReadLine() ?? "1");
        Shape shape;
        if (type == 1)
        {
            double r = double.Parse(Console.ReadLine() ?? "0", CultureInfo.InvariantCulture);
            shape = new Circle(r);
        }
        else
        {
            string[] parts = (Console.ReadLine() ?? "").Split(' ');
            double w = double.Parse(parts[0], CultureInfo.InvariantCulture);
            double h = double.Parse(parts[1], CultureInfo.InvariantCulture);
            shape = new Rectangle(w, h);
        }
        Console.WriteLine($"面積:{shape.GetArea().ToString("F2", CultureInfo.InvariantCulture)}");
    }
}

10
