TQC+ 程式語言C# CSD207  氣泡排序由小到大

難度：中等
主題：陣列

== 題目 ==
輸入 n 個整數，使用氣泡排序法將其由小到大排序後輸出。

輸入說明：一行，n 個以空白分隔的整數。
輸出說明：一行，排序後的整數，以空白分隔。

== 參考解法 (C#) ==
using System;
using System.Linq;

class Program
{
    static void Main()
    {
        int[] nums = (Console.ReadLine() ?? "").Split(' ', StringSplitOptions.RemoveEmptyEntries)
            .Select(int.Parse).ToArray();
        int n = nums.Length;
        for (int i = 0; i < n - 1; i++)
        {
            for (int j = 0; j < n - 1 - i; j++)
            {
                if (nums[j] > nums[j + 1])
                {
                    (nums[j], nums[j + 1]) = (nums[j + 1], nums[j]);
                }
            }
        }
        Console.WriteLine(string.Join(" ", nums));
    }
}

== 範例 1 輸入 ==
5 3 8 1 9
== 範例 1 輸出 ==
1 3 5 8 9

== 範例 2 輸入 ==
4 4 2 1
== 範例 2 輸出 ==
1 2 4 4
