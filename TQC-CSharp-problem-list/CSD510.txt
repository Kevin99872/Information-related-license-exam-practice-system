TQC+ 程式語言C# CSD510  介面預設行為與多型輸出

難度：困難
主題：物件導向

== 題目 ==
定義介面 ILibraryItem，含方法 GetInfo() 回傳字串。定義類別 Book（書名、作者）與 Magazine（刊名、期數）皆實作此介面，GetInfo() 分別回傳「書籍:書名/作者」與「雜誌:刊名 第期數期」。輸入 n 筆資料，依序建立對應物件並輸出 GetInfo() 結果。

輸入說明：第一行為整數 n；接著 n 行，每行為「B 書名 作者」（書籍）或「M 刊名 期數」（雜誌，期數為整數）。
輸出說明：n 行，依序為每筆資料的 GetInfo() 結果。

== 參考解法 (C#) ==
using System;
using System.Collections.Generic;

interface ILibraryItem
{
    string GetInfo();
}

class Book : ILibraryItem
{
    private string title;
    private string author;

    public Book(string title, string author)
    {
        this.title = title;
        this.author = author;
    }

    public string GetInfo() => $"書籍:{title}/{author}";
}

class Magazine : ILibraryItem
{
    private string name;
    private int issue;

    public Magazine(string name, int issue)
    {
        this.name = name;
        this.issue = issue;
    }

    public string GetInfo() => $"雜誌:{name} 第{issue}期";
}

class Program
{
    static void Main()
    {
        int n = int.Parse(Console.ReadLine() ?? "0");
        List<ILibraryItem> items = new List<ILibraryItem>();
        for (int i = 0; i < n; i++)
        {
            string[] parts = (Console.ReadLine() ?? "").Split(' ');
            if (parts[0] == "B")
            {
                items.Add(new Book(parts[1], parts[2]));
            }
            else
            {
                items.Add(new Magazine(parts[1], int.Parse(parts[2])));
            }
        }
        foreach (ILibraryItem item in items)
        {
            Console.WriteLine(item.GetInfo());
        }
    }
}

== 範例 1 輸入 ==
2
B 三國演義 羅貫中
M 科學人 200
== 範例 1 輸出 ==
書籍:三國演義/羅貫中
雜誌:科學人 第200期

== 範例 2 輸入 ==
1
B 紅樓夢 曹雪芹
== 範例 2 輸出 ==
書籍:紅樓夢/曹雪芹
