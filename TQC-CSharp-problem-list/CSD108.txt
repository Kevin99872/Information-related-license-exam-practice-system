TQC+ 程式語言C# CSD108  三角形星號圖案

難度：中等
主題：格式化輸出

== 題目 ==
輸入一個正整數 n，輸出一個 n 列的直角三角形星號圖案，第 i 列（由 1 開始）包含 i 個星號。

輸入說明：一行正整數 n（1 <= n <= 20）。
輸出說明：n 行，第 i 行為 i 個 '*' 字元。

== 參考解法 (C#) ==
using System;
using System.Text;

class Program
{
    static void Main()
    {
        int n = int.Parse(Console.ReadLine() ?? "0");
        for (int i = 1; i <= n; i++)
        {
            Console.WriteLine(new string('*', i));
        }
    }
}

== 範例 1 輸入 ==
3
== 範例 1 輸出 ==
*
**
***

== 範例 2 輸入 ==
5
== 範例 2 輸出 ==
*
**
***
****
*****
