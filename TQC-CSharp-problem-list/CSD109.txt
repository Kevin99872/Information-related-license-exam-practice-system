TQC+ 程式語言C# CSD109  九九乘法表單一直行

難度：中等
主題：格式化輸出

== 題目 ==
輸入一個 1 到 9 的整數 n，輸出該數字的九九乘法表（n 乘以 1 到 9），格式為「n x i = 結果」。

輸入說明：一行整數 n（1 <= n <= 9）。
輸出說明：九行，依序為 n x 1 = ... 到 n x 9 = ...。

== 參考解法 (C#) ==
using System;

class Program
{
    static void Main()
    {
        int n = int.Parse(Console.ReadLine() ?? "1");
        for (int i = 1; i <= 9; i++)
        {
            Console.WriteLine($"{n} x {i} = {n * i}");
        }
    }
}

== 範例 1 輸入 ==
3
== 範例 1 輸出 ==
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
3 x 6 = 18
3 x 7 = 21
3 x 8 = 24
3 x 9 = 27

== 範例 2 輸入 ==
9
== 範例 2 輸出 ==
9 x 1 = 9
9 x 2 = 18
9 x 3 = 27
9 x 4 = 36
9 x 5 = 45
9 x 6 = 54
9 x 7 = 63
9 x 8 = 72
9 x 9 = 81
