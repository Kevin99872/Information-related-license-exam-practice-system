難度：困難
主題：例外處理

== 題目 ==
定義自訂例外 InvalidScoreException（繼承 Exception）。輸入 n 個分數，使用迴圈逐一檢查，若分數不在 0~100 範圍內則拋出 InvalidScoreException 並附訊息「發現不合法分數:X」（X 為該分數），以 try-catch 攔截並輸出該訊息後結束；若全部分數皆合法，則使用 LINQ 計算平均分數（保留小數點後 1 位）並輸出「平均:X」。

輸入說明：第一行為整數 n；第二行為 n 個以空白分隔的整數分數（可能包含不合法範圍的值）。
輸出說明：一行，若有不合法分數輸出「發現不合法分數:X」（X 為第一個發現的不合法分數）；否則輸出「平均:X」。

== 參考解法 (C#) ==
using System;
using System.Linq;
using System.Globalization;

class InvalidScoreException : Exception
{
    public InvalidScoreException(string message) : base(message)
    {
    }
}

class Program
{
    static void Main()
    {
        int n = int.Parse(Console.ReadLine() ?? "0");
        int[] scores = (Console.ReadLine() ?? "").Split(' ', StringSplitOptions.RemoveEmptyEntries)
            .Select(int.Parse).ToArray();
        try
        {
            foreach (int s in scores)
            {
                if (s < 0 || s > 100)
                {
                    throw new InvalidScoreException($"發現不合法分數:{s}");
                }
            }
            double avg = scores.Average();
            Console.WriteLine(string.Format(CultureInfo.InvariantCulture, "平均:{0:F1}", avg));
        }
        catch (InvalidScoreException ex)
        {
            Console.WriteLine(ex.Message);
        }
    }
}

== 範例 1 輸入 ==
5
80 90 75 60 100
== 範例 1 輸出 ==
平均:81.0

== 範例 2 輸入 ==
3
80 150 60
== 範例 2 輸出 ==
發現不合法分數:150
