TQC+ 程式語言C# CSD103  浮點數四捨五入格式化

難度：簡單
主題：格式化輸出

== 題目 ==
輸入一個浮點數，輸出其分別四捨五入至小數點後 0 位、1 位、2 位的結果，使用 string.Format 的固定小數位格式。

輸入說明：一行浮點數 x。
輸出說明：三行，依序為 0 位、1 位、2 位小數的四捨五入結果。

== 參考解法 (C#) ==
using System;
using System.Globalization;

class Program
{
    static void Main()
    {
        double x = double.Parse(Console.ReadLine() ?? "0", CultureInfo.InvariantCulture);
        Console.WriteLine(string.Format(CultureInfo.InvariantCulture, "{0:F0}", x));
        Console.WriteLine(string.Format(CultureInfo.InvariantCulture, "{0:F1}", x));
        Console.WriteLine(string.Format(CultureInfo.InvariantCulture, "{0:F2}", x));
    }
}

== 範例 1 輸入 ==
3.14159
== 範例 1 輸出 ==
3
3.1
3.14

== 範例 2 輸入 ==
2.995
== 範例 2 輸出 ==
3
3.0
3.00
