TQC+ 程式語言C# CSD205  迴圈計算階乘

難度：簡單
主題：控制流程

== 題目 ==
輸入一個非負整數 n，使用迴圈計算 n 的階乘（n!）。

輸入說明：一行整數 n（0 <= n <= 20）。
輸出說明：一行，n! 的計算結果。

== 參考解法 (C#) ==
using System;

class Program
{
    static void Main()
    {
        int n = int.Parse(Console.ReadLine() ?? "0");
        long result = 1;
        for (int i = 2; i <= n; i++)
        {
            result *= i;
        }
        Console.WriteLine(result);
    }
}

== 範例 1 輸入 ==
5
== 範例 1 輸出 ==
120

== 範例 2 輸入 ==
0
== 範例 2 輸出 ==
1
