TQC+ 程式語言C# CSD106  百分比格式化輸出

難度：簡單
主題：格式化輸出

== 題目 ==
輸入及格人數與總人數，計算及格率並以百分比格式輸出（小數點後 1 位，含 % 符號）。

輸入說明：第一行為及格人數 pass（整數）；第二行為總人數 total（整數，total > 0）。
輸出說明：一行，格式為「及格率：XX.X%」。

== 參考解法 (C#) ==
using System;
using System.Globalization;

class Program
{
    static void Main()
    {
        int pass = int.Parse(Console.ReadLine() ?? "0");
        int total = int.Parse(Console.ReadLine() ?? "1");
        double rate = pass * 100.0 / total;
        Console.WriteLine(string.Format(CultureInfo.InvariantCulture, "及格率：{0:F1}%", rate));
    }
}

== 範例 1 輸入 ==
18
20
== 範例 1 輸出 ==
及格率：90.0%

== 範例 2 輸入 ==
7
9
== 範例 2 輸出 ==
及格率：77.8%
