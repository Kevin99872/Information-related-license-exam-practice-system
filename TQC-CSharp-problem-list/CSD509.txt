TQC+ 程式語言C# CSD509  訂單與商品組合關係

難度：困難
主題：物件導向

== 題目 ==
定義 Item 類別（含 Name、Price、Qty），定義 Order 類別內含 List&lt;Item&gt; 作為組合關係，提供方法 AddItem(Item item) 加入商品，以及方法 GetTotal() 計算所有商品小計（Price * Qty）加總。輸入 n 筆商品資料加入訂單，輸出訂單總金額。

輸入說明：第一行為整數 n；接著 n 行，每行為「品名 單價 數量」（單價、數量為整數）。
輸出說明：一行，格式為「訂單總額:X」。

== 參考解法 (C#) ==
using System;
using System.Collections.Generic;

class Item
{
    public string Name { get; set; }
    public int Price { get; set; }
    public int Qty { get; set; }

    public Item(string name, int price, int qty)
    {
        Name = name;
        Price = price;
        Qty = qty;
    }

    public int Subtotal() => Price * Qty;
}

class Order
{
    private List<Item> items = new List<Item>();

    public void AddItem(Item item)
    {
        items.Add(item);
    }

    public int GetTotal()
    {
        int total = 0;
        foreach (Item item in items)
        {
            total += item.Subtotal();
        }
        return total;
    }
}

class Program
{
    static void Main()
    {
        int n = int.Parse(Console.ReadLine() ?? "0");
        Order order = new Order();
        for (int i = 0; i < n; i++)
        {
            string[] parts = (Console.ReadLine() ?? "").Split(' ');
            order.AddItem(new Item(parts[0], int.Parse(parts[1]), int.Parse(parts[2])));
        }
        Console.WriteLine($"訂單總額:{order.GetTotal()}");
    }
}

== 範例 1 輸入 ==
2
筆記本 45 3
鉛筆 8 5
== 範例 1 輸出 ==
訂單總額:175

== 範例 2 輸入 ==

== 範例 2 輸出 ==
