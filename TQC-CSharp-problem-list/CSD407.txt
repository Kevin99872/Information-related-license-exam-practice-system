TQC+ 程式語言C# CSD407  靜態欄位計數器類別

難度：中等
主題：物件導向

== 題目 ==
定義 Counter 類別，使用靜態欄位 Count 記錄目前已建立的物件個數，每建立一個物件 Count 加一。輸入建立物件的次數 n，輸出建立完成後的 Count 值。

輸入說明：一行整數 n（1 <= n <= 100）。
輸出說明：一行，格式為「目前物件數量:X」。

== 參考解法 (C#) ==
using System;

class Counter
{
    public static int Count { get; private set; } = 0;

    public Counter()
    {
        Count++;
    }
}

class Program
{
    static void Main()
    {
        int n = int.Parse(Console.ReadLine() ?? "0");
        for (int i = 0; i < n; i++)
        {
            new Counter();
        }
        Console.WriteLine($"目前物件數量:{Counter.Count}");
    }
}

== 範例 1 輸入 ==
5
== 範例 1 輸出 ==
目前物件數量:5

== 範例 2 輸入 ==
1
== 範例 2 輸出 ==
目前物件數量:1
