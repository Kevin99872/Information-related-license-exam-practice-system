# TQC+ 程式語言 C# 練習題庫

本資料夾收錄仿 **TQC+ 程式設計能力認證（C#）** 常見主題所編寫的練習題，每題附**參考解法（C#）**與**已實際編譯執行驗證過**的測試資料，供本系統匯入後自動判題練習使用。

## 重要說明（請先閱讀）

- **TQC+（中華民國電腦技能基金會）之官方認證試題屬於受版權保護的正式測驗內容**，本資料夾**並非**官方考題的重製或翻譯，題目文字、情境與參考解法皆為**原創編寫**。
- 題目涵蓋的範疇與難易度分佈，是依照 TQC+ 程式設計能力認證 C# / 一般 C# 基礎能力測驗**常見涵蓋的技能主題**（主控台輸入輸出與格式化、流程控制、陣列、字串處理、方法與多載、物件導向、例外處理、集合與 LINQ 等）自行設計，用於在本系統中練習與自動判題。
- 若要準備正式認證考試，請洽 [中華民國電腦技能基金會 TQC+](https://www.tqc.org.tw/) 取得官方試題與應檢資料。

## 解法語言與驗證方式

- 每一題的參考解法皆以 **C#** 撰寫（`using System; class Program { static void Main() { ... } }` 型式），並實際透過 `dotnet build` + 執行的方式跑過**每一組範例輸入**，確認主控台輸出與題庫中記錄的 `ExpectedOutput` **逐字元相符**，因此解法與測試資料保證一致、可直接匯入本系統自動判題。
- 驗證專案設定與本系統執行 C# 程式碼時使用的 `.csproj`（`OutputType=Exe`、`TargetFramework=net10.0`、`ImplicitUsings`、`Nullable` 皆為 enable）一致，確保匯入後在系統內判題行為與本地驗證結果相同。

## 檔案內容

| 檔案 | 說明 |
|------|------|
| `TQC-CSharp-problems.csv` | 可直接匯入本系統的題庫檔（UTF-8，無 BOM），含**解法程式碼**。相同 `ProblemCode` 的列會合併成同一題（每題 2 組範例測試資料）。 |
| `CSDxxx.txt` | 各題的人類可讀版本：題目敘述 + 參考解法（C#）+ 範例輸入 / 輸出。 |

共 **60 題、120 組測試資料**，難度分佈：簡單 18 題、中等 27 題、困難 15 題。

## 如何匯入本系統

1. 開啟應用程式，左側選單點選「匯入」。
2. 切換到「表單匯入」分頁。
3. 點「選擇 CSV / XLS / XLSX」，選擇本資料夾的 `TQC-CSharp-problems.csv`。
4. 點「預覽 / 驗證」確認無誤後，點「匯入 / 更新」。

匯入後即可在「已載入題庫」與「題目」頁面看到 `ExamType = TQC`、`SolutionLanguage = C#` 的題目（本系統目前僅有單一 TQC 分類，尚無獨立的 C# 子分類，此為預期行為）。
