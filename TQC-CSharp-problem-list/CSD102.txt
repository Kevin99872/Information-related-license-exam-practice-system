TQC+ 程式語言C# CSD102  四則運算格式化輸出

難度：簡單
主題：格式化輸出

== 題目 ==
輸入兩個整數 a、b，依序輸出兩數的和、差、積、商（整數除法）與餘數，每項各佔一行，格式為「a 運算符 b = 結果」。

輸入說明：第一行為整數 a；第二行為整數 b（b 不為 0）。
輸出說明：五行，依序為加、減、乘、除、餘數的算式與結果。

== 參考解法 (C#) ==
using System;

class Program
{
    static void Main()
    {
        int a = int.Parse(Console.ReadLine() ?? "0");
        int b = int.Parse(Console.ReadLine() ?? "0");
        Console.WriteLine($"{a} + {b} = {a + b}");
        Console.WriteLine($"{a} - {b} = {a - b}");
        Console.WriteLine($"{a} * {b} = {a * b}");
        Console.WriteLine($"{a} / {b} = {a / b}");
        Console.WriteLine($"{a} % {b} = {a % b}");
    }
}

== 範例 1 輸入 ==
10
3
== 範例 1 輸出 ==
10 + 3 = 13
10 - 3 = 7
10 * 3 = 30
10 / 3 = 3
10 % 3 = 1

== 範例 2 輸入 ==
7
7
== 範例 2 輸出 ==
7 + 7 = 14
7 - 7 = 0
7 * 7 = 49
7 / 7 = 1
7 % 7 = 0
