TQC+ 程式語言C# CSD306  StringBuilder 組合報表列

難度：中等
主題：字串

== 題目 ==
輸入 n 筆「品名 數量 單價」資料，使用 StringBuilder 組合輸出報表，每筆一行，格式為「品名 x 數量 = 小計」，小計為數量乘以單價，最後一行輸出「總計：X」為所有小計加總。

輸入說明：第一行為整數 n；接著 n 行，每行為「品名 數量 單價」，數量與單價皆為整數。
輸出說明：n 行商品小計，最後一行為總計。

== 參考解法 (C#) ==
using System;
using System.Text;

class Program
{
    static void Main()
    {
        int n = int.Parse(Console.ReadLine() ?? "0");
        StringBuilder sb = new StringBuilder();
        int total = 0;
        for (int i = 0; i < n; i++)
        {
            string[] parts = (Console.ReadLine() ?? "").Split(' ');
            string name = parts[0];
            int qty = int.Parse(parts[1]);
            int price = int.Parse(parts[2]);
            int subtotal = qty * price;
            total += subtotal;
            sb.AppendLine($"{name} x {qty} = {subtotal}");
        }
        sb.Append($"總計：{total}");
        Console.WriteLine(sb.ToString());
    }
}

== 範例 1 輸入 ==
2
筆記本 3 45
鉛筆 5 8
== 範例 1 輸出 ==
筆記本 x 3 = 135
鉛筆 x 5 = 40
總計：175

== 範例 2 輸入 ==
1
橡皮擦 10 15
== 範例 2 輸出 ==
橡皮擦 x 10 = 150
總計：150
