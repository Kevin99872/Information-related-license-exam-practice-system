TQC+ 程式語言C# CSD203  數字位數加總

難度：簡單
主題：控制流程

== 題目 ==
輸入一個正整數，計算其各位數字的總和。

輸入說明：一行正整數 n（1 <= n <= 2000000000）。
輸出說明：一行，該整數各位數字的總和。

== 參考解法 (C#) ==
using System;

class Program
{
    static void Main()
    {
        long n = long.Parse(Console.ReadLine() ?? "0");
        long sum = 0;
        while (n > 0)
        {
            sum += n % 10;
            n /= 10;
        }
        Console.WriteLine(sum);
    }
}

== 範例 1 輸入 ==
12345
== 範例 1 輸出 ==
15

== 範例 2 輸入 ==
9999
== 範例 2 輸出 ==
36
