TQC+ 程式語言C# CSD605  LINQ OrderBy 多鍵排序

難度：困難
主題：集合與LINQ

== 題目 ==
輸入 n 筆學生資料（姓名、班級、分數），使用 LINQ 先依分數由高到低排序，分數相同時依姓名字典順序排序，輸出排序後的「姓名 班級 分數」。

輸入說明：第一行為整數 n；接著 n 行，每行為「姓名 班級 分數」（分數為整數）。
輸出說明：n 行，排序後的「姓名 班級 分數」。

== 參考解法 (C#) ==
using System;
using System.Collections.Generic;
using System.Linq;

class Student
{
    public string Name = "";
    public string Class = "";
    public int Score;
}

class Program
{
    static void Main()
    {
        int n = int.Parse(Console.ReadLine() ?? "0");
        List<Student> students = new List<Student>();
        for (int i = 0; i < n; i++)
        {
            string[] parts = (Console.ReadLine() ?? "").Split(' ');
            students.Add(new Student { Name = parts[0], Class = parts[1], Score = int.Parse(parts[2]) });
        }
        var sorted = students
            .OrderByDescending(s => s.Score)
            .ThenBy(s => s.Name, StringComparer.Ordinal)
            .ToList();
        foreach (var s in sorted)
        {
            Console.WriteLine($"{s.Name} {s.Class} {s.Score}");
        }
    }
}
