電腦軟體設計乙級 練習題 SWB02  選擇排序（由小到大）

難度：簡單

== 題目 ==
以「選擇排序法」將 n 個整數由小到大排序後輸出。

輸入說明：第一行整數 n；第二行 n 個整數 (以空白分隔)。
輸出說明：一行，排序後的 n 個整數。

== 參考解法 (Python) ==
n = int(input())
a = list(map(int, input().split()))
for i in range(n):
    m = i
    for j in range(i + 1, n):
        if a[j] < a[m]:
            m = j
    a[i], a[m] = a[m], a[i]
print(' '.join(map(str, a)))

== 範例 1 輸入 ==
5
5 2 8 1 9
== 範例 1 輸出 ==
1 2 5 8 9

== 範例 2 輸入 ==
6
3 3 1 2 2 1
== 範例 2 輸出 ==
1 1 2 2 3 3
