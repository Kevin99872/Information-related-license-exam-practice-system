電腦軟體設計乙級 練習題 SWB20  閏年判斷

難度：簡單

== 題目 ==
閏年規則：能被 4 整除但不能被 100 整除，或能被 400 整除。輸出區間 [a,b] 內的所有閏年。

輸入說明：一行兩個整數 a 與 b (1<=a<=b<=3000)。
輸出說明：區間內的閏年 (由小到大，空白分隔)；若無則輸出 none。

== 參考解法 (Python) ==
a, b = map(int, input().split())
res = [y for y in range(a, b + 1) if (y % 4 == 0 and y % 100 != 0) or y % 400 == 0]
print(' '.join(map(str, res)) if res else 'none')

== 範例 1 輸入 ==
2000 2012
== 範例 1 輸出 ==
2000 2004 2008 2012

== 範例 2 輸入 ==
1900 1901
== 範例 2 輸出 ==
none
