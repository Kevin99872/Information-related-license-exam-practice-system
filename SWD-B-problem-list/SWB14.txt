電腦軟體設計乙級 練習題 SWB14  二分搜尋法

難度：中等

== 題目 ==
在一個「已由小到大排序」的陣列中，以二分搜尋法尋找目標值，輸出其位置 (1 起算)，找不到輸出 -1。

輸入說明：第一行整數 n；第二行 n 個遞增整數；第三行為目標值 t。
輸出說明：t 的位置 (1 起算)，找不到則 -1。

== 參考解法 (Python) ==
n = int(input())
a = list(map(int, input().split()))
t = int(input())
lo, hi, ans = 0, n - 1, -1
while lo <= hi:
    mid = (lo + hi) // 2
    if a[mid] == t:
        ans = mid + 1
        break
    elif a[mid] < t:
        lo = mid + 1
    else:
        hi = mid - 1
print(ans)

== 範例 1 輸入 ==
7
1 3 5 7 9 11 13
7
== 範例 1 輸出 ==
4

== 範例 2 輸入 ==
5
2 4 6 8 10
5
== 範例 2 輸出 ==
-1
