電腦軟體設計乙級 練習題 SWB09  最大公因數與最小公倍數

難度：簡單

== 題目 ==
計算兩個正整數的最大公因數 (GCD) 與最小公倍數 (LCM)。

輸入說明：一行兩個正整數 a 與 b。
輸出說明：一行，GCD 與 LCM，以空白分隔。

== 參考解法 (Python) ==
def gcd(x, y):
    while y:
        x, y = y, x % y
    return x
a, b = map(int, input().split())
g = gcd(a, b)
print(g, a * b // g)

== 範例 1 輸入 ==
12 18
== 範例 1 輸出 ==
6 36

== 範例 2 輸入 ==
7 5
== 範例 2 輸出 ==
1 35

== 範例 3 輸入 ==
100 40
== 範例 3 輸出 ==
20 200
