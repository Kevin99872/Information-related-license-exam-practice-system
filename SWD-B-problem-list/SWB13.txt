電腦軟體設計乙級 練習題 SWB13  完全數

難度：中等

== 題目 ==
完全數是指等於其所有真因數 (不含自身) 之和的正整數，如 6=1+2+3。輸出區間 [a,b] 內的所有完全數。

輸入說明：一行兩個正整數 a 與 b (1<=a<=b<=10000)。
輸出說明：區間內的完全數 (由小到大，空白分隔)；若無則輸出 none。

== 參考解法 (Python) ==
a, b = map(int, input().split())
res = []
for n in range(max(a, 1), b + 1):
    s = sum(d for d in range(1, n) if n % d == 0)
    if s == n:
        res.append(n)
print(' '.join(map(str, res)) if res else 'none')

== 範例 1 輸入 ==
1 30
== 範例 1 輸出 ==
6 28

== 範例 2 輸入 ==
1 10000
== 範例 2 輸出 ==
6 28 496 8128

== 範例 3 輸入 ==
10 20
== 範例 3 輸出 ==
none
