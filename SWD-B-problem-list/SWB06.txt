電腦軟體設計乙級 練習題 SWB06  任意進位轉十進位

難度：中等

== 題目 ==
將一個 N 進位數 (2<=N<=16) 轉換為十進位。位數可含 0~9 與大寫 A~F。

輸入說明：一行：進位基底 N 與該進位下的數字字串。
輸出說明：對應的十進位整數。

== 參考解法 (Python) ==
s = input().split()
base, num = int(s[0]), s[1]
print(int(num, base))

== 範例 1 輸入 ==
16 FF
== 範例 1 輸出 ==
255

== 範例 2 輸入 ==
2 11110
== 範例 2 輸出 ==
30

== 範例 3 輸入 ==
8 144
== 範例 3 輸出 ==
100
