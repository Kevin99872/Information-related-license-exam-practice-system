電腦軟體設計乙級 練習題 SWB19  十六進位加法

難度：中等

== 題目 ==
計算兩個十六進位數的和，並以大寫十六進位輸出 (數值可能很大)。

輸入說明：一行兩個十六進位數 (可含 0~9、A~F)。
輸出說明：兩數之和的十六進位表示 (大寫)。

== 參考解法 (Python) ==
s = input().split()
print(format(int(s[0], 16) + int(s[1], 16), 'X'))

== 範例 1 輸入 ==
FF 1
== 範例 1 輸出 ==
100

== 範例 2 輸入 ==
1A2B 00C4
== 範例 2 輸出 ==
1AEF

== 範例 3 輸入 ==
FFFFFFFF FFFFFFFF
== 範例 3 輸出 ==
1FFFFFFFE
