電腦軟體設計乙級 練習題 SWB16  阿拉伯數字轉羅馬數字

難度：困難

== 題目 ==
將 1~3999 的整數轉換為羅馬數字。

輸入說明：一行一個整數 n (1<=n<=3999)。
輸出說明：對應的羅馬數字。

== 參考解法 (Python) ==
n = int(input())
table = [(1000,'M'),(900,'CM'),(500,'D'),(400,'CD'),(100,'C'),(90,'XC'),
         (50,'L'),(40,'XL'),(10,'X'),(9,'IX'),(5,'V'),(4,'IV'),(1,'I')]
r = ''
for v, sym in table:
    while n >= v:
        r += sym
        n -= v
print(r)

== 範例 1 輸入 ==
4
== 範例 1 輸出 ==
IV

== 範例 2 輸入 ==
1994
== 範例 2 輸出 ==
MCMXCIV

== 範例 3 輸入 ==
3888
== 範例 3 輸出 ==
MMMDCCCLXXXVIII
