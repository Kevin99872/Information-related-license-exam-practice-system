電腦軟體設計乙級 練習題 SWB05  十進位轉任意進位（2~16）

難度：中等

== 題目 ==
將十進位整數轉換為指定的 N 進位 (2<=N<=16)，超過 9 的位數以大寫英文字母 A~F 表示。

輸入說明：一行兩個整數：數值 與 進位基底 N。
輸出說明：轉換後的字串 (數值為 0 時輸出 0)。

== 參考解法 (Python) ==
digs = "0123456789ABCDEF"
s = input().split()
n, base = int(s[0]), int(s[1])
if n == 0:
    print('0')
else:
    r = ''
    while n > 0:
        r = digs[n % base] + r
        n //= base
    print(r)

== 範例 1 輸入 ==
255 16
== 範例 1 輸出 ==
FF

== 範例 2 輸入 ==
30 2
== 範例 2 輸出 ==
11110

== 範例 3 輸入 ==
100 8
== 範例 3 輸出 ==
144
