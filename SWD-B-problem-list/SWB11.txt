電腦軟體設計乙級 練習題 SWB11  巴斯卡三角形

難度：中等

== 題目 ==
輸出巴斯卡 (Pascal) 三角形的前 n 列，每列數字以空白分隔。

輸入說明：一行一個正整數 n (1<=n<=20)。
輸出說明：n 行，第 i 行為第 i 列的二項式係數。

== 參考解法 (Python) ==
n = int(input())
row = [1]
for _ in range(n):
    print(' '.join(map(str, row)))
    row = [1] + [row[j] + row[j + 1] for j in range(len(row) - 1)] + [1]

== 範例 1 輸入 ==
5
== 範例 1 輸出 ==
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1

== 範例 2 輸入 ==
1
== 範例 2 輸出 ==
1
