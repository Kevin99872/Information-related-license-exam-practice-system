電腦軟體設計乙級 練習題 SWB10  質因數分解

難度：中等

== 題目 ==
將一個大於 1 的整數分解為質因數的乘積，由小到大輸出所有質因數 (含重複)。

輸入說明：一行一個整數 n (2<=n<=1000000)。
輸出說明：一行，質因數由小到大以空白分隔，例如 60 -> 2 2 3 5。

== 參考解法 (Python) ==
n = int(input())
res = []
d = 2
while d * d <= n:
    while n % d == 0:
        res.append(d)
        n //= d
    d += 1
if n > 1:
    res.append(n)
print(' '.join(map(str, res)))

== 範例 1 輸入 ==
60
== 範例 1 輸出 ==
2 2 3 5

== 範例 2 輸入 ==
97
== 範例 2 輸出 ==
97

== 範例 3 輸入 ==
360
== 範例 3 輸出 ==
2 2 2 3 3 5
