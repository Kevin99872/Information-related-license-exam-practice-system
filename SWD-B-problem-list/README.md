# 電腦軟體設計乙級 練習題庫

本資料夾收錄 **電腦軟體設計乙級技術士**（勞動部勞動力發展署技能檢定）術科常見主題的練習題，每題附**參考解法**與**驗證過的測試資料**。

## 重要說明（請先閱讀）

- 乙級技術士的**官方術科試題屬於受版權保護的正式測驗題目**，本資料夾**並非**官方考題的重製，而是依照乙級術科**實際涵蓋的演算法主題**（數列、排序、搜尋、進制轉換、矩陣運算、數論、遞迴、字串處理、經典演算法等）自行編寫的**練習題**，用於在本系統中練習與自動判題。
- 若要準備正式考試，請至 [勞動部技能檢定中心](https://www.wdasec.gov.tw/) 取得官方試題與應檢資料。

## 解法語言為什麼是 Python？

- 乙級術科實際使用 **C / C++**。但這台開發環境**未安裝可用的 C/C++ 命令列編譯器**（無 g++；MSVC 命令列環境無法運作），而本系統的 C++ 判題預設也依賴 `g++`。
- 因此本題庫的參考解法以 **Python** 撰寫：本機的 Python 可正常執行、本系統的判題器支援 Python，且**每一題的解法都已實際執行**，其輸出即為題庫中的 `ExpectedOutput`，因此**解法與測試資料保證一致、可直接自動判題**。
- 若日後安裝好 C/C++ 編譯器，可再請我補上對應語言的解法版本。

## 檔案內容

| 檔案 | 說明 |
|------|------|
| `SWD-B-problems.csv` | 可直接匯入本系統的題庫檔（UTF-8，無 BOM），含**解法程式碼**。相同 `ProblemCode` 的列會合併成同一題。 |
| `SWBxx.txt` | 各題的人類可讀版本：題目敘述 + 參考解法 + 範例輸入 / 輸出。 |

共 **20 題、50 組測試資料**，難度分佈：簡單 8、中等 8、困難 4。

## 如何匯入本系統

1. 開啟應用程式，左側選單點選「匯入」。
2. 切換到「表單匯入」分頁。
3. 點「選擇 CSV / XLS / XLSX」，選擇本資料夾的 `SWD-B-problems.csv`。
4. 點「預覽 / 驗證」確認無誤後，點「匯入 / 更新」。

匯入後即可在「已載入題庫」與「題目」頁面看到 `ExamType = 軟設乙級` 的題目。
