電腦軟體設計乙級 練習題 SWB04  十進位轉二進位

難度：簡單

== 題目 ==
將一個非負十進位整數轉換為二進位字串。

輸入說明：一行一個非負整數 n (0<=n<=1000000000)。
輸出說明：n 的二進位表示 (n=0 輸出 0)。

== 參考解法 (Python) ==
n = int(input())
if n == 0:
    print('0')
else:
    r = ''
    while n > 0:
        r = str(n % 2) + r
        n //= 2
    print(r)

== 範例 1 輸入 ==
10
== 範例 1 輸出 ==
1010

== 範例 2 輸入 ==
0
== 範例 2 輸出 ==
0

== 範例 3 輸入 ==
255
== 範例 3 輸出 ==
11111111
