電腦軟體設計乙級 練習題 SWB18  約瑟夫問題

難度：困難

== 題目 ==
n 個人圍成一圈 (編號 1~n)，從第 1 人開始報數，每數到第 m 人就將其淘汰，直到全部淘汰。
輸出淘汰的順序。

輸入說明：一行兩個正整數 n 與 m。
輸出說明：一行，被淘汰者的編號順序，以空白分隔。

== 參考解法 (Python) ==
from collections import deque
n, m = map(int, input().split())
q = deque(range(1, n + 1))
order = []
while q:
    q.rotate(-(m - 1))
    order.append(q.popleft())
print(' '.join(map(str, order)))

== 範例 1 輸入 ==
7 3
== 範例 1 輸出 ==
3 6 2 7 5 1 4

== 範例 2 輸入 ==
5 2
== 範例 2 輸出 ==
2 4 1 5 3
