APCS 實作題 APCP009 質數判斷

難度：簡單
主題：數學/數論

== 題目 ==
給定一個整數 n，請判斷它是否為質數。

輸入說明：一行一個整數 n (2<=n<=10^6)。
輸出說明：若 n 為質數輸出「是質數」，否則輸出「不是質數」。

== 參考解法 (Python) ==
n = int(input())
is_prime = True
if n < 2:
    is_prime = False
else:
    i = 2
    while i * i <= n:
        if n % i == 0:
            is_prime = False
            break
        i += 1
print("是質數" if is_prime else "不是質數")

== 範例 1 輸入 ==
7
== 範例 1 輸出 ==
是質數

== 範例 2 輸入 ==
12
== 範例 2 輸出 ==
不是質數

== 範例 3 輸入 ==
2
== 範例 3 輸出 ==
是質數
