APCS 實作題 APCP014 找出陣列中第二大的值

難度：簡單
主題：陣列

== 題目 ==
給定一個長度為 n 的整數陣列（陣列中至少存在兩個相異值），請找出陣列中相異值裡第二大的值。

輸入說明：第一行一個正整數 n (2<=n<=1000)；第二行 n 個整數，以空白分隔。
輸出說明：一行，輸出第二大的相異值。

== 參考解法 (Python) ==
n = int(input())
arr = list(map(int, input().split()))
uniq = sorted(set(arr), reverse=True)
print(uniq[1])

== 範例 1 輸入 ==
5
5 3 9 9 1
== 範例 1 輸出 ==
5

== 範例 2 輸入 ==
4
2 2 2 7
== 範例 2 輸出 ==
2
