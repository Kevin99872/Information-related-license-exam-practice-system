APCS 實作題 APCP029 找出缺失的數字

難度：中等
主題：數學

== 題目 ==
有一個長度為 n 的整數陣列，其內容原本應為 1 到 n+1 之間所有整數，但其中恰好缺少一個數字。請找出這個缺失的數字。

輸入說明：第一行一個正整數 n (1<=n<=100000)，代表陣列長度；第二行 n 個相異整數，範圍在 1 到 n+1 之間。
輸出說明：一行，輸出缺失的數字。

== 參考解法 (Python) ==
n = int(input())
arr = list(map(int, input().split()))
total = (n + 1) * (n + 2) // 2
print(total - sum(arr))

== 範例 1 輸入 ==
4
1 2 4 5
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
1
2
== 範例 2 輸出 ==
1
