APCS 實作題 APCP007 成績等第判斷

難度：簡單
主題：條件判斷

== 題目 ==
給定 n 位學生的分數，請依下列規則判斷每位學生的等第：
分數 >= 90 為 A；分數 >= 80 為 B；分數 >= 70 為 C；分數 >= 60 為 D；其餘為 E。

輸入說明：第一行一個正整數 n (1<=n<=1000)；第二行 n 個整數分數 (0<=分數<=100)，以空白分隔。
輸出說明：共 n 行，依序輸出每位學生的等第。

== 參考解法 (Python) ==
n = int(input())
scores = list(map(int, input().split()))
for s in scores:
    if s >= 90:
        print("A")
    elif s >= 80:
        print("B")
    elif s >= 70:
        print("C")
    elif s >= 60:
        print("D")
    else:
        print("E")

== 範例 1 輸入 ==
3
95 82 55
== 範例 1 輸出 ==
A
B
E

== 範例 2 輸入 ==
2
60 59
== 範例 2 輸出 ==
D
E
