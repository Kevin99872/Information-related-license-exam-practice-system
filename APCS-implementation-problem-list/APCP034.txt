APCS 實作題 APCP034 字串字典序比較

難度：中等
主題：字串

== 題目 ==
給定兩個僅由小寫英文字母組成的字串 a 與 b，請比較兩者的字典序大小。

輸入說明：第一行字串 a；第二行字串 b（長度皆 1<=len<=1000）。
輸出說明：若 a 的字典序小於 b，輸出 "<"；若大於，輸出 ">"；若相等，輸出 "="。

== 參考解法 (Python) ==
a = input()
b = input()
if a < b:
    print("<")
elif a > b:
    print(">")
else:
    print("=")

== 範例 1 輸入 ==
apple
banana
== 範例 1 輸出 ==
<

== 範例 2 輸入 ==
zoo
zoo
== 範例 2 輸出 ==
=
