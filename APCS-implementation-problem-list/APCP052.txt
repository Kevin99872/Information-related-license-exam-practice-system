APCS 實作題 APCP052 二元樹前序與中序走訪

難度：困難
主題：樹/遞迴

== 題目 ==
有一棵以陣列表示的二元樹，共有 n 個位置（1-indexed），根節點位於位置 1，位置 i 的左子節點位於位置 2i、右子節點位於位置 2i+1。陣列中的值若為 0，代表該位置沒有節點。請使用遞迴，分別輸出此二元樹的前序走訪與中序走訪結果（不存在的位置不輸出）。

輸入說明：第一行一個正整數 n (1<=n<=1000)；第二行 n 個整數 a[1..n]（a[i]=0 表示該位置無節點；保證 a[1] != 0）。
輸出說明：共兩行：第一行輸出前序走訪結果，第二行輸出中序走訪結果，元素間以空白分隔。

== 參考解法 (Python) ==
import sys
sys.setrecursionlimit(10000)
n = int(input())
a = list(map(int, input().split()))

def preorder(i, out):
    if i > n or a[i - 1] == 0:
        return
    out.append(a[i - 1])
    preorder(2 * i, out)
    preorder(2 * i + 1, out)

def inorder(i, out):
    if i > n or a[i - 1] == 0:
        return
    inorder(2 * i, out)
    out.append(a[i - 1])
    inorder(2 * i + 1, out)

pre, ino = [], []
preorder(1, pre)
inorder(1, ino)
print(' '.join(map(str, pre)))
print(' '.join(map(str, ino)))

== 範例 1 輸入 ==
7
1 2 3 4 5 6 7
== 範例 1 輸出 ==
1 2 4 5 3 6 7
4 2 5 1 6 3 7

== 範例 2 輸入 ==
3
1 0 3
== 範例 2 輸出 ==
1 3
1 3
