APCS 實作題 APCP016 氣泡排序過程

難度：中等
主題：排序

== 題目 ==
給定一個長度為 n 的整數陣列，請使用氣泡排序（由小到大）將其排序，並依序印出每一輪排序後的陣列狀態，共 n-1 輪（每輪皆需輸出，即使該輪未發生交換）。

輸入說明：第一行一個正整數 n (2<=n<=100)；第二行 n 個整數，以空白分隔。
輸出說明：共 n-1 行，每行輸出該輪結束後的陣列內容，元素間以空白分隔。

== 參考解法 (Python) ==
n = int(input())
arr = list(map(int, input().split()))
lines = []
for i in range(n - 1):
    for j in range(n - 1 - i):
        if arr[j] > arr[j + 1]:
            arr[j], arr[j + 1] = arr[j + 1], arr[j]
    lines.append(' '.join(map(str, arr)))
print('\n'.join(lines))

== 範例 1 輸入 ==
4
4 3 2 1
== 範例 1 輸出 ==
3 2 1 4
2 1 3 4
1 2 3 4

== 範例 2 輸入 ==
3
1 2 3
== 範例 2 輸出 ==
1 2 3
1 2 3
