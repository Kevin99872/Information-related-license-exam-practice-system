APCS 實作題 APCP011 二維座標距離

難度：簡單
主題：數學

== 題目 ==
給定平面上兩個點的座標 (x1, y1) 與 (x2, y2)，請計算兩點之間的歐幾里得距離。

輸入說明：一行四個整數 x1 y1 x2 y2，以空白分隔（座標範圍 -10000<=值<=10000）。
輸出說明：一行，輸出兩點之間的距離，四捨五入至小數點後三位。

== 參考解法 (Python) ==
import math
x1, y1, x2, y2 = map(int, input().split())
d = math.sqrt((x1 - x2) ** 2 + (y1 - y2) ** 2)
print(f"{d:.3f}")

== 範例 1 輸入 ==
0 0 3 4
== 範例 1 輸出 ==
5.000

== 範例 2 輸入 ==
1 1 1 1
== 範例 2 輸出 ==
0.000
