APCS 實作題 APCP020 前綴和區間查詢

難度：中等
主題：前綴和

== 題目 ==
給定一個長度為 n 的整數陣列，以及 q 個區間查詢 (l, r)（1-indexed，包含兩端），請對每個查詢輸出該區間內所有元素的總和。

輸入說明：第一行一個正整數 n (1<=n<=100000)；第二行 n 個整數；第三行一個正整數 q (1<=q<=1000)；接下來 q 行，每行兩個整數 l r (1<=l<=r<=n)。
輸出說明：共 q 行，依序輸出每個查詢區間的總和。

== 參考解法 (Python) ==
n = int(input())
arr = list(map(int, input().split()))
prefix = [0] * (n + 1)
for i in range(n):
    prefix[i + 1] = prefix[i] + arr[i]
q = int(input())
out = []
for _ in range(q):
    l, r = map(int, input().split())
    out.append(str(prefix[r] - prefix[l - 1]))
print('\n'.join(out))

== 範例 1 輸入 ==
5
1 2 3 4 5
2
1 3
2 5
== 範例 1 輸出 ==
6
14

== 範例 2 輸入 ==
3
-1 -2 -3
1
1 3
== 範例 2 輸出 ==
-6
