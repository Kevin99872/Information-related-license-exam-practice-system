APCS 實作題 APCP022 滑動視窗最大和

難度：中等
主題：陣列/滑動視窗

== 題目 ==
給定一個長度為 n 的整數陣列與一個視窗大小 k，請找出所有長度為 k 的連續子陣列中，總和最大的那個。

輸入說明：第一行一個正整數 n (1<=n<=100000)；第二行 n 個整數；第三行一個正整數 k (1<=k<=n)。
輸出說明：一行，輸出長度為 k 的連續子陣列中的最大總和。

== 參考解法 (Python) ==
n = int(input())
arr = list(map(int, input().split()))
k = int(input())
window = sum(arr[:k])
best = window
for i in range(k, n):
    window += arr[i] - arr[i - k]
    best = max(best, window)
print(best)

== 範例 1 輸入 ==
5
2 1 5 1 3
2
== 範例 1 輸出 ==
6

== 範例 2 輸入 ==
4
-1 -2 -3 -4
1
== 範例 2 輸出 ==
-1
