APCS 實作題 APCP036 貪心活動選擇問題

難度：中等
主題：貪心

== 題目 ==
給定 n 個活動，每個活動有開始時間與結束時間，一個場地一次只能舉辦一個活動（活動之間不可時間重疊，但允許前一個活動結束時間等於下一個活動開始時間）。請問最多能舉辦幾個不重疊的活動。

輸入說明：第一行一個正整數 n (1<=n<=100000)；接下來 n 行，每行兩個整數 s e (0<=s<e<=10^9)，代表該活動的開始與結束時間。
輸出說明：一行，輸出最多可舉辦的不重疊活動數量。

== 參考解法 (Python) ==
n = int(input())
activities = []
for _ in range(n):
    s, e = map(int, input().split())
    activities.append((s, e))
activities.sort(key=lambda x: x[1])
count = 0
last_end = -1
for s, e in activities:
    if s >= last_end:
        count += 1
        last_end = e
print(count)

== 範例 1 輸入 ==
4
1 3
2 4
3 5
6 7
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
1
1 2
== 範例 2 輸出 ==
1
