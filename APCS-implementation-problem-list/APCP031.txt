APCS 實作題 APCP031 貪心找零錢

難度：中等
主題：貪心

== 題目 ==
假設硬幣的面額只有 1, 5, 10, 50 四種，請問要湊出金額 amount，最少需要幾枚硬幣（使用貪心法，由大面額硬幣優先使用即可得到最少枚數）。

輸入說明：一行一個非負整數 amount (0<=amount<=100000)。
輸出說明：一行，輸出所需的最少硬幣數。

== 參考解法 (Python) ==
amount = int(input())
coins = [50, 10, 5, 1]
count = 0
for c in coins:
    count += amount // c
    amount %= c
print(count)

== 範例 1 輸入 ==
88
== 範例 1 輸出 ==
8

== 範例 2 輸入 ==
0
== 範例 2 輸出 ==
0
