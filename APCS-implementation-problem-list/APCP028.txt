APCS 實作題 APCP028 合併兩個排序陣列

難度：中等
主題：陣列/合併

== 題目 ==
給定兩個已由小到大排序的整數陣列（長度可能為 0），請將它們合併為一個由小到大排序的陣列（保留重複值）。

輸入說明：第一行一個非負整數 n；第二行 n 個遞增整數（n 為 0 時此行可能為空行）；第三行一個非負整數 m；第四行 m 個遞增整數（m 為 0 時此行可能為空行）。
輸出說明：一行，輸出合併後由小到大排序的陣列，以空白分隔；若結果為空，輸出空行。

== 參考解法 (Python) ==
n = int(input())
a = list(map(int, input().split()))
m = int(input())
b = list(map(int, input().split()))
merged = []
i = j = 0
while i < n and j < m:
    if a[i] <= b[j]:
        merged.append(a[i])
        i += 1
    else:
        merged.append(b[j])
        j += 1
merged.extend(a[i:])
merged.extend(b[j:])
print(' '.join(map(str, merged)))

== 範例 1 輸入 ==
3
1 3 5
3
2 4 6
== 範例 1 輸出 ==
1 2 3 4 5 6

== 範例 2 輸入 ==
0

2
7 8
== 範例 2 輸出 ==
7 8
