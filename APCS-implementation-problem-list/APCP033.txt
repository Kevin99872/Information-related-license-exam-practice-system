APCS 實作題 APCP033 第 K 小的值

難度：中等
主題：排序/搜尋

== 題目 ==
給定一個長度為 n 的整數陣列與一個整數 k，請找出陣列由小到大排序後，第 k 個位置的值。

輸入說明：第一行一個正整數 n (1<=n<=100000)；第二行 n 個整數；第三行一個整數 k (1<=k<=n)。
輸出說明：一行，輸出排序後第 k 小的值。

== 參考解法 (Python) ==
n = int(input())
arr = list(map(int, input().split()))
k = int(input())
arr.sort()
print(arr[k - 1])

== 範例 1 輸入 ==
5
5 3 8 1 9
3
== 範例 1 輸出 ==
5

== 範例 2 輸入 ==
1
100
1
== 範例 2 輸出 ==
100
