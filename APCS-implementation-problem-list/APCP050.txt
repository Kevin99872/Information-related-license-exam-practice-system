APCS 實作題 APCP050 圖的二分圖判斷

難度：困難
主題：圖/BFS/DFS

== 題目 ==
給定一個含 n 個節點（編號 1 到 n）、m 條邊的無向圖，請使用 BFS（二著色法）判斷此圖是否為二分圖（即是否能將所有節點分成兩組，使得每條邊的兩端點分別屬於不同組）。圖不保證連通。

輸入說明：第一行兩個非負整數 n m (1<=n<=100000, 0<=m<=100000)；接下來 m 行，每行兩個整數 u v (1<=u,v<=n)，代表一條無向邊。
輸出說明：若此圖是二分圖，輸出 "Yes"；否則輸出 "No"。

== 參考解法 (Python) ==
from collections import deque
n, m = map(int, input().split())
adj = [[] for _ in range(n + 1)]
for _ in range(m):
    u, v = map(int, input().split())
    adj[u].append(v)
    adj[v].append(u)
color = [-1] * (n + 1)
is_bipartite = True
for start in range(1, n + 1):
    if color[start] != -1:
        continue
    color[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                is_bipartite = False
print("Yes" if is_bipartite else "No")

== 範例 1 輸入 ==
4 4
1 2
2 3
3 4
4 1
== 範例 1 輸出 ==
Yes

== 範例 2 輸入 ==
3 3
1 2
2 3
3 1
== 範例 2 輸出 ==
No
