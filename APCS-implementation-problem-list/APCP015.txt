APCS 實作題 APCP015 數字反轉

難度：簡單
主題：數學

== 題目 ==
給定一個整數 n（可能為負數），請將其數字部分反轉後輸出（負號維持在最前面；若反轉後出現前導零，則自動省略）。

輸入說明：一行一個整數 n (-10^9<=n<=10^9)。
輸出說明：一行，輸出反轉後的整數。

== 參考解法 (Python) ==
n = int(input())
sign = -1 if n < 0 else 1
n = abs(n)
rev = int(str(n)[::-1])
print(sign * rev)

== 範例 1 輸入 ==
1234
== 範例 1 輸出 ==
4321

== 範例 2 輸入 ==
-520
== 範例 2 輸出 ==
-25

== 範例 3 輸入 ==
100
== 範例 3 輸出 ==
1
