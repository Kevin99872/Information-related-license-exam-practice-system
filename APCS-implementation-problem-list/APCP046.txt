APCS 實作題 APCP046 動態規劃湊零錢（最少硬幣數）

難度：困難
主題：動態規劃

== 題目 ==
給定 n 種硬幣面額（不保證是常見面額組合）與一個目標金額 amount，每種硬幣可使用無限多次，請使用動態規劃求出湊出 amount 所需的最少硬幣數；若無法湊出，輸出 -1。

輸入說明：第一行一個非負整數 amount (0<=amount<=100000)；第二行一個正整數 n (1<=n<=50)，代表硬幣種類數；第三行 n 個正整數，代表各硬幣面額。
輸出說明：一行，輸出湊出 amount 所需的最少硬幣數；若無法湊出，輸出 -1。

== 參考解法 (Python) ==
amount = int(input())
n = int(input())
coins = list(map(int, input().split()))
INF = float('inf')
dp = [0] + [INF] * amount
for i in range(1, amount + 1):
    for c in coins:
        if c <= i and dp[i - c] + 1 < dp[i]:
            dp[i] = dp[i - c] + 1
print(dp[amount] if dp[amount] != INF else -1)

== 範例 1 輸入 ==
6
3
1 3 4
== 範例 1 輸出 ==
2

== 範例 2 輸入 ==
7
2
2 4
== 範例 2 輸出 ==
-1
