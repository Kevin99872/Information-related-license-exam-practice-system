APCS 實作題 APCP005 判斷回文字串

難度：簡單
主題：字串

== 題目 ==
給定一行不含空白字元的字串 s，請判斷它是否為回文字串（正著讀與反著讀相同）。

輸入說明：一行字串 s（僅含英文小寫字母，長度 1<=len(s)<=200）。
輸出說明：若為回文輸出「是」，否則輸出「否」。

== 參考解法 (Python) ==
s = input()
print("是" if s == s[::-1] else "否")

== 範例 1 輸入 ==
level
== 範例 1 輸出 ==
是

== 範例 2 輸入 ==
apcs
== 範例 2 輸出 ==
否

== 範例 3 輸入 ==
a
== 範例 3 輸出 ==
是
