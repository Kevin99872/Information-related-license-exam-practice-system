APCS 實作題 APCP006 攝氏轉華氏

難度：簡單
主題：數學

== 題目 ==
給定一個攝氏溫度 c，請將其轉換為華氏溫度。轉換公式為 F = C * 9 / 5 + 32。

輸入說明：一行一個實數 c，代表攝氏溫度。
輸出說明：一行，輸出對應的華氏溫度，四捨五入至小數點後一位。

== 參考解法 (Python) ==
c = float(input())
f = c * 9 / 5 + 32
print(f"{f:.1f}")

== 範例 1 輸入 ==
0
== 範例 1 輸出 ==
32.0

== 範例 2 輸入 ==
100
== 範例 2 輸出 ==
212.0

== 範例 3 輸入 ==
37.5
== 範例 3 輸出 ==
99.5
