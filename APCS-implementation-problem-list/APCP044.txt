APCS 實作題 APCP044 圖的最短路徑（Dijkstra）

難度：困難
主題：圖/最短路徑

== 題目 ==
給定一個含 n 個節點（編號 1 到 n）、m 條邊的無向加權圖（邊權皆為正整數），請使用 Dijkstra 演算法求出從節點 s 到節點 t 的最短距離；若不可達，輸出 -1。

輸入說明：第一行兩個正整數 n m (1<=n<=1000, 0<=m<=10000)；接下來 m 行，每行三個整數 u v w (1<=u,v<=n, 1<=w<=1000)，代表節點 u 與 v 之間有一條權重為 w 的無向邊；最後一行兩個整數 s t。
輸出說明：一行，輸出 s 到 t 的最短距離；若不可達，輸出 -1。

== 參考解法 (Python) ==
import heapq
n, m = map(int, input().split())
adj = [[] for _ in range(n + 1)]
for _ in range(m):
    u, v, w = map(int, input().split())
    adj[u].append((v, w))
    adj[v].append((u, w))
s, t = map(int, input().split())
INF = float('inf')
dist = [INF] * (n + 1)
dist[s] = 0
pq = [(0, s)]
while pq:
    d, u = heapq.heappop(pq)
    if d > dist[u]:
        continue
    for v, w in adj[u]:
        nd = d + w
        if nd < dist[v]:
            dist[v] = nd
            heapq.heappush(pq, (nd, v))
print(dist[t] if dist[t] != INF else -1)

== 範例 1 輸入 ==
4 4
1 2 1
2 3 2
1 3 4
3 4 1
1 4
== 範例 1 輸出 ==
4

== 範例 2 輸入 ==
3 1
1 2 5
1 3
== 範例 2 輸出 ==
-1
