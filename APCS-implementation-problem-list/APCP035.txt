APCS 實作題 APCP035 找出陣列中的峰值元素

難度：中等
主題：陣列

== 題目 ==
給定一個長度為 n 的整數陣列（相鄰元素皆不相等），峰值元素定義為比左右相鄰元素都大的元素（陣列頭尾的元素只需比唯一的相鄰元素大即可視為峰值）。請由左到右掃描，輸出第一個找到的峰值元素的索引（1-indexed）。

輸入說明：第一行一個正整數 n (1<=n<=100000)；第二行 n 個整數，相鄰元素皆不相等。
輸出說明：一行，輸出第一個峰值元素的索引。

== 參考解法 (Python) ==
n = int(input())
arr = list(map(int, input().split()))
for i in range(n):
    left_ok = (i == 0) or arr[i] > arr[i - 1]
    right_ok = (i == n - 1) or arr[i] > arr[i + 1]
    if left_ok and right_ok:
        print(i + 1)
        break

== 範例 1 輸入 ==
5
1 3 2 4 1
== 範例 1 輸出 ==
2

== 範例 2 輸入 ==
1
5
== 範例 2 輸出 ==
1
