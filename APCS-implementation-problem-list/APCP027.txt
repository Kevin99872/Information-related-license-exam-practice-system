APCS 實作題 APCP027 字串壓縮

難度：中等
主題：字串

== 題目 ==
給定一行僅由英文大寫字母組成的字串 s，請以「字元＋連續出現次數」的方式壓縮字串（即使某字元只連續出現一次，仍需輸出次數 1）。

輸入說明：一行字串 s（僅含英文大寫字母，長度 1<=len(s)<=1000）。
輸出說明：一行，輸出壓縮後的字串。

== 參考解法 (Python) ==
s = input()
res = []
i = 0
n = len(s)
while i < n:
    j = i
    while j < n and s[j] == s[i]:
        j += 1
    res.append(s[i] + str(j - i))
    i = j
print(''.join(res))

== 範例 1 輸入 ==
AAABCCDDDD
== 範例 1 輸出 ==
A3B1C2D4

== 範例 2 輸入 ==
A
== 範例 2 輸出 ==
A1
