APCS 實作題 APCP024 費氏數列（遞迴＋記憶化）

難度：中等
主題：遞迴

== 題目 ==
定義費氏數列 F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)（n>=2）。給定一個整數 n，請使用遞迴（搭配記憶化以避免重複計算）求出 F(n)。

輸入說明：一行一個整數 n (0<=n<=50)。
輸出說明：一行，輸出 F(n) 的值。

== 參考解法 (Python) ==
import sys
sys.setrecursionlimit(10000)
memo = {0: 0, 1: 1}
def fib(k):
    if k in memo:
        return memo[k]
    memo[k] = fib(k - 1) + fib(k - 2)
    return memo[k]
n = int(input())
print(fib(n))

== 範例 1 輸入 ==
10
== 範例 1 輸出 ==
55

== 範例 2 輸入 ==
0
== 範例 2 輸出 ==
0

== 範例 3 輸入 ==
50
== 範例 3 輸出 ==
12586269025
