APCS 實作題 APCP026 最長連續遞增子序列

難度：中等
主題：陣列

== 題目 ==
給定一個長度為 n 的整數陣列，請找出其中「連續」且嚴格遞增的最長子序列的長度。

輸入說明：第一行一個正整數 n (1<=n<=100000)；第二行 n 個整數。
輸出說明：一行，輸出最長連續嚴格遞增子序列的長度。

== 參考解法 (Python) ==
n = int(input())
arr = list(map(int, input().split()))
best = 1
cur = 1
for i in range(1, n):
    if arr[i] > arr[i - 1]:
        cur += 1
    else:
        cur = 1
    best = max(best, cur)
print(best)

== 範例 1 輸入 ==
6
1 2 2 3 4 1
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
1
5
== 範例 2 輸出 ==
1
