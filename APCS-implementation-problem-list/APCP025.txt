APCS 實作題 APCP025 質因數分解

難度：中等
主題：數學/數論

== 題目 ==
給定一個整數 n，請將其分解為質因數的乘積，並由小到大輸出所有質因數（重複的質因數需重複列出）。

輸入說明：一行一個整數 n (2<=n<=10^9)。
輸出說明：一行，輸出 n 的所有質因數，由小到大排列，以空白分隔。

== 參考解法 (Python) ==
n = int(input())
factors = []
d = 2
while d * d <= n:
    while n % d == 0:
        factors.append(d)
        n //= d
    d += 1
if n > 1:
    factors.append(n)
print(' '.join(map(str, factors)))

== 範例 1 輸入 ==
60
== 範例 1 輸出 ==
2 2 3 5

== 範例 2 輸入 ==
97
== 範例 2 輸出 ==
97
