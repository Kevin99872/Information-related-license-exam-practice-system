APCS 實作題 APCP051 逆序數計算（合併排序法）

難度：困難
主題：分治法

== 題目 ==
給定一個長度為 n 的整數陣列，對於任意 i < j，若 arr[i] > arr[j]，則稱 (i, j) 為一組逆序對。請使用分治法（合併排序）有效率地計算陣列中逆序對的總數。

輸入說明：第一行一個正整數 n (1<=n<=100000)；第二行 n 個整數。
輸出說明：一行，輸出逆序對的總數。

== 參考解法 (Python) ==
def merge_count(arr):
    n = len(arr)
    if n <= 1:
        return arr, 0
    mid = n // 2
    left, cnt_l = merge_count(arr[:mid])
    right, cnt_r = merge_count(arr[mid:])
    merged = []
    i = j = 0
    cnt = cnt_l + cnt_r
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            merged.append(left[i])
            i += 1
        else:
            merged.append(right[j])
            j += 1
            cnt += len(left) - i
    merged.extend(left[i:])
    merged.extend(right[j:])
    return merged, cnt

n = int(input())
arr = list(map(int, input().split()))
_, total = merge_count(arr)
print(total)

== 範例 1 輸入 ==
5
2 4 1 3 5
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
3
3 2 1
== 範例 2 輸出 ==
3
