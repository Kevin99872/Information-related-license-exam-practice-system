APCS 實作題 APCP039 最長共同子序列

難度：困難
主題：動態規劃

== 題目 ==
給定兩個僅由小寫英文字母組成的字串 a 與 b，請使用動態規劃求出兩字串的最長共同子序列（Longest Common Subsequence）的長度。

輸入說明：第一行字串 a；第二行字串 b（長度皆 0<=len<=200，可能為空字串）。
輸出說明：一行，輸出最長共同子序列的長度。

== 參考解法 (Python) ==
a = input()
b = input()
n, m = len(a), len(b)
dp = [[0] * (m + 1) for _ in range(n + 1)]
for i in range(1, n + 1):
    for j in range(1, m + 1):
        if a[i - 1] == b[j - 1]:
            dp[i][j] = dp[i - 1][j - 1] + 1
        else:
            dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
print(dp[n][m])

== 範例 1 輸入 ==
abcde
ace
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
abc
def
== 範例 2 輸出 ==
0
