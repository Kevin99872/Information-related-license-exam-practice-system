APCS 實作題 APCP003 計算奇偶數個數

難度：簡單
主題：陣列

== 題目 ==
給定一個長度為 n 的整數陣列，請計算其中奇數與偶數的個數。

輸入說明：第一行一個正整數 n (1<=n<=1000)；第二行 n 個整數，以空白分隔。
輸出說明：一行，依序輸出奇數個數與偶數個數，以空白分隔。

== 參考解法 (Python) ==
n = int(input())
arr = list(map(int, input().split()))
odd = sum(1 for x in arr if x % 2 != 0)
even = n - odd
print(odd, even)

== 範例 1 輸入 ==
5
1 2 3 4 5
== 範例 1 輸出 ==
3 2

== 範例 2 輸入 ==
3
2 4 6
== 範例 2 輸出 ==
0 3
