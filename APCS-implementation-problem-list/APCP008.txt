APCS 實作題 APCP008 最大公因數（輾轉相除法）

難度：簡單
主題：數學/數論

== 題目 ==
給定兩個正整數 a 與 b，請使用輾轉相除法計算兩數的最大公因數。

輸入說明：一行兩個正整數 a 與 b (1<=a,b<=10^6)，以空白分隔。
輸出說明：一行，輸出 a 與 b 的最大公因數。

== 參考解法 (Python) ==
a, b = map(int, input().split())
while b:
    a, b = b, a % b
print(a)

== 範例 1 輸入 ==
12 18
== 範例 1 輸出 ==
6

== 範例 2 輸入 ==
17 5
== 範例 2 輸出 ==
1
