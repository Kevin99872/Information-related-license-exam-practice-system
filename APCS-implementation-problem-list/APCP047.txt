APCS 實作題 APCP047 最大不相鄰子序列和

難度：困難
主題：動態規劃

== 題目 ==
給定一個長度為 n 的非負整數陣列，請從中挑選若干個「不相鄰」的元素（可以不挑選任何元素，此時總和為 0），使其總和最大，並輸出此最大總和。

輸入說明：第一行一個正整數 n (1<=n<=100000)；第二行 n 個非負整數 (0<=值<=1000)。
輸出說明：一行，輸出可達到的最大總和。

== 參考解法 (Python) ==
n = int(input())
arr = list(map(int, input().split()))
prev2 = 0
prev1 = 0
for i in range(n):
    cur = max(prev1, prev2 + arr[i])
    prev2 = prev1
    prev1 = cur
print(prev1)

== 範例 1 輸入 ==
5
3 2 5 10 7
== 範例 1 輸出 ==
15

== 範例 2 輸入 ==
1
0
== 範例 2 輸出 ==
0
