APCS 實作題 APCP010 陣列中特定值出現次數

難度：簡單
主題：陣列

== 題目 ==
給定一個長度為 n 的整數陣列，以及一個查詢值 x，請計算 x 在陣列中出現的次數。

輸入說明：第一行一個正整數 n (1<=n<=1000)；第二行 n 個整數，以空白分隔；第三行一個整數 x。
輸出說明：一行，輸出 x 在陣列中出現的次數。

== 參考解法 (Python) ==
n = int(input())
arr = list(map(int, input().split()))
x = int(input())
print(arr.count(x))

== 範例 1 輸入 ==
5
1 2 2 3 2
2
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
4
5 6 7 8
9
== 範例 2 輸出 ==
0
