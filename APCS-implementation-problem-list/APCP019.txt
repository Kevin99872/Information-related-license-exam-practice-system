APCS 實作題 APCP019 矩陣轉置

難度：中等
主題：二維陣列

== 題目 ==
給定一個 r 列 c 行的整數矩陣，請輸出其轉置矩陣（即 c 列 r 行，第 i 列第 j 行的元素等於原矩陣第 j 列第 i 行的元素）。

輸入說明：第一行兩個正整數 r c (1<=r,c<=100)；接下來 r 行，每行 c 個整數，以空白分隔。
輸出說明：共 c 行，每行 r 個整數，以空白分隔，代表轉置後的矩陣。

== 參考解法 (Python) ==
r, c = map(int, input().split())
mat = [list(map(int, input().split())) for _ in range(r)]
for j in range(c):
    print(' '.join(str(mat[i][j]) for i in range(r)))

== 範例 1 輸入 ==
2 3
1 2 3
4 5 6
== 範例 1 輸出 ==
1 4
2 5
3 6

== 範例 2 輸入 ==
1 1
5
== 範例 2 輸出 ==
5
