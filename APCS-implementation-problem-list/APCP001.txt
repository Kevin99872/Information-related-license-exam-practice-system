APCS 實作題 APCP001 陣列總和與平均

難度：簡單
主題：陣列

== 題目 ==
給定一個長度為 n 的整數陣列，請計算所有元素的總和與平均值。

輸入說明：第一行一個正整數 n (1<=n<=1000)；第二行 n 個整數，範圍在 -1000 到 1000 之間，以空白分隔。
輸出說明：一行，依序輸出總和與平均值（平均值四捨五入至小數點後兩位），以空白分隔。

== 參考解法 (Python) ==
n = int(input())
arr = list(map(int, input().split()))
s = sum(arr)
avg = s / n
print(f"{s} {avg:.2f}")

== 範例 1 輸入 ==
5
1 2 3 4 5
== 範例 1 輸出 ==
15 3.00

== 範例 2 輸入 ==
3
-1 0 1
== 範例 2 輸出 ==
0 0.00
