# APCS 實作題 練習題庫

本資料夾收錄 **APCS（大學程式先修檢測，Advanced Placement Computer Science，教育部委託國立臺灣師範大學資訊工程學系主辦）「實作題」** 的自製練習題，用於在本系統中練習與自動判題。

## 來源與說明

- APCS 官方會定期公開歷屆檢測的實作題全文供大眾練習，但正式考題屬於受保護的測驗題目。本資料夾**並非**任何一次正式檢測考題的重製或翻譯，而是依照 APCS 實作題**實際涵蓋的主題與命題風格**（陣列/字串基礎、模擬、排序/搜尋、雙指標、前綴和、遞迴、基礎動態規劃、圖形走訪 BFS/DFS、貪心、數學/數論、基礎樹狀結構等）**自行編寫的原創題目**，題目敘述、範例輸入輸出皆為新撰寫內容。
- 每題皆採用與官方 APCS 實作題相同的輸出入慣例：**由標準輸入 (stdin) 讀取資料、由標準輸出 (stdout) 印出答案**。
- 每題都附有**參考解法（Python）**，且每一筆範例的 `TestInput` / `ExpectedOutput` 皆已**實際執行參考解法驗證**，保證彼此一致、可直接用於本系統的自動判題。
- 難度分佈仿照 APCS 官方實作題四級評分的精神做簡化對應：簡單（約當第 1 級：基本輸出入與迴圈）、中等（約當第 2 級：陣列/字串/簡單演算法）、困難（約當第 3～4 級：遞迴、搜尋排序進階應用、基礎動態規劃、圖形演算法）。

> 若要準備正式 APCS 檢測，請至 [APCS 大學程式先修檢測官網](https://apcs.csie.ntnu.edu.tw/) 取得官方歷屆試題與檢測資訊。

## 檔案內容

| 檔案 | 說明 |
|------|------|
| `APCS-implementation-problems.csv` | 可直接匯入本系統的題庫檔（UTF-8，無 BOM），含**解法程式碼**。相同 `ProblemCode` 的列會合併成同一題。 |
| `APCPxxx.txt` | 各題的人類可讀版本：題目敘述 + 參考解法 (Python) + 範例輸入 / 輸出。 |

共 **52 題、114 組測試資料**，難度分佈：簡單 15、中等 22、困難 15。

## 如何匯入本系統

1. 開啟應用程式，左側選單點選「匯入」。
2. 切換到「表單匯入」分頁。
3. 點「選擇 CSV / XLS / XLSX」，選擇本資料夾的 `APCS-implementation-problems.csv`。
4. 點「預覽 / 驗證」確認無誤後，點「匯入 / 更新」。

匯入後即可在「已載入題庫」與「題目」頁面看到 `ExamType = APCS` 的題目。

若題庫內容有更新（新增或修改 `APCPxxx.txt`），可重新執行以下指令重新產生 CSV：

```bash
python3 scripts/generate_apcs_implementation_import_csv.py
```
