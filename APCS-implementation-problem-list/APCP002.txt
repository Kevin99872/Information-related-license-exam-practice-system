APCS 實作題 APCP002 找最大值與其位置

難度：簡單
主題：陣列

== 題目 ==
給定一個長度為 n 的整數陣列，請找出最大值以及它第一次出現的位置。

輸入說明：第一行一個正整數 n (1<=n<=1000)；第二行 n 個整數，以空白分隔。
輸出說明：一行，輸出最大值與其位置（位置從 1 開始計數；若最大值重複出現，取第一次出現的位置），以空白分隔。

== 參考解法 (Python) ==
n = int(input())
arr = list(map(int, input().split()))
mx = arr[0]
idx = 1
for i in range(1, n):
    if arr[i] > mx:
        mx = arr[i]
        idx = i + 1
print(mx, idx)

== 範例 1 輸入 ==
5
3 1 4 1 5
== 範例 1 輸出 ==
5 5

== 範例 2 輸入 ==
4
7 7 2 1
== 範例 2 輸出 ==
7 1
