APCS 實作題 APCP043 DFS 連通元件計數

難度：困難
主題：圖/DFS

== 題目 ==
給定一個含 n 個節點（編號 1 到 n）、m 條邊的無向圖，請使用 DFS 求出圖中連通元件（connected component）的個數。

輸入說明：第一行兩個非負整數 n m (1<=n<=100000, 0<=m<=100000)；接下來 m 行，每行兩個整數 u v (1<=u,v<=n)，代表一條無向邊。
輸出說明：一行，輸出連通元件的個數。

== 參考解法 (Python) ==
import sys
sys.setrecursionlimit(200000)
n, m = map(int, input().split())
adj = [[] for _ in range(n + 1)]
for _ in range(m):
    u, v = map(int, input().split())
    adj[u].append(v)
    adj[v].append(u)
visited = [False] * (n + 1)
def dfs(start):
    stack = [start]
    visited[start] = True
    while stack:
        node = stack.pop()
        for nxt in adj[node]:
            if not visited[nxt]:
                visited[nxt] = True
                stack.append(nxt)
count = 0
for i in range(1, n + 1):
    if not visited[i]:
        count += 1
        dfs(i)
print(count)

== 範例 1 輸入 ==
5 2
1 2
3 4
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
4 3
1 2
2 3
3 4
== 範例 2 輸出 ==
1
