TQC+ 程式語言Java JAD105  三科成績平均

難度：簡單
主題：格式化輸出

== 題目 ==
輸入三科成績（整數），計算平均分數，四捨五入至小數點後兩位輸出。

輸入說明：一行，三個整數，以空白分隔。
輸出說明：一行，格式為「平均 = xx.xx」。

== 參考解法 (Java) ==
import java.util.Locale;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int a = sc.nextInt();
        int b = sc.nextInt();
        int c = sc.nextInt();
        double avg = (a + b + c) / 3.0;
        System.out.printf(Locale.US, "平均 = %.2f%n", avg);
    }
}

== 範例 1 輸入 ==
80 90 100
== 範例 1 輸出 ==
平均 = 90.00

== 範例 2 輸入 ==
70 85 77
== 範例 2 輸出 ==
平均 = 77.33
