TQC+ 程式語言Java JAD203  成績等級判定

難度：簡單
主題：控制流程

== 題目 ==
輸入一個整數分數（0~100），依照範圍判定等級：90 分以上為 A，80~89 為 B，70~79 為 C，60~69 為 D，60 分以下為 E。

輸入說明：一行一個整數 score (0<=score<=100)。
輸出說明：一行，對應的等級字母。

== 參考解法 (Java) ==
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int score = sc.nextInt();
        String grade;
        if (score >= 90) {
            grade = "A";
        } else if (score >= 80) {
            grade = "B";
        } else if (score >= 70) {
            grade = "C";
        } else if (score >= 60) {
            grade = "D";
        } else {
            grade = "E";
        }
        System.out.println(grade);
    }
}

== 範例 1 輸入 ==
95
== 範例 1 輸出 ==
A

== 範例 2 輸入 ==
82
== 範例 2 輸出 ==
B

== 範例 3 輸入 ==
55
== 範例 3 輸出 ==
E
