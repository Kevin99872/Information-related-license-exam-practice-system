TQC+ 程式語言Java JAD407  陣列傳遞與方法

難度：中等
主題：方法

== 題目 ==
撰寫方法 sum(int[] arr) 回傳陣列總和，以及方法 average(int[] arr) 回傳陣列平均值，於 main 中呼叫並輸出結果。

輸入說明：第一行一個整數 n；第二行 n 個整數，以空白分隔。
輸出說明：一行，格式為「總和: x 平均: y.yy」（平均值取小數點後兩位）。

== 參考解法 (Java) ==
import java.util.Locale;
import java.util.Scanner;

public class Main {
    static int sum(int[] arr) {
        int total = 0;
        for (int v : arr) {
            total += v;
        }
        return total;
    }

    static double average(int[] arr) {
        return sum(arr) / (double) arr.length;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }
        System.out.printf(Locale.US, "總和: %d 平均: %.2f%n", sum(arr), average(arr));
    }
}

== 範例 1 輸入 ==
5
1 2 3 4 5
== 範例 1 輸出 ==
總和: 15 平均: 3.00

== 範例 2 輸入 ==
3
2 3 5
== 範例 2 輸出 ==
總和: 10 平均: 3.33
