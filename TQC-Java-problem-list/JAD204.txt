TQC+ 程式語言Java JAD204  陣列最大值與最小值

難度：中等
主題：陣列

== 題目 ==
輸入 n 個整數，輸出其中的最大值與最小值。

輸入說明：第一行一個整數 n；第二行 n 個整數，以空白分隔。
輸出說明：一行，格式為「最大值: x 最小值: y」。

== 參考解法 (Java) ==
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }
        int max = arr[0];
        int min = arr[0];
        for (int i = 1; i < n; i++) {
            if (arr[i] > max) {
                max = arr[i];
            }
            if (arr[i] < min) {
                min = arr[i];
            }
        }
        System.out.println("最大值: " + max + " 最小值: " + min);
    }
}

== 範例 1 輸入 ==
5
3 7 2 9 4
== 範例 1 輸出 ==
最大值: 9 最小值: 2

== 範例 2 輸入 ==
4
-3 -7 -2 -9
== 範例 2 輸出 ==
最大值: -2 最小值: -9
