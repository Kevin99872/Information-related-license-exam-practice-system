TQC+ 程式語言Java JAD205  陣列反轉輸出

難度：中等
主題：陣列

== 題目 ==
輸入 n 個整數，將陣列反轉後，於同一行以空白分隔輸出。

輸入說明：第一行一個整數 n；第二行 n 個整數，以空白分隔。
輸出說明：一行，反轉後的 n 個整數，以空白分隔。

== 參考解法 (Java) ==
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }
        StringBuilder sb = new StringBuilder();
        for (int i = n - 1; i >= 0; i--) {
            sb.append(arr[i]);
            if (i > 0) {
                sb.append(' ');
            }
        }
        System.out.println(sb.toString());
    }
}

== 範例 1 輸入 ==
5
1 2 3 4 5
== 範例 1 輸出 ==
5 4 3 2 1

== 範例 2 輸入 ==
3
10 20 30
== 範例 2 輸出 ==
30 20 10
