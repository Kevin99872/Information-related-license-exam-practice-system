TQC+ 程式語言Java JAD608  多重catch與finally

難度：困難
主題：例外處理

== 題目 ==
輸入一個陣列大小 n、n 個整數、一個索引 idx、以及一個除數 d，嘗試計算 arr[idx] / d。程式需依序處理可能發生的 ArrayIndexOutOfBoundsException（索引超出範圍）與 ArithmeticException（除以零），並在 finally 區塊輸出「執行結束」。

輸入說明：第一行一個整數 n；第二行 n 個整數，以空白分隔；第三行一個整數 idx；第四行一個整數 d。
輸出說明：兩行。第一行依情況輸出「結果: value」「錯誤: 索引超出範圍」或「錯誤: 除數為零」；第二行固定輸出「執行結束」。

== 參考解法 (Java) ==
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }
        int idx = sc.nextInt();
        int d = sc.nextInt();
        try {
            int value = arr[idx] / d;
            System.out.println("結果: " + value);
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("錯誤: 索引超出範圍");
        } catch (ArithmeticException e) {
            System.out.println("錯誤: 除數為零");
        } finally {
            System.out.println("執行結束");
        }
    }
}

== 範例 1 輸入 ==
3
1 2 3
1
0
== 範例 1 輸出 ==
錯誤: 除數為零
執行結束

== 範例 2 輸入 ==
3
1 2 3
5
2
== 範例 2 輸出 ==
錯誤: 索引超出範圍
執行結束

== 範例 3 輸入 ==
3
6 9 12
2
3
== 範例 3 輸出 ==
結果: 4
執行結束
