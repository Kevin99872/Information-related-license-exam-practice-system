TQC+ 程式語言Java JAD107  消費金額千分位輸出

難度：中等
主題：格式化輸出

== 題目 ==
輸入購買數量與單價，計算總金額，並以千分位符號、小數點後兩位的格式輸出。

輸入說明：一行，數量（整數）與單價（浮點數），以空白分隔。
輸出說明：一行，格式為「總金額: $x,xxx.xx」。

== 參考解法 (Java) ==
import java.util.Locale;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int qty = sc.nextInt();
        double price = sc.nextDouble();
        double total = qty * price;
        System.out.printf(Locale.US, "總金額: $%,.2f%n", total);
    }
}

== 範例 1 輸入 ==
3 199.5
== 範例 1 輸出 ==
總金額: $598.50

== 範例 2 輸入 ==
1000 12.5
== 範例 2 輸出 ==
總金額: $12,500.00
