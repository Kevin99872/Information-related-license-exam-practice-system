TQC+ 程式語言Java JAD106  九九乘法表單列

難度：簡單
主題：格式化輸出

== 題目 ==
輸入一個整數 n (1<=n<=9)，輸出 n 的乘法表，從 n*1 到 n*9。

輸入說明：一行一個整數 n。
輸出說明：九行，每行格式為「n * i = 結果」，i 由 1 到 9。

== 參考解法 (Java) ==
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        for (int i = 1; i <= 9; i++) {
            System.out.println(n + " * " + i + " = " + (n * i));
        }
    }
}

== 範例 1 輸入 ==
3
== 範例 1 輸出 ==
3 * 1 = 3
3 * 2 = 6
3 * 3 = 9
3 * 4 = 12
3 * 5 = 15
3 * 6 = 18
3 * 7 = 21
3 * 8 = 24
3 * 9 = 27
