TQC+ 程式語言Java JAD605  ArrayList基本操作

難度：中等
主題：集合

== 題目 ==
輸入 n 個整數，依序加入 ArrayList&lt;Integer&gt;，計算並輸出這些元素的總和與最大值。

輸入說明：第一行一個整數 n；第二行 n 個整數，以空白分隔。
輸出說明：一行，格式為「總和: x 最大值: y」。

== 參考解法 (Java) ==
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        List<Integer> list = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            list.add(sc.nextInt());
        }
        int sum = 0;
        int max = list.get(0);
        for (int v : list) {
            sum += v;
            if (v > max) {
                max = v;
            }
        }
        System.out.println("總和: " + sum + " 最大值: " + max);
    }
}

== 範例 1 輸入 ==
4
3 7 1 9
== 範例 1 輸出 ==
總和: 20 最大值: 9

== 範例 2 輸入 ==
3
-1 -5 -2
== 範例 2 輸出 ==
總和: -8 最大值: -1
