TQC+ 程式語言Java JAD402  方法多載計算面積

難度：簡單
主題：方法

== 題目 ==
撰寫兩個同名方法 area：一個接受一個參數（正方形邊長）回傳正方形面積，另一個接受兩個參數（矩形的長與寬）回傳矩形面積，利用方法多載（Overload）實作。

輸入說明：第一行一個整數 k（1 或 2，代表接下來參數的個數）；第二行 k 個整數，以空白分隔。當 k=1 時為正方形邊長；當 k=2 時為矩形的長與寬。
輸出說明：一行，計算出的面積。

== 參考解法 (Java) ==
import java.util.Scanner;

public class Main {
    static int area(int side) {
        return side * side;
    }

    static int area(int length, int width) {
        return length * width;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int k = sc.nextInt();
        if (k == 1) {
            int side = sc.nextInt();
            System.out.println(area(side));
        } else {
            int length = sc.nextInt();
            int width = sc.nextInt();
            System.out.println(area(length, width));
        }
    }
}

== 範例 1 輸入 ==
1
5
== 範例 1 輸出 ==
25

== 範例 2 輸入 ==
2
4 6
== 範例 2 輸出 ==
24
