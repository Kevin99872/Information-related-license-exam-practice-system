TQC+ 程式語言Java JAD104  個人資料輸出

難度：簡單
主題：格式化輸出

== 題目 ==
輸入姓名與年齡，輸出一句自我介紹。

輸入說明：一行，姓名與年齡以空白分隔（姓名不含空白）。
輸出說明：一行，格式為「我是 姓名，今年 年齡 歲。」。

== 參考解法 (Java) ==
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String name = sc.next();
        int age = sc.nextInt();
        System.out.println("我是 " + name + "，今年 " + age + " 歲。");
    }
}

== 範例 1 輸入 ==
小明 20
== 範例 1 輸出 ==
我是 小明，今年 20 歲。

== 範例 2 輸入 ==
Amy 17
== 範例 2 輸出 ==
我是 Amy，今年 17 歲。
