TQC+ 程式語言Java JAD509  泛型堆疊類別

難度：困難
主題：物件導向

== 題目 ==
自行實作一個簡單的泛型堆疊類別 MyStack&lt;T&gt;（可用 ArrayList 實作），支援 push(T)、pop()、isEmpty() 等操作。依序執行輸入的操作，每次 pop 時輸出彈出的值；若堆疊已空則輸出「empty」。

輸入說明：第一行一個整數 m，代表操作數量；接下來 m 行，每行為「push x」（x 為整數）或「pop」。
輸出說明：對於每個 pop 操作輸出一行結果（彈出的值，或 empty）。

== 參考解法 (Java) ==
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Main {
    static class MyStack<T> {
        private final List<T> data = new ArrayList<>();

        void push(T value) {
            data.add(value);
        }

        T pop() {
            if (isEmpty()) {
                return null;
            }
            return data.remove(data.size() - 1);
        }

        boolean isEmpty() {
            return data.isEmpty();
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        MyStack<Integer> stack = new MyStack<>();
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < m; i++) {
            String op = sc.next();
            if (op.equals("push")) {
                int x = sc.nextInt();
                stack.push(x);
            } else {
                if (stack.isEmpty()) {
                    sb.append("empty").append('\n');
                } else {
                    sb.append(stack.pop()).append('\n');
                }
            }
        }
        System.out.print(sb.toString());
    }
}

== 範例 1 輸入 ==
5
push 1
push 2
pop
push 3
pop
== 範例 1 輸出 ==
2
3

== 範例 2 輸入 ==
3
pop
push 5
pop
== 範例 2 輸出 ==
empty
5
