TQC+ 程式語言Java JAD404  遞迴計算費氏數

難度：中等
主題：方法

== 題目 ==
撰寫一個遞迴方法計算費氏數列的第 n 項（F1=1, F2=1, Fn=Fn-1+Fn-2）。

輸入說明：一行一個整數 n (1<=n<=30)。
輸出說明：一行，第 n 個費氏數。

== 參考解法 (Java) ==
import java.util.Scanner;

public class Main {
    static long fib(int n) {
        if (n <= 2) {
            return 1;
        }
        return fib(n - 1) + fib(n - 2);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        System.out.println(fib(n));
    }
}

== 範例 1 輸入 ==
6
== 範例 1 輸出 ==
8

== 範例 2 輸入 ==
1
== 範例 2 輸出 ==
1

== 範例 3 輸入 ==
10
== 範例 3 輸出 ==
55
