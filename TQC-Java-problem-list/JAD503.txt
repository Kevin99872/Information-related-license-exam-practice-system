TQC+ 程式語言Java JAD503  介面實作：可比較的箱子

難度：中等
主題：物件導向

== 題目 ==
定義類別 Box，含欄位 length、width、height，並實作 Comparable&lt;Box&gt; 介面，依體積（長 x 寬 x 高）由小到大比較大小。輸入 n 個 Box 的長寬高，排序後依序輸出各箱子的體積。

輸入說明：第一行一個整數 n；接下來 n 行，每行三個整數，代表長、寬、高。
輸出說明：n 行，排序後（體積由小到大）各箱子的體積。

== 參考解法 (Java) ==
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.Scanner;

public class Main {
    static class Box implements Comparable<Box> {
        int length, width, height;

        Box(int length, int width, int height) {
            this.length = length;
            this.width = width;
            this.height = height;
        }

        int volume() {
            return length * width * height;
        }

        @Override
        public int compareTo(Box other) {
            return this.volume() - other.volume();
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        List<Box> boxes = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            int l = sc.nextInt();
            int w = sc.nextInt();
            int h = sc.nextInt();
            boxes.add(new Box(l, w, h));
        }
        Collections.sort(boxes);
        for (Box b : boxes) {
            System.out.println(b.volume());
        }
    }
}

== 範例 1 輸入 ==
3

== 範例 2 輸入 ==
