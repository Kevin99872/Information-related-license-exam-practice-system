# TQC+ 程式語言認證 Java 練習題庫

本資料夾收錄 **TQC+ 程式設計能力認證（Java）** 常見主題的練習題，每題附**參考解法**與**驗證過的測試資料**。

## 重要說明（請先閱讀）

- TQC+（財團法人中華民國電腦技能基金會）的**官方認證試題屬於受版權保護的正式測驗題目**，本資料夾**並非**官方考題的重製或翻譯，而是依照 TQC+ Java /一般 Java 基礎能力認證**實際涵蓋的技能主題**（主控台輸入輸出與格式化輸出、控制流程、陣列、字串處理、方法與多載、物件導向、例外處理、集合與 Stream 等）**自行編寫**的原創練習題，用於在本系統中練習與自動判題。題目敘述、範例與參考解法皆為原創撰寫，未參照或抄錄任何官方試題文字。
- 若要準備正式認證考試，請洽 [中華民國電腦技能基金會 TQC+ 認證中心](https://www.tqc.org.tw/) 取得官方試題與應檢資料。

## 檔案內容

| 檔案 | 說明 |
|------|------|
| `TQC-Java-problems.csv` | 可直接匯入本系統的題庫檔（UTF-8，無 BOM），含**解法程式碼**。相同 `ProblemCode` 的列會合併成同一題。 |
| `JADxxx.txt` | 各題的人類可讀版本：題目敘述 + 參考解法（Java）+ 範例輸入 / 輸出。 |

共 **54 題、120 組測試資料**，難度分佈：簡單 17 題、中等 24 題、困難 13 題。

每一題的參考解法皆已使用 OpenJDK（`javac` / `java`）**實際編譯並執行過**，其標準輸出即為題庫中的 `ExpectedOutput`，因此解法與測試資料保證一致、可直接自動判題。所有解法皆使用 `public class Main` 作為主類別名稱，方便本系統以單一編譯流程統一判題。

## 如何匯入本系統

1. 開啟應用程式，左側選單點選「匯入」。
2. 切換到「表單匯入」分頁。
3. 點「選擇 CSV / XLS / XLSX」，選擇本資料夾的 `TQC-Java-problems.csv`。
4. 點「預覽 / 驗證」確認無誤後，點「匯入 / 更新」。

匯入後即可在「已載入題庫」與「題目」頁面看到 `ExamType = TQC`、`SolutionLanguage = Java` 的題目（目前本系統尚未區分 Java 子分類，與既有 TQC Python 題庫共用同一 `ExamType`，屬預期行為）。

## 重新產生 CSV

若修改了 `JADxxx.txt`，可重新執行以下指令重新解析並驗證整個題庫（需要本機已安裝 `javac` / `java`）：

```bash
python3 scripts/generate_tqc_java_import_csv.py
```

此腳本會先逐題編譯 / 執行每個範例並比對輸出，成功後才寫出 `TQC-Java-problems.csv`，最後再讀取 CSV 內容重新編譯 / 執行一次做最終驗證，任何一筆不通過都會讓腳本以非零狀態結束。
