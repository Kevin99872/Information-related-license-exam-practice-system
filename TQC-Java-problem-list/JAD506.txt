TQC+ 程式語言Java JAD506  多型陣列與面積總計

難度：困難
主題：物件導向

== 題目 ==
沿用抽象類別 Shape（含抽象方法 getArea()）與子類別 Circle、Square。輸入 n 筆圖形資料（可能混合圓形與正方形），計算所有圖形的面積總和（圓周率使用 3.14159，取小數點後兩位）。

輸入說明：第一行一個整數 n；接下來 n 行，每行為「circle 半徑」或「square 邊長」。
輸出說明：一行，格式為「總面積: xx.xx」。

== 參考解法 (Java) ==
import java.util.Locale;
import java.util.Scanner;

public class Main {
    abstract static class Shape {
        abstract double getArea();
    }

    static class Circle extends Shape {
        double radius;

        Circle(double radius) {
            this.radius = radius;
        }

        @Override
        double getArea() {
            return 3.14159 * radius * radius;
        }
    }

    static class Square extends Shape {
        double side;

        Square(double side) {
            this.side = side;
        }

        @Override
        double getArea() {
            return side * side;
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        Shape[] shapes = new Shape[n];
        for (int i = 0; i < n; i++) {
            String kind = sc.next();
            double value = sc.nextDouble();
            if (kind.equals("circle")) {
                shapes[i] = new Circle(value);
            } else {
                shapes[i] = new Square(value);
            }
        }
        double total = 0;
        for (Shape s : shapes) {
            total += s.getArea();
        }
        System.out.printf(Locale.US, "總面積: %.2f%n", total);
    }
}

== 範例 1 輸入 ==
2
circle 1
square 2
== 範例 1 輸出 ==
總面積: 7.14

== 範例 2 輸入 ==
3
square 1
square 2
circle 2
== 範例 2 輸出 ==
總面積: 17.57
