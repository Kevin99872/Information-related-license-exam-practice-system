TQC+ 程式語言Java JAD207  陣列去重計數

難度：中等
主題：陣列

== 題目 ==
輸入 n 個整數，計算其中不重複的元素個數。

輸入說明：第一行一個整數 n；第二行 n 個整數，以空白分隔。
輸出說明：一行，格式為「不重複元素個數: x」。

== 參考解法 (Java) ==
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }
        int count = 0;
        for (int i = 0; i < n; i++) {
            boolean seenBefore = false;
            for (int j = 0; j < i; j++) {
                if (arr[j] == arr[i]) {
                    seenBefore = true;
                    break;
                }
            }
            if (!seenBefore) {
                count++;
            }
        }
        System.out.println("不重複元素個數: " + count);
    }
}

== 範例 1 輸入 ==
6
1 2 2 3 3 3
== 範例 1 輸出 ==
不重複元素個數: 3

== 範例 2 輸入 ==
5
4 4 4 4 4
== 範例 2 輸出 ==
不重複元素個數: 1
