APCS 觀念題 APCC027 內層迴圈範圍與複雜度分析

難度：困難
主題：時間複雜度

== 題目 ==
下列程式的時間複雜度（以 n 表示輸入規模）為何？

    for i in range(n):
        for j in range(i, n):
            print(i, j)

(A) O(n)
(B) O(n log n)
(C) O(n^2)
(D) O(n^3)

== 正解 ==
C

== 解析 ==
內層迴圈執行次數依 i 而不同，總執行次數為 n+(n-1)+...+1 = n(n+1)/2，這是 n 的二次多項式，時間複雜度仍為 O(n^2)。
