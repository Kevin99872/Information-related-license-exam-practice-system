APCS 觀念題 APCC015 遞迴計算最大公因數追蹤

難度：困難
主題：遞迴追蹤

== 題目 ==
下列輾轉相除法（歐幾里得演算法）的遞迴函式，執行 gcd(48, 18) 後回傳值為何？

    def gcd(a, b):
        if b == 0:
            return a
        return gcd(b, a % b)

    print(gcd(48, 18))

(A) 3
(B) 6
(C) 9
(D) 18

== 正解 ==
B

== 解析 ==
gcd(48,18)=gcd(18, 48%18=12)=gcd(12, 18%12=6)=gcd(6, 12%6=0)=6，因此結果為 6。
