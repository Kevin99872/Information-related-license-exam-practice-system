APCS 觀念題 APCC016 遞迴呼叫次數計算

難度：困難
主題：遞迴追蹤

== 題目 ==
下列函式沒有使用備忘（memoization），是最原始的雙重遞迴寫法。執行 f(4) 時，函式 f 總共被呼叫幾次（包含最外層呼叫本身）？

    def f(n):
        if n <= 1:
            return 1
        return f(n - 1) + f(n - 2)

    f(4)

(A) 5
(B) 7
(C) 15
(D) 9

== 正解 ==
D

== 解析 ==
設呼叫次數為 c(n)：c(0)=c(1)=1，c(n)=1+c(n-1)+c(n-2)。可得 c(2)=3, c(3)=5, c(4)=1+c(3)+c(2)=1+5+3=9。這也說明未優化的雙重遞迴呼叫次數會隨 n 呈指數成長。
