APCS 觀念題 APCC019 排序與切片組合追蹤

難度：中等
主題：陣列運算

== 題目 ==
下列程式執行後，會輸出什麼？

    a = [3, 1, 4, 1, 5, 9, 2, 6]
    b = sorted(a, reverse=True)[:3]
    print(b)

(A) [9, 6, 5]
(B) [1, 1, 2]
(C) [3, 1, 4]
(D) [9, 5, 6]

== 正解 ==
A

== 解析 ==
sorted(a, reverse=True) 會把 a 由大到小排序得到 [9,6,5,4,3,2,1,1]，取前 3 個即為 [9,6,5]。
