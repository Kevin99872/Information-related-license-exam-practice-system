APCS 觀念題 APCC056 動態規劃改善遞迴效率

難度：困難
主題：演算法設計

== 題目 ==
計算費氏數列 fib(n) 時，若使用最原始的雙重遞迴（如 fib(n)=fib(n-1)+fib(n-2)）會有大量重複計算，時間複雜度為指數等級 O(2^n)。若改用動態規劃（DP），將每個 fib(k) 的計算結果儲存起來，之後直接查表使用，可以將時間複雜度改善為何？

(A) O(1)
(B) O(n)
(C) O(n log n)
(D) O(2^n)，與原本相同，DP 無法改善

== 正解 ==
B

== 解析 ==
DP 的核心概念是「用空間換取時間」：把每個子問題 fib(k) 的結果存下來，之后需要用到相同子問題時直接查表，不必重複計算。費氏數列共有 n 個不同的子問題，每個只需計算一次，因此時間複雜度可降為 O(n)。
