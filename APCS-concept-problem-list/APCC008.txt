APCS 觀念題 APCC008 遞迴呼叫順序與輸出追蹤

難度：困難
主題：遞迴追蹤

== 題目 ==
下列程式執行 f(3) 後，依序會印出哪些數字？（每個數字之間以空白分隔）

    def f(n):
        if n == 0:
            return
        print(n, end=' ')
        f(n - 1)
        print(-n, end=' ')

    f(3)

(A) 3 2 1 -1 -2 -3
(B) 3 2 1 -3 -2 -1
(C) -1 -2 -3 1 2 3
(D) 1 2 3 -1 -2 -3

== 正解 ==
A

== 解析 ==
f(3) 先印出 3，遞迴呼叫 f(2)（印出 2，再呼叫 f(1) 印出 1，呼叫 f(0) 直接返回），f(1) 返回後印出 -1，f(2) 返回後印出 -2，f(3) 返回前印出 -3。順序為：3 2 1 -1 -2 -3。
