APCS 觀念題 APCC004 陣列單趟比較交換追蹤

難度：中等
主題：陣列運算

== 題目 ==
下列程式對陣列做「單一趟」相鄰比較交換（只執行一次由左到右的掃描），執行後 a 的內容為何？

    a = [3, 7, 1, 9, 4]
    for i in range(len(a) - 1):
        if a[i] > a[i + 1]:
            a[i], a[i + 1] = a[i + 1], a[i]
    print(a)

(A) [1, 3, 4, 7, 9]
(B) [9, 7, 4, 3, 1]
(C) [3, 7, 1, 9, 4]
(D) [3, 1, 7, 4, 9]

== 正解 ==
D

== 解析 ==
逐一比較相鄰元素：(3,7)不換、(7,1)互換得[3,1,7,9,4]、(7,9)不換、(9,4)互換得[3,1,7,4,9]。這只是氣泡排序的「一趟」，陣列尚未完全排序。
