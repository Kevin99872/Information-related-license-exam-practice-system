APCS 觀念題 APCC023 陣列旋轉切片組合追蹤

難度：中等
主題：陣列運算

== 題目 ==
下列程式利用切片將陣列向左旋轉 k 個位置，執行後 a 的內容為何？

    a = [1, 2, 3, 4, 5]
    k = 2
    a = a[k:] + a[:k]
    print(a)

(A) [4, 5, 1, 2, 3]
(B) [3, 4, 5, 1, 2]
(C) [1, 2, 3, 4, 5]
(D) [2, 3, 4, 5, 1]

== 正解 ==
B

== 解析 ==
a[k:] 取出索引 2 之後的部分 [3,4,5]，a[:k] 取出前 2 個 [1,2]，兩者相接得到 [3,4,5,1,2]，即整個陣列向左旋轉 2 格的結果。
