APCS 觀念題 APCC007 遞迴費氏數列追蹤

難度：中等
主題：遞迴追蹤

== 題目 ==
下列遞迴函式執行 fib(6) 後，回傳值為何？

    def fib(n):
        if n <= 1:
            return n
        return fib(n - 1) + fib(n - 2)

    print(fib(6))

(A) 8
(B) 6
(C) 5
(D) 13

== 正解 ==
A

== 解析 ==
費氏數列 fib(0)=0, fib(1)=1, fib(2)=1, fib(3)=2, fib(4)=3, fib(5)=5, fib(6)=fib(5)+fib(4)=5+3=8。
