APCS 觀念題 APCC022 佇列運算追蹤

難度：簡單
主題：資料結構

== 題目 ==
下列程式模擬佇列（queue，先進先出）操作，list 的 append 為加入尾端、pop(0) 為移除並取出最前端元素。執行後 queue 的內容為何？

    queue = [1, 2, 3]
    queue.append(4)
    queue.pop(0)
    queue.append(5)
    print(queue)

(A) [1, 2, 3, 4, 5]
(B) [2, 3, 4]
(C) [5, 4, 3, 2]
(D) [2, 3, 4, 5]

== 正解 ==
D

== 解析 ==
append(4) 後為 [1,2,3,4]；pop(0) 移除最前端的 1，變成 [2,3,4]；再 append(5) 得到 [2,3,4,5]，符合先進先出的佇列行為。
