APCS 觀念題 APCC012 雙指標反轉陣列追蹤

難度：中等
主題：陣列運算

== 題目 ==
下列程式使用雙指標交換法，執行後 a 的內容為何？

    a = [1, 2, 3, 4, 5]
    left, right = 0, len(a) - 1
    while left < right:
        a[left], a[right] = a[right], a[left]
        left += 1
        right -= 1
    print(a)

(A) [5, 4, 3, 2, 1]
(B) [1, 2, 3, 4, 5]
(C) [5, 1, 3, 4, 2]
(D) [2, 1, 3, 5, 4]

== 正解 ==
A

== 解析 ==
雙指標由兩端向中間交換，效果就是把整個陣列反轉，結果為 [5, 4, 3, 2, 1]。
