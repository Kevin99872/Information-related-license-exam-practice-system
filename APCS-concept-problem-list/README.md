# APCS 觀念題（大學程式設計先修檢測）練習題庫

本資料夾收錄 **APCS（大學程式設計先修檢測，Advanced Placement Computer Science，教育部委託國立臺灣師範大學資訊工程學系辦理）觀念題**風格的練習題，共 **57 題**選擇題。

## 來源與說明

- APCS 觀念題屬於**正式檢定的題目**，官方會將歷屆試題公開釋出供大眾練習，但那些題目文字**受版權保護**，不宜直接重製、收錄於第三方系統中。
- 本資料夾中的題目**全部為原創撰寫**，並非任何一屆 APCS 觀念題的重製或翻譯，而是依照 APCS 觀念題**實際涵蓋的主題與命題風格**（見下方主題分佈）自行設計、撰寫。
- 若要準備正式 APCS 檢定，請至 [APCS 大學程式設計先修檢測官網](https://apcs.csie.ntnu.edu.tw/) 取得官方歷屆試題與相關資訊。

### 主題涵蓋範圍

依照真實 APCS 觀念題的命題重點，本題庫涵蓋：

- **程式碼追蹤／輸出預測**（最常見的題型，約佔全題庫 40% 以上）：迴圈、陣列、字串、遞迴、二維陣列、堆疊／佇列操作等程式片段的追蹤
- 時間複雜度（Big-O）分析
- 資料結構觀念（堆疊、佇列、鏈結串列、二元樹、圖形的儲存方式）
- 排序與搜尋演算法的行為與效率比較
- 遞迴觀念（終止條件、呼叫次數、呼叫順序）
- 布林邏輯與位元運算
- 數字系統與進位轉換（二進位／十六進位／二補數）
- 圖形走訪（DFS / BFS 走訪順序）
- 演算法設計思維（貪心法 vs. 動態規劃）

每一題程式碼追蹤題目的「正解」都經過**實際以 Python 執行驗證**（或透過等價的計算手動核對），確保 `ExpectedOutput` 對應的選項正確無誤。

## 選擇題如何塞進本系統的「程式碼判題」schema？（重要，維護者必讀）

本系統的 `Problem` schema（`ProblemCode, ExamType, Title, Description, Difficulty, Status, SolutionLanguage, SolutionCode, OrderIndex, IsExample, TestInput, ExpectedOutput`）**原生只支援「寫程式、跑出正確輸出」的題目，沒有選擇題型別**。本題庫用以下方式改造 schema 來承載選擇題，因此看起來會跟 CPE / TQC / SWD-B 等其他題庫不太一樣：

| 欄位 | 用法 | 原因 |
|------|------|------|
| `Description` | 題目情境／程式碼片段（若有）＋ `(A)`～`(D)` 四個選項的完整文字 | 學生會看到的題目內容，**不含正解與解析**，避免看到 Description 就等於看到答案 |
| `SolutionLanguage` | 固定為 `Python` | 判題器支援 Python |
| `SolutionCode` | 一行 Python，例如 `print("C")` | 「參考解」直接印出正確選項字母，讓判題器可以用跑程式的方式驗證 |
| `TestInput` | 固定為 `-`（一個無意義的佔位字元，**不可為空字串**） | 本系統的匯入驗證（`ProblemImportService.ValidateSpreadsheetRow`）會把 `TestInput` 為空白視為 **Error** 而整列拒絕匯入；但這裡的 `SolutionCode` 完全不會讀取任何輸入（`print("C")` 不吃 stdin），所以填什麼值都不影響判題正確性，只是用來滿足「欄位不可為空」的匯入前提 |
| `ExpectedOutput` | 正確選項字母，例如 `C` | 學生提交的程式只要印出正確字母（如 `print("C")`）就算對 |
| `IsExample` | 固定為 `False` | 這是刻意偏離其他題庫（那些題庫多半 `IsExample=True`，把測資當作「範例」直接顯示給學生看）。這裡若設成 `True`，等於把正確答案當「範例輸出」秀給學生看，直接洩題；設成 `False` 讓它維持為「隱藏測資」，程式判題邏輯照常運作，但答案不會被顯示出來 |
| `OrderIndex` | 固定為 `0` | 每題選擇題只對應「一筆」測資（不像其他題庫一題可能有多組範例輸入輸出） |

換句話說：學生在系統中看到的是「題目 + (A)(B)(C)(D) 選項」（`Description`），他要做的事情等同於寫一支印出正確字母的程式（例如 `print("C")`）並送出評測；系統跑他的程式、拿輸出跟 `ExpectedOutput` 比對，藉此達到「批改選擇題」的效果。

人類可讀的 `.txt` 原始檔則額外保留 `== 正解 ==` 與 `== 解析 ==` 兩個區段，方便日後維護者或人工複審時對照答案與理由；這兩個區段**不會**被匯入 CSV 的 `Description` 欄位（由 `scripts/generate_apcs_concept_import_csv.py` 明確排除），避免洩題。

## 檔案內容

| 檔案 | 說明 |
|------|------|
| `APCS-concept-problems.csv` | 可直接匯入本系統的題庫檔（UTF-8，無 BOM）。每一列即為一題（一筆測資）。 |
| `APCCxxx.txt` | 各題的人類可讀版本：難度／主題／題目與選項／正解／解析。 |

共 **57 題**，難度分佈：簡單 17、中等 25、困難 15（約 30% / 44% / 26%）。四個選項作為正解的分佈大致平均（A 15、B 14、C 14、D 14），避免答案集中在特定字母造成「猜題」漏洞。

## 如何匯入本系統

1. 開啟應用程式，左側選單點選「匯入」。
2. 切換到「表單匯入」分頁。
3. 點「選擇 CSV / XLS / XLSX」，選擇本資料夾的 `APCS-concept-problems.csv`。
4. 點「預覽 / 驗證」確認無誤後，點「匯入 / 更新」。

匯入後即可在「已載入題庫」與「題目」頁面看到 `ExamType = APCS` 的題目。學生作答時會看到題目與四個選項（`Description`），只要提交一支印出正確字母的程式（如 `print("C")`）即可通過判題。

## 如何重新產生 CSV

若修改或新增了 `APCCxxx.txt`，執行以下指令重新產生 `APCS-concept-problems.csv`：

```
python3 scripts/generate_apcs_concept_import_csv.py
```

腳本會解析每個 `APCCxxx.txt` 的 `== 題目 ==` 到 `== 正解 ==` 之間的內容作為 `Description`（已排除 `== 正解 ==` 與 `== 解析 ==` 區段），並自動填入 `SolutionCode`、`ExpectedOutput`、固定欄位（`TestInput="-"`、`IsExample=False`、`OrderIndex=0` 等），同時會檢查 `Description` 是否不慎包含「正解」或「解析」字樣以防洩題。
