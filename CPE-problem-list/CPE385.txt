CPE Rotting Oranges

難度：中等
來源：原創（多源 BFS：柑橘腐爛時間模擬）

== 題目 ==
給定 R*C 網格，0 表示空格、1 表示新鮮柑橘、2 表示腐爛柑橘。每分鐘，腐爛柑橘會使上下左右相鄰的新鮮柑橘也腐爛，求所有新鮮柑橘都腐爛所需的最少分鐘數；若有新鮮柑橘永遠無法腐爛則輸出 -1。

輸入說明：每組第一行 R C，接著 R 行each C 個以空白分隔的整數 (0/1/2)。R=0 且 C=0 表示輸入結束。
輸出說明：每組輸出所需的最少分鐘數，或 -1。

== 參考解法 (Python) ==
import sys
from collections import deque

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        r, c = map(int, line.split())
        if r == 0 and c == 0:
            break
        grid = []
        for _ in range(r):
            grid.append(list(map(int, data[idx].split())))
            idx += 1
        q = deque()
        fresh = 0
        for i in range(r):
            for j in range(c):
                if grid[i][j] == 2:
                    q.append((i, j, 0))
                elif grid[i][j] == 1:
                    fresh += 1
        minutes = 0
        while q:
            x, y, t = q.popleft()
            minutes = max(minutes, t)
            for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                nx, ny = x + dx, y + dy
                if 0 <= nx < r and 0 <= ny < c and grid[nx][ny] == 1:
                    grid[nx][ny] = 2
                    fresh -= 1
                    q.append((nx, ny, t + 1))
        out.append(str(minutes) if fresh == 0 else '-1')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3 3
2 1 1
1 1 0
0 1 1
0 0
== 範例 1 輸出 ==
4

== 範例 2 輸入 ==
1 2
1 0
0 0
== 範例 2 輸出 ==
-1
