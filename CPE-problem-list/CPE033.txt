== 題目 ==
定義函式 M(n)：若 n>100，M(n)=n-10；否則 M(n)=M(M(n+11))。給定整數 n，求 M(n) 的值。

輸入說明：每行一個整數 n (-2000000000<=n<=2147483647)，以單獨一行 -99999999 結束 (不處理)。
輸出說明：每行輸出 M(n) 的值。

== 參考解法 (Python) ==
import sys

def m91(n):
    if n > 100:
        return n - 10
    return 91

for line in sys.stdin:
    line = line.strip()
    if not line:
        continue
    n = int(line)
    if n == -99999999:
        break
    print(m91(n))

== 範例 1 輸入 ==
1
100
101
-99999999
== 範例 1 輸出 ==
91
91
91

== 範例 2 輸入 ==

-99999999
== 範例 2 輸出 ==
