CPE BST Insert and Inorder Traversal

難度：簡單
來源：原創（二元搜尋樹建立與中序走訪）

== 題目 ==
依序將 n 個數字插入一棵二元搜尋樹 (BST)，然後輸出中序走訪的結果 (中序走訪一棵 BST 會得到由小到大排序的結果)。

輸入說明：每組第一行 n，第二行 n 個整數 (插入順序，數字不重複)。n=0 表示輸入結束。
輸出說明：每組輸出中序走訪結果 (以空白分隔)。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        vals = [int(data[idx + i]) for i in range(n)]
        idx += n
        tree = {}
        root = None
        for v in vals:
            if root is None:
                root = v
                tree[v] = [None, None]
                continue
            node = root
            while True:
                if v < node:
                    if tree[node][0] is None:
                        tree[node][0] = v
                        tree[v] = [None, None]
                        break
                    node = tree[node][0]
                else:
                    if tree[node][1] is None:
                        tree[node][1] = v
                        tree[v] = [None, None]
                        break
                    node = tree[node][1]
        result = []

        def inorder(node):
            if node is None:
                return
            inorder(tree[node][0])
            result.append(node)
            inorder(tree[node][1])

        inorder(root)
        out.append(' '.join(map(str, result)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
5 3 8 1 4
0
== 範例 1 輸出 ==
1 3 4 5 8

== 範例 2 輸入 ==
3
2 1 3
0
== 範例 2 輸出 ==
1 2 3
