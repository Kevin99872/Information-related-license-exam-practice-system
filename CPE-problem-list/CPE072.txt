CPE 10415 Eb Alto Saxophone Player

難度：中等
來源：改編自 UVa Online Judge #10415 (CPE 大學程式能力檢定經典題)

== 題目 ==
薩克斯風每個音符需要按住特定手指組合的按鍵：
c: 2,3,4,7,8,9,10  d: 2,3,4,7,8,9  e: 2,3,4,7,8  f: 2,3,4,7  g: 2,3,4  a: 2,3  b: 2
C: 3  D: 1,2,3,4,7,8,9  E: 1,2,3,4,7,8  F: 1,2,3,4,7  G: 1,2,3,4  A: 1,2,3  B: 1,2

若某手指在目前音符需要用到、但在「上一個音符」沒有用到 (或此為第一個音符)，則該手指需要「按一次」。求整首曲子中每根手指總共按了幾次。

輸入說明：第一行為測試個數 t (1<=t<=1000)；之後每行一首曲子 (由上述字母組成，最多 200 個音符，可能為空)。
輸出說明：每行輸出 10 個數字，依序為手指 1~10 的按鍵次數，以空白分隔。

== 參考解法 (Python) ==
import sys

NOTE_FINGERS = {
    'c': {2,3,4,7,8,9,10}, 'd': {2,3,4,7,8,9}, 'e': {2,3,4,7,8}, 'f': {2,3,4,7},
    'g': {2,3,4}, 'a': {2,3}, 'b': {2}, 'C': {3}, 'D': {1,2,3,4,7,8,9},
    'E': {1,2,3,4,7,8}, 'F': {1,2,3,4,7}, 'G': {1,2,3,4}, 'A': {1,2,3}, 'B': {1,2},
}

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    while data[idx].strip() == '':
        idx += 1
    t = int(data[idx].strip()); idx += 1
    out = []
    for _ in range(t):
        song = data[idx].strip() if idx < len(data) else ''
        idx += 1
        counts = [0] * 11
        prev = set()
        for note in song:
            cur = NOTE_FINGERS.get(note, set())
            for finger in cur - prev:
                counts[finger] += 1
            prev = cur
        out.append(' '.join(str(counts[i]) for i in range(1, 11)))
    print('\n'.join(out))

main()
