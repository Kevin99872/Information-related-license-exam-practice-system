CPE Find Minimum in Rotated Sorted Array

難度：中等
來源：原創（二分搜尋：旋轉排序陣列的最小值）

== 題目 ==
給定一個原本嚴格遞增、但經過循環旋轉的陣列 (元素不重複)，用二分搜尋法 (O(log n)) 求陣列中的最小值。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出最小值。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        lo, hi = 0, n - 1
        while lo < hi:
            mid = (lo + hi) // 2
            if a[mid] > a[hi]:
                lo = mid + 1
            else:
                hi = mid
        out.append(str(a[lo]))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
3 4 5 1 2
0
== 範例 1 輸出 ==
1

== 範例 2 輸入 ==
4
4 5 6 7
0
== 範例 2 輸出 ==
4
