CPE Z-Algorithm Pattern Count

難度：中等
來源：原創（Z 演算法 (Z-Function) 字串比對）

== 題目 ==
給定文字 text 與樣式 pattern，使用 Z 演算法計算 pattern 在 text 中出現的次數 (可重疊)。

輸入說明：每行兩個以空白分隔的字串 text pattern，讀到檔案結尾。
輸出說明：每行輸出出現次數。

== 參考解法 (Python) ==
import sys

def z_function(s):
    n = len(s)
    z = [0] * n
    l = r = 0
    for i in range(1, n):
        if i < r:
            z[i] = min(r - i, z[i - l])
        while i + z[i] < n and s[z[i]] == s[i + z[i]]:
            z[i] += 1
        if i + z[i] > r:
            l, r = i, i + z[i]
    return z

def main():
    out = []
    for line in sys.stdin:
        line = line.rstrip('\n')
        if not line:
            continue
        text, pattern = line.split()
        combined = pattern + '#' + text
        z = z_function(combined)
        count = sum(1 for v in z[len(pattern) + 1:] if v >= len(pattern))
        out.append(str(count))
    print('\n'.join(out))

main()

== 範例 2 輸出 ==
