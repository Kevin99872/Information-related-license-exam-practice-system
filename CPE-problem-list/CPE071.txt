CPE 10409 Die Game

難度：中等
來源：改編自 UVa Online Judge #10409 (CPE 大學程式能力檢定經典題)

== 題目 ==
一顆骰子初始時頂面朝上為 1、北面為 2、西面為 3 (相對兩面數字和為 7)。骰子依指令 "north"/"south"/"east"/"west" 朝該方向翻滾 90 度 (繞底部該側的邊翻轉)。求執行完一連串指令後，頂面的數字。

輸入說明：每組資料第一行為指令數 k (<=1024)；之後 k 行每行一個指令。k=0 表示輸入結束。
輸出說明：每組輸出翻滾結束後頂面的數字。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        k = int(data[idx]); idx += 1
        if k == 0:
            break
        top, north, east = 1, 2, 4
        for i in range(k):
            cmd = data[idx + i]
            if cmd == 'north':
                top, north = 7 - north, top
            elif cmd == 'south':
                top, north = north, 7 - top
            elif cmd == 'east':
                top, east = 7 - east, top
            elif cmd == 'west':
                top, east = east, 7 - top
        idx += k
        out.append(str(top))
    print('\n'.join(out))

main()

5
