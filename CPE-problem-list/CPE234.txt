CPE Longest Wiggle Subsequence

難度：中等
來源：原創（動態規劃：最長擺動子序列）

== 題目 ==
擺動序列是指相鄰元素的差值正負號交替變化的序列。給定 n 個整數，求其最長擺動子序列的長度。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出最長擺動子序列長度。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        if n == 1:
            out.append('1')
            continue
        up = down = 1
        for i in range(1, n):
            if a[i] > a[i - 1]:
                up = down + 1
            elif a[i] < a[i - 1]:
                down = up + 1
        out.append(str(max(up, down)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
6
1 7 4 9 2 5
0
== 範例 1 輸出 ==
6

== 範例 2 輸入 ==
4
1 2 3 4
0
== 範例 2 輸出 ==
2
