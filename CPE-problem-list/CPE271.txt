CPE Quick Sort Comparison Count

難度：中等
來源：原創（快速排序法比較次數）

== 題目 ==
給定 n 個整數，使用快速排序法 (每次選最後一個元素為 pivot) 排序，求排序過程中總共執行了幾次元素比較。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出比較次數。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        count = [0]

        def quicksort(lo, hi):
            if lo >= hi:
                return
            pivot = a[hi]
            i = lo
            for j in range(lo, hi):
                count[0] += 1
                if a[j] < pivot:
                    a[i], a[j] = a[j], a[i]
                    i += 1
            a[i], a[hi] = a[hi], a[i]
            quicksort(lo, i - 1)
            quicksort(i + 1, hi)

        quicksort(0, n - 1)
        out.append(str(count[0]))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
5 4 3 2 1
0
== 範例 1 輸出 ==
10

== 範例 2 輸入 ==
4
1 2 3 4
0
== 範例 2 輸出 ==
6
