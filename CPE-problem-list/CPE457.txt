CPE Dijkstra 最短路徑還原

難度：中等
來源：原創（最短路徑演算法，附路徑還原）

== 題目 ==
給定一個 n 個節點（編號 0 到 n-1）、m 條邊的無向帶權圖，邊權皆為正整數。
給定起點 src 與終點 dst，請求出從 src 到 dst 的最短距離，並輸出其中一條最短路徑（節點序列）。

輸入格式：第一行為 n m src dst（n=0 且 m=0 且 src=0 且 dst=0 代表輸入結束）；接下來 m 行each 為 u v w，
代表節點 u 與 v 之間有一條權重為 w 的邊。

對每組測試資料：若 dst 不可達，輸出 -1；否則輸出兩行，第一行為最短距離，第二行為路徑上的節點序列（以空白分隔，從 src 到 dst）。

== 參考解法 (Python) ==
import sys
import heapq

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); m = int(data[idx + 1]); src = int(data[idx + 2]); dst = int(data[idx + 3]); idx += 4
        if n == 0 and m == 0 and src == 0 and dst == 0:
            break
        adj = [[] for _ in range(n)]
        for _ in range(m):
            u = int(data[idx]); v = int(data[idx + 1]); w = int(data[idx + 2]); idx += 3
            adj[u].append((v, w))
            adj[v].append((u, w))
        INF = float('inf')
        dist = [INF] * n
        parent = [-1] * n
        dist[src] = 0
        pq = [(0, src)]
        while pq:
            d, u = heapq.heappop(pq)
            if d > dist[u]:
                continue
            for v, w in adj[u]:
                if d + w < dist[v]:
                    dist[v] = d + w
                    parent[v] = u
                    heapq.heappush(pq, (dist[v], v))
        if dist[dst] == INF:
            out.append('-1')
        else:
            path = []
            cur = dst
            while cur != -1:
                path.append(cur)
                cur = parent[cur]
            path.reverse()
            out.append(str(dist[dst]))
            out.append(' '.join(map(str, path)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5 6 0 4
0 1 2
0 2 5
1 2 1
1 3 4
2 3 1
3 4 3
== 範例 1 輸出 ==
7
0 1 2 3 4

== 範例 2 輸入 ==
3 1 0 2
0 1 1
== 範例 2 輸出 ==
