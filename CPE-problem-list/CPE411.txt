CPE Coin Change with Reconstruction

難度：中等
來源：原創（動態規劃：找零錢還原所用硬幣）

== 題目 ==
給定 n 種硬幣面額 (可無限使用) 與目標金額 target，求湊出 target 所需的最少硬幣數，並輸出所使用的硬幣清單；若無法湊出則輸出 -1。

輸入說明：每組第一行 n target，第二行 n 個正整數面額。n=0 且 target=0 表示輸入結束。
輸出說明：每組輸出最少硬幣數與所用硬幣清單 (以空白分隔)；若無解僅輸出 -1。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); target = int(data[idx + 1]); idx += 2
        if n == 0 and target == 0:
            break
        coins = [int(data[idx + i]) for i in range(n)]
        idx += n
        INF = float('inf')
        dp = [0] + [INF] * target
        choice = [-1] * (target + 1)
        for i in range(1, target + 1):
            for c in coins:
                if c <= i and dp[i - c] + 1 < dp[i]:
                    dp[i] = dp[i - c] + 1
                    choice[i] = c
        if dp[target] == INF:
            out.append('-1')
        else:
            result = []
            cur = target
            while cur > 0:
                result.append(choice[cur])
                cur -= choice[cur]
            out.append(str(len(result)))
            out.append(' '.join(map(str, result)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3 11
1 2 5
0 0
== 範例 1 輸出 ==
3
1 5 5

== 範例 2 輸入 ==
1 3
2
0 0
== 範例 2 輸出 ==
-1
