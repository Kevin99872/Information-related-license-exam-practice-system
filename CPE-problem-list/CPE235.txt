CPE Remove Duplicates from Sorted Array

難度：簡單
來源：原創（雙指標：移除已排序陣列中的重複元素）

== 題目 ==
給定一個已由小到大排序的陣列，移除重複元素 (每個相異值只保留一個)，保持原本的相對順序。

輸入說明：每組第一行 n，第二行 n 個已排序整數。n=0 表示輸入結束。
輸出說明：每組輸出去除重複後的陣列 (以空白分隔)。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        result = []
        for x in a:
            if not result or result[-1] != x:
                result.append(x)
        out.append(' '.join(map(str, result)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
7
1 1 2 2 2 3 4
0
== 範例 1 輸出 ==
1 2 3 4

== 範例 2 輸入 ==
3
1 2 3
0
== 範例 2 輸出 ==
1 2 3
