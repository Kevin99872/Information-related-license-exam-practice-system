CPE Word Break

難度：中等
來源：原創（動態規劃：單字拆解判斷）

== 題目 ==
給定一個字串 s 與一個字典 (m 個單字)，判斷 s 是否可以拆解成字典中的單字依序串接而成 (單字可重複使用)。

輸入說明：每組第一行為字串 s，第二行為字典大小 m，接著 m 行each 一個字典單字，直到出現單獨一行 "#" 為止 (不處理)。
輸出說明：每組輸出 Yes 或 No。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        if line == '#':
            break
        s = line
        m = int(data[idx].strip()); idx += 1
        words = set(data[idx + i].strip() for i in range(m))
        idx += m
        n = len(s)
        dp = [False] * (n + 1)
        dp[0] = True
        for i in range(1, n + 1):
            for j in range(i):
                if dp[j] and s[j:i] in words:
                    dp[i] = True
                    break
        out.append('Yes' if dp[n] else 'No')
    print('\n'.join(out))

main()
