CPE 11054 Wine trading in Gergovia

難度：簡單
來源：改編自 UVa Online Judge #11054 (CPE 大學程式能力檢定經典題)

== 題目 ==
一條街上有 n 戶人家，每戶要買入或賣出若干瓶酒 (正數表示要買、負數表示要賣，總和保證為 0)。運送一瓶酒到相鄰房子需要 1 單位工作量。求完成所有交易所需的最少總工作量。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出最少總工作量。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        total = 0
        cur = 0
        for x in a[:-1]:
            cur += x
            total += abs(cur)
        out.append(str(total))
    print('\n'.join(out))

main()

== 範例 1 輸出 ==
9
9000

== 範例 2 輸入 ==

== 範例 2 輸出 ==
