CPE Palindrome Partitioning (List All Ways)

難度：中等
來源：原創（回溯法：列出所有回文分割方式）

== 題目 ==
給定一個字串，列出所有能將其切割成「每段皆為回文」的分割方式。

輸入說明：每行一個字串，讀到檔案結尾。
輸出說明：每行輸入先輸出分割方式總數，接著每行輸出一種分割方式 (各段以 '|' 相連)。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        s = line.strip()
        if not s:
            continue
        results = []

        def backtrack(start, path):
            if start == len(s):
                results.append('|'.join(path))
                return
            for end in range(start + 1, len(s) + 1):
                piece = s[start:end]
                if piece == piece[::-1]:
                    path.append(piece)
                    backtrack(end, path)
                    path.pop()

        backtrack(0, [])
        out.append(str(len(results)))
        out.extend(results)
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
aab
== 範例 1 輸出 ==
2
a|a|b
aa|b

== 範例 2 輸入 ==
aba
== 範例 2 輸出 ==
2
a|b|a
aba
