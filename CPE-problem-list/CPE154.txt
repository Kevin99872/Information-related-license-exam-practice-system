CPE 400 Unix ls

難度：困難
來源：改編自 UVa Online Judge #400 (CPE 大學程式能力檢定經典題)

== 題目 ==
模擬 Unix 的 ls 指令格式化輸出。給定 N 個檔名，將其依 ASCII 字元順序由小到大排序後，排列成多欄顯示：欄寬由「最長檔名長度」決定 — 最右邊那欄寬度恰為最長檔名長度，其餘各欄寬度為最長檔名長度+2 (左靠齊)；在 60 字元的寬度限制內盡量塞入最多欄數；接著用最少的列數由左到右、由上到下排滿 (即先塞滿第一欄由上到下，再塞第二欄，以此類推)。

輸入說明：多組資料，每組第一行為檔名數 N (1<=N<=100)，接著 N 行each 一個檔名 (1~60 字元，只含英數字與 . _ -)。讀到檔案結尾。
輸出說明：每組先輸出一行 60 個 '-'，接著輸出排版後的檔名列表。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip()
        if line == '':
            idx += 1
            continue
        n = int(line); idx += 1
        names = []
        for _ in range(n):
            names.append(data[idx]); idx += 1
        names.sort()
        maxlen = max(len(x) for x in names)
        col_width = maxlen + 2
        cols = 1 + (60 - maxlen) // col_width
        if cols < 1:
            cols = 1
        rows = (n + cols - 1) // cols
        out.append('-' * 60)
        for r in range(rows):
            parts = []
            for c in range(cols):
                i = c * rows + r
                if i < n:
                    name = names[i]
                    parts.append(name if c == cols - 1 else name.ljust(col_width))
            out.append(''.join(parts))
    print('\n'.join(out))

main()
