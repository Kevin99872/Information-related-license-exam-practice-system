CPE 299 Train Swapping

難度：中等
來源：改編自 UVa Online Judge #299 (CPE 大學程式能力檢定經典題)

== 題目 ==
給定一列火車車廂目前的排列順序（1~L 的一個排列），每次只能交換「相鄰」的兩節車廂，求把車廂排成 1,2,...,L 由小到大順序所需的最少交換次數。

輸入說明：第一行為測試case數 N。每個 case 兩行：第一行為車廂數 L (0<=L<=50)；第二行為 1~L 的排列。
輸出說明：每個 case 輸出一行 "Optimal train swapping takes S swaps."，S 為最少交換次數。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    t = int(data[idx]); idx += 1
    out = []
    for _ in range(t):
        l = int(data[idx]); idx += 1
        arr = [int(data[idx + i]) for i in range(l)]
        idx += l
        swaps = 0
        for i in range(l):
            for j in range(l - 1 - i):
                if arr[j] > arr[j + 1]:
                    arr[j], arr[j + 1] = arr[j + 1], arr[j]
                    swaps += 1
        out.append(f"Optimal train swapping takes {swaps} swaps.")
    print('\n'.join(out))

main()
