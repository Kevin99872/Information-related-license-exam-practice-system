CPE 10193 All You Need Is Love

難度：中等
來源：改編自 UVa Online Judge #10193 (CPE 大學程式能力檢定經典題)

== 題目 ==
給定兩個二進位字串 S1、S2 (皆合法：無前導 0，且長度至少 2)，判斷是否存在一個合法的二進位字串 L，使得 S1 與 S2 都可以透過「不斷減去 L」剛好減到 L (也就是 S1、S2 都是 L 的正整數倍)。

可以證明：這樣的 L 存在，若且唯若把 S1、S2 視為整數的最大公因數 gcd(S1,S2) 轉成二進位後長度至少為 2 (也就是 gcd>=2)。

輸入說明：第一行為測試個數 N (N<10000)，之後每兩行一組，分別是 S1、S2。
輸出說明：每組輸出 "Pair #p: All you need is love!" 或 "Pair #p: Love is not all you need!"，p 從 1 開始。

== 參考解法 (Python) ==
import sys
import math

def main():
    data = sys.stdin.read().split()
    idx = 0
    n = int(data[idx]); idx += 1
    out = []
    for p in range(1, n + 1):
        s1 = data[idx]; s2 = data[idx + 1]; idx += 2
        g = math.gcd(int(s1, 2), int(s2, 2))
        if g >= 2:
            out.append(f"Pair #{p}: All you need is love!")
        else:
            out.append(f"Pair #{p}: Love is not all you need!")
    print('\n'.join(out))

main()
