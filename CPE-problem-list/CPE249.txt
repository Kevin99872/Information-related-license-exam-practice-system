CPE Count Set Bits in Range

難度：簡單
來源：原創（位元運算：區間內 1 的總個數）

== 題目 ==
給定區間 [a,b]，求此區間內所有整數的二進位表示中，「1」出現的總次數。

輸入說明：每行兩個整數 a b (0<=a<=b<=10^6)，讀到檔案結尾。
輸出說明：每行輸出 1 出現的總次數。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        a, b = map(int, line.split())
        out.append(str(sum(bin(x).count('1') for x in range(a, b + 1))))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
1 5
0 0
== 範例 1 輸出 ==
7
0

== 範例 2 輸入 ==
1 10
== 範例 2 輸出 ==
17
