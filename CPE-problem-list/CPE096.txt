CPE Kth Largest Element

難度：簡單
來源：原創（第 K 大元素查詢）

== 題目 ==
給定 n 個整數與 k，求第 k 大的元素 (由大到小排序後第 k 個)。

輸入說明：每組第一行 n k，第二行 n 個整數。n=0 且 k=0 表示輸入結束。
輸出說明：每組輸出第 k 大的元素。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); k = int(data[idx + 1]); idx += 2
        if n == 0:
            break
        nums = [int(data[idx + i]) for i in range(n)]
        idx += n
        nums.sort(reverse=True)
        out.append(str(nums[k - 1]))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
6 2
3 1 4 1 5 9
0 0
== 範例 1 輸出 ==
5

== 範例 2 輸入 ==
5 5
7 7 7 7 7
0 0
== 範例 2 輸出 ==
7
