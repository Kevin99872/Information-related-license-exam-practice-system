CPE Count Complete Tree Nodes

難度：簡單
來源：原創（二元樹節點總數計算）

== 題目 ==
給定一棵二元樹 (陣列表示，節點 0 為根，left[i]/right[i] 為左右子節點索引，-1 表示不存在)，求樹中節點總數。

輸入說明：每組第一行 n，接著 n 行each 兩個整數 (節點 0~n-1 依序的 left、right)。n=0 表示輸入結束。
輸出說明：每組輸出節點總數。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        left, right = [], []
        for _ in range(n):
            left.append(int(data[idx])); right.append(int(data[idx + 1])); idx += 2

        def count(u):
            if u == -1:
                return 0
            return 1 + count(left[u]) + count(right[u])

        out.append(str(count(0)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
1 2
3 4
-1 -1
-1 -1
-1 -1
0
== 範例 1 輸出 ==
5

== 範例 2 輸入 ==
1
-1 -1
0
== 範例 2 輸出 ==
1
