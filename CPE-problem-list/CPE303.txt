CPE Word Search in Grid

難度：中等
來源：原創（回溯法：格子中的單字搜尋）

== 題目 ==
給定 R*C 的字母格子與一個單字，判斷能否從某個格子出發，沿上下左右相鄰格子 (每格只能使用一次) 依序拼出該單字。

輸入說明：每組第一行 R C，接著 R 行each C 個字元；再一行為欲搜尋的單字。R=0 且 C=0 表示輸入結束。
輸出說明：每組輸出 Yes 或 No。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        r, c = map(int, line.split())
        if r == 0 and c == 0:
            break
        grid = [data[idx + i] for i in range(r)]
        idx += r
        word = data[idx].strip(); idx += 1
        visited = [[False] * c for _ in range(r)]

        def dfs(x, y, pos):
            if pos == len(word):
                return True
            if x < 0 or x >= r or y < 0 or y >= c or visited[x][y] or grid[x][y] != word[pos]:
                return False
            visited[x][y] = True
            found = (dfs(x + 1, y, pos + 1) or dfs(x - 1, y, pos + 1) or
                     dfs(x, y + 1, pos + 1) or dfs(x, y - 1, pos + 1))
            visited[x][y] = False
            return found

        found = any(dfs(i, j, 0) for i in range(r) for j in range(c))
        out.append('Yes' if found else 'No')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3 4
ABCE
SFCS
ADEE
ABCCED
0 0
== 範例 1 輸出 ==
Yes

== 範例 2 輸入 ==
2 2
AB
CD
ABCD
0 0
== 範例 2 輸出 ==
No
