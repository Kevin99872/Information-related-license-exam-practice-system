CPE 11364 Optimal Parking

難度：簡單
來源：改編自 UVa Online Judge #11364 (CPE 大學程式能力檢定經典題)

== 題目 ==
Long Street 是一條直線，位置皆為整數。Michael 只能停一次車，之後要走路到每間想去的商店 (可任意順序)，最後不需要回到車上。求在「最佳停車位置」下，走路的最短總距離。

輸入說明：第一行為測試個數 t；每組第一行為商店數 n (1<=n<=20)，第二行為 n 個商店的整數座標 (0<=x<=99)。
輸出說明：每組輸出最短總距離。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    t = int(data[idx]); idx += 1
    out = []
    for _ in range(t):
        n = int(data[idx]); idx += 1
        xs = [int(data[idx + i]) for i in range(n)]
        idx += n
        out.append(str(2 * (max(xs) - min(xs))))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
2
4
24 13 89 37
6
7 30 41 14 39 42
== 範例 1 輸出 ==
152
70

== 範例 2 輸入 ==
1
2
0 99
== 範例 2 輸出 ==
198
