CPE String Rotation Check

難度：簡單
來源：原創（字串旋轉判斷）

== 題目 ==
判斷字串 B 是否為字串 A 經過「循環旋轉」後得到的結果 (例如 "waterbottle" 旋轉後可得 "erbottlewat")。

輸入說明：每行兩個以空白分隔的字串 A B，讀到檔案結尾。
輸出說明：每行輸出 Yes 或 No。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        line = line.rstrip('\n')
        if not line:
            continue
        a, b = line.split()
        out.append('Yes' if len(a) == len(b) and b in (a + a) else 'No')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
waterbottle erbottlewat
abc acb
== 範例 1 輸出 ==
Yes
No

== 範例 2 輸入 ==
abcd cdab
== 範例 2 輸出 ==
Yes
