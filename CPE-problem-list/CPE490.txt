CPE 搜尋二維矩陣

難度：中等
來源：原創（二分搜尋）

== 題目 ==
給定一個 r x c 的矩陣，每一列由左到右遞增排列，且每一列第一個元素大於前一列最後一個元素
（可視為整體攤平後遞增）。給定目標值 target，請判斷矩陣中是否存在該值。輸出 "Yes" 或 "No"。

輸入格式：第一行為 r c（r=0 且 c=0 代表輸入結束）；接下來 r 行each 為該列的 c 個整數；
最後一行為 target。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        r = int(data[idx]); c = int(data[idx + 1]); idx += 2
        if r == 0 and c == 0:
            break
        grid = []
        for i in range(r):
            grid.append([int(data[idx + j]) for j in range(c)])
            idx += c
        target = int(data[idx]); idx += 1
        lo, hi = 0, r * c - 1
        found = False
        while lo <= hi:
            mid = (lo + hi) // 2
            val = grid[mid // c][mid % c]
            if val == target:
                found = True
                break
            elif val < target:
                lo = mid + 1
            else:
                hi = mid - 1
        out.append('Yes' if found else 'No')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3 4
1 3 5 7
10 11 16 20
23 30 34 60
3
== 範例 1 輸出 ==
Yes

== 範例 2 輸入 ==
3 4
1 3 5 7
10 11 16 20
23 30 34 60
13
== 範例 2 輸出 ==
No
