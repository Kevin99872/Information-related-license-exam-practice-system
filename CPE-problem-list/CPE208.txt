CPE 756 Biorhythms

難度：中等
來源：改編自 UVa Online Judge #756 (CPE 大學程式能力檢定經典題)

== 題目 ==
每個人出生時開始三個週期：體力 (23 天)、情緒 (28 天)、智力 (33 天)，各週期都有一個高峰日。給定三個週期各自某一次高峰發生的日子 p、e、i (從今年年初算起第幾天)，以及目前日期 d，求「從 d 之後」下一次三個週期同時到達高峰 (三重高峰) 是在幾天後 (不含 d 當天，若剛好 d 當天就是三重高峰，則求下一次)。

輸入說明：每行四個整數 p e i d，"-1 -1 -1 -1" 表示輸入結束。
輸出說明：每組輸出 "Case X: the next triple peak occurs in Y days."，X 從 1 開始。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    case = 0
    while True:
        p = int(data[idx]); e = int(data[idx + 1]); i = int(data[idx + 2]); d = int(data[idx + 3])
        idx += 4
        if p == -1 and e == -1 and i == -1 and d == -1:
            break
        case += 1
        day = d + 1
        while not ((day - p) % 23 == 0 and (day - e) % 28 == 0 and (day - i) % 33 == 0):
            day += 1
        out.append(f"Case {case}: the next triple peak occurs in {day - d} days.")
    print('\n'.join(out))

main()
