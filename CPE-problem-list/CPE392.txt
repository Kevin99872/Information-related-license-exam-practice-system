CPE Trie with Wildcard Search

難度：中等
來源：原創（字典樹：支援萬用字元 '.' 的單字查詢）

== 題目 ==
給定 n 個單字建立字典樹，接著回答 q 個查詢：某個樣式字串 (可能含 '.'，代表可匹配任意一個字元) 是否與字典中「某個單字」完全匹配 (長度也需相同)。

輸入說明：每組第一行為 n，接著 n 行each 一個單字；再一行查詢數 q，接著 q 行each 一個樣式字串。n=0 表示輸入結束。
輸出說明：每個查詢輸出 Yes 或 No。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        n = int(line)
        if n == 0:
            break
        trie = {}
        for _ in range(n):
            w = data[idx].strip(); idx += 1
            node = trie
            for c in w:
                node = node.setdefault(c, {})
            node['$'] = True
        q = int(data[idx].strip()); idx += 1

        def search(word):
            def dfs(node, pos):
                if pos == len(word):
                    return '$' in node
                c = word[pos]
                if c == '.':
                    return any(dfs(child, pos + 1) for k, child in node.items() if k != '$')
                if c not in node:
                    return False
                return dfs(node[c], pos + 1)
            return dfs(trie, 0)

        for _ in range(q):
            w = data[idx].strip(); idx += 1
            out.append('Yes' if search(w) else 'No')
    print('\n'.join(out))

main()
