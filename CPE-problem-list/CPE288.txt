CPE Closest Pair of Points

難度：中等
來源：原創（計算幾何：最近點對距離）

== 題目 ==
給定平面上 n 個點，求距離最近的兩點之間的距離。

輸入說明：每組第一行 n (2<=n<=200)，接著 n 行each 兩個整數 x y。n=0 表示輸入結束。
輸出說明：每組輸出最短距離，四捨五入到小數點後 4 位。

== 參考解法 (Python) ==
import sys
import math

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        pts = []
        for _ in range(n):
            x = int(data[idx]); y = int(data[idx + 1]); idx += 2
            pts.append((x, y))
        best = float('inf')
        for i in range(n):
            for j in range(i + 1, n):
                d = math.hypot(pts[i][0] - pts[j][0], pts[i][1] - pts[j][1])
                best = min(best, d)
        out.append(f"{best:.4f}")
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4
0 0
3 4
1 1
5 5
0
== 範例 1 輸出 ==
1.4142

== 範例 2 輸入 ==
2
