== 題目 ==
建築師有 n 個可用樓層，每個樓層有大小 (絕對值) 與顏色 (正值=藍色、負值=紅色，大小皆不重複)。要蓋一棟盡量高的大樓，規則：由下到上樓層大小必須嚴格遞增，且相鄰樓層顏色必須不同 (樓層可任意排列組合、不需依原輸入順序)。求最多能使用幾層樓。

輸入說明：第一行為測試個數 p；每組第一行為樓層數 n，接著 n 個整數 (正負號代表顏色，絕對值代表大小)。
輸出說明：每組輸出最多能蓋的樓層數。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    p = int(data[idx]); idx += 1
    out = []
    for _ in range(p):
        n = int(data[idx]); idx += 1
        floors = [int(data[idx + i]) for i in range(n)]
        idx += n
        floors.sort(key=abs)
        best_pos = 0
        best_neg = 0
        for v in floors:
            if v > 0:
                best_pos = max(best_pos, best_neg + 1)
            else:
                best_neg = max(best_neg, best_pos + 1)
        out.append(str(max(best_pos, best_neg)))
    print('\n'.join(out))

main()
