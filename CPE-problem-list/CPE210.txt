== 題目 ==
一個環狀 DNA 序列 (只含 A、C、G、T) 可以從任意位置切開變成線性序列。求所有可能的線性序列中「字典序最小」的一個。

輸入說明：第一行為測試個數 T；接著 T 行each 一個環狀序列 (以任意起點寫成的線性字串，長度 2~100)。
輸出說明：每行輸出字典序最小的線性序列。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    t = int(data[idx]); idx += 1
    out = []
    for _ in range(t):
        s = data[idx]; idx += 1
        n = len(s)
        out.append(min(s[i:] + s[:i] for i in range(n)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
2
CGAGTCAGCT
CTCC
== 範例 1 輸出 ==
AGCTCGAGTC
CCCT

== 範例 2 輸入 ==
1
BAAB
== 範例 2 輸出 ==
AABB
