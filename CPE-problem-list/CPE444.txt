CPE Minimum Height of Balanced BST from Sorted Array

難度：簡單
來源：原創（由已排序陣列建立平衡二元搜尋樹的最小高度）

== 題目 ==
給定已排序陣列的元素個數 n，若總是選取「中間元素」作為根遞迴建立二元搜尋樹，求所建出的樹的高度 (單一節點高度為 1)。

輸入說明：每行一個整數 n (0<=n<=10^9)，讀到檔案結尾。
輸出說明：每行輸出樹的高度。

== 參考解法 (Python) ==
import sys
import math

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        if n == 0:
            out.append('0')
            continue
        out.append(str(math.floor(math.log2(n)) + 1))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
1
3
7
4
== 範例 1 輸出 ==
1
2
3
3

== 範例 2 輸入 ==
0
1000000000
== 範例 2 輸出 ==
0
30
