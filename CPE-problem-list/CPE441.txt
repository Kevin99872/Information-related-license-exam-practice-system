CPE Binary Tree Level Sums

難度：簡單
來源：原創（BFS：二元樹各層總和）

== 題目 ==
給定一棵二元樹 (陣列表示，節點 0 為根，每個節點有值，left[i]/right[i] 為左右子節點索引，-1 表示不存在)，求每一層節點值的總和 (由上到下)。

輸入說明：每組第一行 n，接著 n 行each 三個整數 (節點 0~n-1 依序的 值、left、right)。n=0 表示輸入結束。
輸出說明：每組輸出各層總和 (以空白分隔)。

== 參考解法 (Python) ==
import sys
from collections import deque

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        val, left, right = [], [], []
        for _ in range(n):
            val.append(int(data[idx])); left.append(int(data[idx + 1])); right.append(int(data[idx + 2])); idx += 3
        sums = []
        q = deque([0])
        while q:
            size = len(q)
            s = 0
            for _ in range(size):
                u = q.popleft()
                s += val[u]
                if left[u] != -1:
                    q.append(left[u])
                if right[u] != -1:
                    q.append(right[u])
            sums.append(s)
        out.append(' '.join(map(str, sums)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
1 1 2
2 3 4
3 -1 -1
4 -1 -1
5 -1 -1
0
== 範例 1 輸出 ==
1 5 9

== 範例 2 輸入 ==
1
1 -1 -1
0
== 範例 2 輸出 ==
1
