CPE Minimum Cost to Merge Piles

難度：中等
來源：原創（貪心 + 最小堆積：合併石堆最小成本 (Huffman 概念)）

== 題目 ==
有 n 堆石頭，每次可以合併「任兩堆」為一堆，合併成本為兩堆數量之和，合併後的堆數量即為該成本。求把所有石頭合併成一堆所需的最小總成本。

輸入說明：每組第一行 n，第二行 n 個正整數 (各堆數量)。n=0 表示輸入結束。
輸出說明：每組輸出最小總成本。

== 參考解法 (Python) ==
import sys
import heapq

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        piles = [int(data[idx + i]) for i in range(n)]
        idx += n
        heapq.heapify(piles)
        total = 0
        while len(piles) > 1:
            a = heapq.heappop(piles)
            b = heapq.heappop(piles)
            s = a + b
            total += s
            heapq.heappush(piles, s)
        out.append(str(total))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4
4 3 2 6
0
== 範例 1 輸出 ==
29

== 範例 2 輸入 ==
1
5
0
== 範例 2 輸出 ==
0
