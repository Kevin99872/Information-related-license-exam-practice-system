== 題目 ==
超商優惠：3 個空瓶可以換 1 瓶新可樂。買了 N 瓶可樂，喝完後可用空瓶換更多可樂 (換到的新可樂喝完後空瓶還能繼續換)。此外也可以先跟朋友「借」1 個空瓶湊數換可樂，但事後必須用手上的空瓶還給朋友 1 個。求最多能喝到幾瓶可樂。

輸入說明：每行一個整數 N (1<=N<=200)，讀到檔案結尾。
輸出說明：每行輸出最多能喝到的可樂瓶數。

== 參考解法 (Python) ==
import sys

def solve(n):
    total = 0
    empty = 0
    while n > 0:
        total += n
        empty += n
        n = empty // 3
        empty %= 3
    if empty == 2:
        total += 1
    return total

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        out.append(str(solve(int(line))))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
8
== 範例 1 輸出 ==
12

== 範例 2 輸入 ==
1
2
200
== 範例 2 輸出 ==
1
3
300
