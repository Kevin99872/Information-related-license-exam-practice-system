CPE Kth Permutation Sequence

難度：中等
來源：原創（階乘進位法：第 K 個排列）

== 題目 ==
給定 n，考慮由 1~n 組成的所有排列，依字典序排列後，求第 k 個排列 (k 由 1 開始)。

輸入說明：每行兩個整數 n k (1<=n<=10)，讀到檔案結尾。
輸出說明：每行輸出第 k 個排列 (數字直接相連，不含空白)。

== 參考解法 (Python) ==
import sys
import math

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n, k = map(int, line.split())
        nums = list(range(1, n + 1))
        k -= 1
        result = []
        for i in range(n, 0, -1):
            f = math.factorial(i - 1)
            idx = k // f
            k %= f
            result.append(str(nums.pop(idx)))
        out.append(''.join(result))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3 3
4 9
== 範例 1 輸出 ==
213
2314

== 範例 2 輸入 ==
3 1
3 6
== 範例 2 輸出 ==
123
321
