CPE [UVa615] 這是一棵樹嗎？

難度：中等
來源：改編自 UVa Online Judge #615 (CPE 大學程式能力檢定經典題)

== 題目 ==
給定若干組測試資料，每組資料描述一個有向圖：一系列邊 (a, b) 代表由節點 a 指向節點 b，
以 "0 0" 結尾代表該組測試資料結束。整個輸入以 "-1 -1" 結尾。

請判斷每組測試資料所描述的圖是否構成一棵「樹」。樹的定義為：
1. 恰好有一個節點沒有任何邊指向它（根節點），其餘每個出現過的節點都恰好有一條邊指向它。
2. 從根節點出發可以到達所有節點（圖是連通的，且不含環）。
3. 空圖（沒有任何節點）也視為一棵樹。

對每組測試資料輸出一行：
"Case k is a tree." 或 "Case k is not a tree."（k 為測試資料編號，從 1 開始）。

輸入範圍：節點編號為正整數，數量不多。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    case = 0
    while True:
        a = int(data[idx]); b = int(data[idx + 1]); idx += 2
        if a == -1 and b == -1:
            break
        case += 1
        parent = {}
        indeg = {}
        nodes = set()

        def find(x):
            parent.setdefault(x, x)
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        is_tree = True
        while not (a == 0 and b == 0):
            nodes.add(a); nodes.add(b)
            indeg[b] = indeg.get(b, 0) + 1
            if indeg[b] > 1:
                is_tree = False
            ra, rb = find(a), find(b)
            if ra == rb:
                is_tree = False
            else:
                parent[ra] = rb
            a = int(data[idx]); b = int(data[idx + 1]); idx += 2
        roots = set(find(n) for n in nodes)
        if len(roots) > 1:
            is_tree = False
        out.append(f"Case {case} is a tree." if is_tree else f"Case {case} is not a tree.")
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
6 8 5 3 5 2 6 4 5 6 0 0
8 1 7 3 6 2 8 9 7 5 7 4 7 8 7 6 0 0
3 8 6 8 6 4 5 3 5 6 5 2 0 0
-1 -1
== 範例 1 輸出 ==
Case 1 is a tree.
Case 2 is a tree.
Case 3 is not a tree.
