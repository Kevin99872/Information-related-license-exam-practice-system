CPE Merge Sorted Array In-Place

難度：簡單
來源：原創（雙指標：原地合併已排序陣列）

== 題目 ==
給定兩個已由小到大排序的陣列 A (長度 n) 與 B (長度 m)，將 B 合併進 A 使 A 成為長度 n+m 的排序陣列。

輸入說明：每組第一行 n m，第二行 n 個整數 (A)，第三行 m 個整數 (B)。n=0 且 m=0 表示輸入結束。
輸出說明：每組輸出合併後的陣列 (以空白分隔)。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); m = int(data[idx + 1]); idx += 2
        if n == 0 and m == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        b = [int(data[idx + i]) for i in range(m)]
        idx += m
        a = a + [0] * m
        i, j, k = n - 1, m - 1, n + m - 1
        while j >= 0:
            if i >= 0 and a[i] > b[j]:
                a[k] = a[i]
                i -= 1
            else:
                a[k] = b[j]
                j -= 1
            k -= 1
        out.append(' '.join(map(str, a)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3 3
1 2 3
2 5 6
0 0
== 範例 1 輸出 ==
1 2 2 3 5 6

== 範例 2 輸入 ==
0 3

1 2 3
0 0
== 範例 2 輸出 ==
1 2 3
