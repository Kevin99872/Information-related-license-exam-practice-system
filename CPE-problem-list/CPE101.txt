CPE Pascal's Triangle Row

難度：簡單
來源：原創（巴斯卡三角形）

== 題目 ==
給定 n (由 0 開始編號)，輸出巴斯卡三角形第 n 列的所有二項式係數 C(n,0), C(n,1), ..., C(n,n)。

輸入說明：每行一個整數 n (0<=n<=30)，讀到檔案結尾。
輸出說明：每行輸出該列的所有係數，以空白分隔。

== 參考解法 (Python) ==
import sys
import math

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        row = [math.comb(n, k) for k in range(n + 1)]
        print(' '.join(map(str, row)))

main()

== 範例 1 輸入 ==
0
1
4
== 範例 1 輸出 ==
1
1 1
1 4 6 4 1

== 範例 2 輸入 ==
5
6
== 範例 2 輸出 ==
1 5 10 10 5 1
1 6 15 20 15 6 1
