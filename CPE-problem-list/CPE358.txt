CPE 10917 A Walk Through the Forest

難度：困難
來源：改編自 UVa Online Judge #10917 (CPE 大學程式能力檢定經典題)

== 題目 ==
Jimmy 從辦公室 (節點 1) 走路回家 (節點 2)，森林中有 N 個路口與 M 條雙向路徑 (各有長度)。從 A 走到 B 稱為「有進展」，若存在一條從 B 到家的路徑比「從 A 到家的最短路徑」更短。Jimmy 每次都選擇有進展的走法，求他總共有幾種不同的走法可以從辦公室走到家。

輸入說明：每組第一行 N M，接著 M 行each 三個整數 a b d (節點 a、b 間有長度 d 的路徑)。N=0 表示輸入結束。
輸出說明：每組輸出走法總數。

== 參考解法 (Python) ==
import sys
import heapq

def main():
    sys.setrecursionlimit(10000)
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        m = int(data[idx]); idx += 1
        adj = [[] for _ in range(n + 1)]
        for _ in range(m):
            a = int(data[idx]); b = int(data[idx + 1]); d = int(data[idx + 2]); idx += 3
            adj[a].append((b, d))
            adj[b].append((a, d))
        INF = float('inf')
        dist = [INF] * (n + 1)
        dist[2] = 0
        pq = [(0, 2)]
        while pq:
            dd, u = heapq.heappop(pq)
            if dd > dist[u]:
                continue
            for v, w in adj[u]:
                if dd + w < dist[v]:
                    dist[v] = dd + w
                    heapq.heappush(pq, (dist[v], v))
        memo = {}

        def count(u):
            if u == 2:
                return 1
            if u in memo:
                return memo[u]
            total = 0
            for v, w in adj[u]:
                if dist[v] < dist[u]:
                    total += count(v)
            memo[u] = total
            return total

        out.append(str(count(1)))
    print('\n'.join(out))

main()
