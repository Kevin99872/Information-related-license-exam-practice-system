CPE Gas Station Circular Tour

難度：中等
來源：原創（貪心：環狀加油站問題）

== 題目 ==
環狀路線上有 n 個加油站，第 i 站可加 gas[i] 公升油，從第 i 站開到下一站需消耗 cost[i] 公升油。若總加油量不小於總消耗量，保證存在唯一一個「起始加油站」，從該站出發可以環繞一圈回到起點且油量不會出現負值；求該起始站的編號 (0-indexed)。若總加油量小於總消耗量則輸出 -1。

輸入說明：每組第一行 n，第二行 n 個整數 gas，第三行 n 個整數 cost。n=0 表示輸入結束。
輸出說明：每組輸出起始加油站編號，或 -1。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        gas = [int(data[idx + i]) for i in range(n)]
        idx += n
        cost = [int(data[idx + i]) for i in range(n)]
        idx += n
        total = 0
        tank = 0
        start = 0
        for i in range(n):
            diff = gas[i] - cost[i]
            total += diff
            tank += diff
            if tank < 0:
                start = i + 1
                tank = 0
        out.append(str(start) if total >= 0 else '-1')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
1 2 3 4 5
3 4 5 1 2
0
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
3
2 3 4
3 4 3
0
== 範例 2 輸出 ==
-1
