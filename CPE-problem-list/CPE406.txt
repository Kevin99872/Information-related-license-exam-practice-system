CPE 11631 Dark roads

難度：簡單
來源：改編自 UVa Online Judge #11631 (CPE 大學程式能力檢定經典題)

== 題目 ==
給定一個連通的無向加權圖 (m 個路口、n 條道路)，每條路每天照明費用等於其長度。求「只保留最小生成樹上的道路照明」，每天最多能省下多少錢 (總長度減去最小生成樹總長度)。

輸入說明：每組第一行 m n，接著 n 行each 三個整數 x y z (路口 x、y 間有長度 z 的道路)。m=0 且 n=0 表示輸入結束。
輸出說明：每組輸出每天最多能節省的金額。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        m = int(data[idx]); n = int(data[idx + 1]); idx += 2
        if m == 0 and n == 0:
            break
        edges = []
        total = 0
        for _ in range(n):
            x = int(data[idx]); y = int(data[idx + 1]); z = int(data[idx + 2]); idx += 3
            edges.append((z, x, y))
            total += z
        edges.sort()
        parent = list(range(m))

        def find(a):
            while parent[a] != a:
                parent[a] = parent[parent[a]]
                a = parent[a]
            return a

        mst = 0
        for z, x, y in edges:
            rx, ry = find(x), find(y)
            if rx != ry:
                parent[rx] = ry
                mst += z
        out.append(str(total - mst))
    print('\n'.join(out))

main()
