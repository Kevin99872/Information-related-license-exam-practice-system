CPE Topological Sort

難度：中等
來源：原創（拓樸排序 (Kahn 演算法)）

== 題目 ==
給定一個含 n 個節點、m 條有向邊的圖，求一組合法的拓樸排序 (若有多組解，輸出「字典序最小」的一組)；若圖中有環 (無法拓樸排序) 則輸出 IMPOSSIBLE。

輸入說明：每組第一行 n m，接著 m 行each 兩個整數 u v (代表邊 u→v)。n=0 且 m=0 表示輸入結束。
輸出說明：每組輸出拓樸排序結果 (以空白分隔)，或 IMPOSSIBLE。

== 參考解法 (Python) ==
import sys
import heapq

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); m = int(data[idx + 1]); idx += 2
        if n == 0:
            break
        adj = [[] for _ in range(n)]
        indeg = [0] * n
        for _ in range(m):
            u = int(data[idx]); v = int(data[idx + 1]); idx += 2
            adj[u].append(v)
            indeg[v] += 1
        heap = [i for i in range(n) if indeg[i] == 0]
        heapq.heapify(heap)
        order = []
        while heap:
            u = heapq.heappop(heap)
            order.append(u)
            for v in adj[u]:
                indeg[v] -= 1
                if indeg[v] == 0:
                    heapq.heappush(heap, v)
        out.append(' '.join(map(str, order)) if len(order) == n else 'IMPOSSIBLE')
    print('\n'.join(out))

main()
