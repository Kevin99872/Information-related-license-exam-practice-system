CPE Decimal to Custom Base

難度：簡單
來源：原創（任意進位制轉換）

== 題目 ==
給定一個十進位整數 n 與目標進位 base (2<=base<=36)，轉換成該進位制的表示法 (使用 0-9、A-Z)。

輸入說明：每行兩個整數 n base (0<=n<=10^9)，讀到檔案結尾。
輸出說明：每行輸出轉換後的字串。

== 參考解法 (Python) ==
import sys

DIGITS = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n, base = map(int, line.split())
        if n == 0:
            out.append('0')
            continue
        digs = []
        while n > 0:
            digs.append(DIGITS[n % base])
            n //= base
        out.append(''.join(reversed(digs)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
255 16
10 2
== 範例 1 輸出 ==
FF
1010

== 範例 2 輸入 ==
0 5
35 36
== 範例 2 輸出 ==
0
Z
