CPE Merge Intervals

難度：中等
來源：原創（區間合併經典題型）

== 題目 ==
給定 n 個區間 [l,r]，合併所有重疊或相接的區間，依左端點由小到大輸出合併後的區間。

輸入說明：每組第一行 n，接著 n 行each 兩個整數 l r。n=0 結束。
輸出說明：每組每行輸出一個合併後區間 "l r"，組與組之間空一行。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    blocks = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        intervals = []
        for _ in range(n):
            l = int(data[idx]); r = int(data[idx + 1]); idx += 2
            intervals.append((l, r))
        intervals.sort()
        merged = []
        for l, r in intervals:
            if merged and l <= merged[-1][1]:
                merged[-1] = (merged[-1][0], max(merged[-1][1], r))
            else:
                merged.append((l, r))
        blocks.append('\n'.join(f"{l} {r}" for l, r in merged))
    print('\n\n'.join(blocks))

main()
