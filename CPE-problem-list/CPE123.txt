CPE 11729 Commando War

難度：中等
來源：改編自 UVa Online Judge #11729 (CPE 大學程式能力檢定經典題)

== 題目 ==
你要依序對 N 名士兵「簡報任務」，第 i 名士兵需要 B_i 秒聽取簡報，簡報必須依序進行 (一次只能對一人簡報)。士兵聽完簡報後立刻開始執行任務，需要 J_i 秒完成 (可與其他士兵的簡報或任務同時進行)。求安排簡報順序，使「所有士兵都完成任務」的最短時間。

輸入說明：每組第一行為士兵數 N，接著 N 行each 兩個整數 B J。N=0 表示輸入結束。
輸出說明：每組輸出 "Case X: Y"，X 為case編號 (從1開始)，Y 為所有任務完成的最短時間。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    case = 0
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        soldiers = []
        for _ in range(n):
            b = int(data[idx]); j = int(data[idx + 1]); idx += 2
            soldiers.append((b, j))
        soldiers.sort(key=lambda x: -x[1])
        case += 1
        t = 0
        total = 0
        for b, j in soldiers:
            t += b
            total = max(total, t + j)
        out.append(f"Case {case}: {total}")
    print('\n'.join(out))

main()
