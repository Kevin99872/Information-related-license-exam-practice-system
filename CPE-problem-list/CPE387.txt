CPE Shortest Path in Binary Matrix

難度：中等
來源：原創（8 方向 BFS：0/1 矩陣最短路徑）

== 題目 ==
給定一個 n*n 的 0/1 矩陣 (0 可通行、1 為障礙)，可沿 8 個方向 (含對角) 移動，求從左上角 (0,0) 到右下角 (n-1,n-1) 的最短路徑長度 (路徑上格子數，含起點終點)；若無法到達或起點/終點本身是障礙則輸出 -1。

輸入說明：每組第一行 n，接著 n 行each n 個以空白分隔的整數。n=0 表示輸入結束。
輸出說明：每組輸出最短路徑長度，或 -1。

== 參考解法 (Python) ==
import sys
from collections import deque

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        n = int(line)
        if n == 0:
            break
        grid = []
        for _ in range(n):
            grid.append(list(map(int, data[idx].split())))
            idx += 1
        if grid[0][0] == 1 or grid[n - 1][n - 1] == 1:
            out.append('-1')
            continue
        dist = [[-1] * n for _ in range(n)]
        dist[0][0] = 1
        q = deque([(0, 0)])
        while q:
            x, y = q.popleft()
            if x == n - 1 and y == n - 1:
                break
            for dx in (-1, 0, 1):
                for dy in (-1, 0, 1):
                    if dx == 0 and dy == 0:
                        continue
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < n and 0 <= ny < n and grid[nx][ny] == 0 and dist[nx][ny] == -1:
                        dist[nx][ny] = dist[x][y] + 1
                        q.append((nx, ny))
        out.append(str(dist[n - 1][n - 1]))
    print('\n'.join(out))

main()
