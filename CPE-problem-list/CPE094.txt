CPE Subset Sum Existence

難度：中等
來源：原創（動態規劃：子集合和問題）

== 題目 ==
給定 n 個正整數與目標值 target，判斷是否存在一個子集合 (可為空集合)，使其元素總和恰為 target。

輸入說明：每組第一行 n target，第二行 n 個正整數。n=0 且 target=0 表示輸入結束 (且不處理)。
輸出說明：每組輸出 Yes 或 No。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); target = int(data[idx + 1]); idx += 2
        if n == 0 and target == 0:
            break
        nums = [int(data[idx + i]) for i in range(n)]
        idx += n
        possible = {0}
        for x in nums:
            possible |= {p + x for p in possible if p + x <= target}
        out.append('Yes' if target in possible else 'No')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5 9
3 34 4 12 5
0 0
== 範例 1 輸出 ==
Yes

== 範例 2 輸入 ==
4 11
1 2 3 4
0 0
== 範例 2 輸出 ==
No
