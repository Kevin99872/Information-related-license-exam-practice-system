CPE Best Time to Buy and Sell Stock

難度：簡單
來源：原創（股票買賣最大獲利 (單次交易)）

== 題目 ==
給定 n 天的股票價格，只能進行「一次」買進與一次賣出 (先買後賣)，求最大獲利；若無法獲利則輸出 0。

輸入說明：每組第一行 n，第二行 n 個整數 (每天的價格)。n=0 表示輸入結束。
輸出說明：每組輸出最大獲利。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        prices = [int(data[idx + i]) for i in range(n)]
        idx += n
        best = 0
        minp = prices[0]
        for p in prices[1:]:
            best = max(best, p - minp)
            minp = min(minp, p)
        out.append(str(best))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
6
7 1 5 3 6 4
0
== 範例 1 輸出 ==
5

== 範例 2 輸入 ==
5
7 6 4 3 1
0
== 範例 2 輸出 ==
0
