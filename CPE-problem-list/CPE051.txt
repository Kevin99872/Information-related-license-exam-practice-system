CPE Coin Change

難度：中等
來源：原創（動態規劃：硬幣找零經典題型）

== 題目 ==
給定 k 種硬幣面額 (硬幣可重複使用不限次數) 與目標金額 amount，求湊出該金額所需的最少硬幣數；若無法湊出，輸出 -1。

輸入說明：每組第一行為 k 與 amount；第二行為 k 個正整數面額。以 k=0 結束 (不處理)。
輸出說明：每組輸出最少硬幣數，若無解輸出 -1。

== 參考解法 (Python) ==
import sys

data = sys.stdin.read().split('\n')
idx = 0
out = []
while idx < len(data):
    line = data[idx].strip()
    idx += 1
    if line == '':
        continue
    k, amount = map(int, line.split())
    if k == 0:
        break
    coins = list(map(int, data[idx].split()))
    idx += 1
    INF = float('inf')
    dp = [0] + [INF] * amount
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a and dp[a - c] + 1 < dp[a]:
                dp[a] = dp[a - c] + 1
    out.append(str(dp[amount] if dp[amount] != INF else -1))
print('\n'.join(out))

== 範例 1 輸入 ==
3 11
1 2 5
2 3
2
== 範例 1 輸出 ==
3
-1

== 範例 2 輸入 ==
1 7
3
3 0
1 5 10
== 範例 2 輸出 ==
-1
0
