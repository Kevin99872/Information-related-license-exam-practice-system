CPE GCD and LCM of an Array

難度：簡單
來源：原創（最大公因數與最小公倍數）

== 題目 ==
給定 n 個正整數，求它們的最大公因數 (GCD) 與最小公倍數 (LCM)。

輸入說明：每組第一行 n，第二行 n 個正整數。n=0 結束。
輸出說明：每組輸出 "GCD LCM"。

== 參考解法 (Python) ==
import sys
import math
from functools import reduce

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        nums = [int(data[idx + i]) for i in range(n)]
        idx += n
        g = reduce(math.gcd, nums)
        l = reduce(lambda a, b: a * b // math.gcd(a, b), nums)
        out.append(f"{g} {l}")
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3
4 8 12
2
7 5
0
== 範例 1 輸出 ==
4 24
1 35

== 範例 2 輸入 ==
4
6 10 15 20
0
== 範例 2 輸出 ==
1 60
