CPE 11991 Easy Problem from Rujia Liu?

難度：中等
來源：改編自 UVa Online Judge #11991 (CPE 大學程式能力檢定經典題)

== 題目 ==
給定一個陣列，回答 m 個查詢：數值 v 在陣列中「由左至右數來第 k 次」出現的位置 (1-indexed)；若不存在則輸出 0。

輸入說明：每組第一行 n m，第二行 n 個正整數；接著 m 行each 兩個整數 k v。
輸出說明：每個查詢輸出對應的位置，或 0。

== 參考解法 (Python) ==
import sys
from collections import defaultdict

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); m = int(data[idx + 1]); idx += 2
        arr = [int(data[idx + i]) for i in range(n)]
        idx += n
        pos = defaultdict(list)
        for i, v in enumerate(arr, 1):
            pos[v].append(i)
        for _ in range(m):
            k = int(data[idx]); v = int(data[idx + 1]); idx += 2
            lst = pos.get(v, [])
            out.append(str(lst[k - 1]) if k <= len(lst) else '0')
    print('\n'.join(out))

main()
