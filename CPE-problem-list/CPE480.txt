CPE 三個數的最大乘積

難度：簡單
來源：原創（排序後貪心比較）

== 題目 ==
給定一個長度至少為 3 的整數陣列（可能包含負數），請找出其中三個數相乘的最大值。

輸入格式：第一行為 n（n=0 代表輸入結束）；第二行為 n 個整數。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = sorted(int(data[idx + i]) for i in range(n))
        idx += n
        out.append(str(max(a[-1] * a[-2] * a[-3], a[0] * a[1] * a[-1])))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3
1 2 3
== 範例 1 輸出 ==
6

== 範例 2 輸入 ==
4
-4 -3 1 2
== 範例 2 輸出 ==
24
