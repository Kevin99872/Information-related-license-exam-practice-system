CPE Largest Rectangle in Histogram

難度：困難
來源：原創（單調堆疊：直方圖最大矩形面積）

== 題目 ==
給定 n 個長條的高度 (寬度皆為 1)，求直方圖中最大矩形的面積。

輸入說明：每組第一行 n，第二行 n 個非負整數。n=0 表示輸入結束。
輸出說明：每組輸出最大矩形面積。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        h = [int(data[idx + i]) for i in range(n)]
        idx += n
        stack = []
        best = 0
        for i in range(n + 1):
            cur = h[i] if i < n else 0
            while stack and h[stack[-1]] >= cur:
                height = h[stack.pop()]
                width = i if not stack else i - stack[-1] - 1
                best = max(best, height * width)
            stack.append(i)
        out.append(str(best))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
6
2 1 5 6 2 3
0
== 範例 1 輸出 ==
10

== 範例 2 輸入 ==
4
2 4 2 1
0
== 範例 2 輸出 ==
6
