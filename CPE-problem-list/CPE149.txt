CPE Fractional Knapsack

難度：中等
來源：原創（貪心：分數背包問題）

== 題目 ==
給定 n 個物品，每個物品有重量 w 與價值 v (可分割，取一部分重量可得對應比例的價值)，以及背包容量 cap，求能裝入的最大總價值。

輸入說明：每組第一行 n cap，接著 n 行each 兩個數字 w v。n=0 且 cap=0 表示輸入結束。
輸出說明：每組輸出最大總價值，四捨五入到小數點後 2 位。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); cap = float(data[idx + 1]); idx += 2
        if n == 0 and cap == 0:
            break
        items = []
        for _ in range(n):
            w = float(data[idx]); v = float(data[idx + 1]); idx += 2
            items.append((w, v))
        items.sort(key=lambda x: -(x[1] / x[0]))
        remain = cap
        total = 0.0
        for w, v in items:
            if remain <= 0:
                break
            take = min(w, remain)
            total += take * (v / w)
            remain -= take
        out.append(f"{total:.2f}")
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3 50
10 60
20 100
30 120
0 0
== 範例 1 輸出 ==
240.00

== 範例 2 輸入 ==
1 10
5 25
0 0
== 範例 2 輸出 ==
25.00
