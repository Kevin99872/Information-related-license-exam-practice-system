CPE Binary Tree Maximum Path Sum

難度：中等
來源：原創（樹狀動態規劃：二元樹最大路徑和）

== 題目 ==
給定一棵二元樹 (陣列表示，節點 0 為根，每個節點有一個值，left[i]/right[i] 為左右子節點索引，-1 表示不存在，節點值可能為負)，路徑定義為樹上任意節點間、沿邊相連的序列 (不需經過根節點)，求路徑上節點總和的最大值。

輸入說明：每組第一行 n，接著 n 行each 三個整數 (節點 0~n-1 依序的 值、left、right)。n=0 表示輸入結束。
輸出說明：每組輸出最大路徑和。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        val, left, right = [], [], []
        for _ in range(n):
            val.append(int(data[idx])); left.append(int(data[idx + 1])); right.append(int(data[idx + 2])); idx += 3
        best = [-10 ** 18]

        def dfs(u):
            if u == -1:
                return 0
            l = max(0, dfs(left[u]))
            r = max(0, dfs(right[u]))
            best[0] = max(best[0], val[u] + l + r)
            return val[u] + max(l, r)

        dfs(0)
        out.append(str(best[0]))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3
1 1 2
2 -1 -1
3 -1 -1
0
== 範例 1 輸出 ==
6

== 範例 2 輸入 ==
3
-10 1 2
9 -1 -1
20 -1 -1
0
== 範例 2 輸出 ==
20
