CPE 424 Integer Inquiry

難度：簡單
來源：改編自 UVa Online Judge #424 (CPE 大學程式能力檢定經典題)

== 題目 ==
給定多個超大整數 (可能超過一般整數型別範圍)，求其總和。

輸入說明：最多 100 行，每行一個大整數 (長度<=100 且只含數字)；最後一行為單獨的 0，表示輸入結束 (不計入總和)。
輸出說明：輸出所有數字的總和。

== 參考解法 (Python) ==
import sys

def main():
    total = 0
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        if n == 0:
            break
        total += n
    print(total)

main()

== 範例 1 輸入 ==
123456789012345678901234567890
123456789012345678901234567890
123456789012345678901234567890
0
== 範例 1 輸出 ==
370370367037037036703703703670

== 範例 2 輸入 ==
999999999999999999999999999999
1
0
== 範例 2 輸出 ==
1000000000000000000000000000000
