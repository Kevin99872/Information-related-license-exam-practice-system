CPE 可可吃香蕉

難度：中等
來源：原創（答案二分搜尋）

== 題目 ==
給定 n 堆香蕉，第 i 堆有 piles[i] 根，可可每小時可以選一堆吃最多 k 根香蕉
（若該堆不足 k 根，則吃完該堆即可，剩餘時間不會用於其他堆）。她想在 h 小時內吃完所有香蕉，
請求出最小的 k（每小時吃的根數上限）。

輸入格式：第一行為 n h（n=0 且 h=0 代表輸入結束）；第二行為 n 個正整數。

== 參考解法 (Python) ==
import sys
import math

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); h = int(data[idx + 1]); idx += 2
        if n == 0 and h == 0:
            break
        piles = [int(data[idx + i]) for i in range(n)]
        idx += n

        def hours_needed(k):
            return sum(math.ceil(p / k) for p in piles)

        lo, hi = 1, max(piles)
        while lo < hi:
            mid = (lo + hi) // 2
            if hours_needed(mid) <= h:
                hi = mid
            else:
                lo = mid + 1
        out.append(str(lo))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4 8
3 6 7 11
== 範例 1 輸出 ==
4

== 範例 2 輸入 ==
5 5
30 11 23 4 20
== 範例 2 輸出 ==
30
