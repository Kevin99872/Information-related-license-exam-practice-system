CPE 10025 The ?1?2?...?n=k problem

難度：中等
來源：改編自 UVa Online Judge #10025 (CPE 大學程式能力檢定經典題)

== 題目 ==
給定算式 ?1?2?...?n=k，每個 '?' 可填入 '+' 或 '-'。給定 k，求能使等式成立的「最小」n (1<=n)。

輸入說明：第一行為測試個數，之後空一行；每個 case 一行一個整數 k (|k|<=1000000000)，case 之間有空行。
輸出說明：每個 case 輸出最小的 n；case 之間空一行。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    while data[idx].strip() == '':
        idx += 1
    t = int(data[idx].strip()); idx += 1
    out = []
    for case in range(t):
        while data[idx].strip() == '':
            idx += 1
        k = abs(int(data[idx].strip())); idx += 1
        n = 0
        s = 0
        while s < k or (s - k) % 2 != 0:
            n += 1
            s += n
        if case > 0:
            out.append('')
        out.append(str(n))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
2

12

-3646397
== 範例 1 輸出 ==
7

2701

== 範例 2 輸入 ==
1

0
== 範例 2 輸出 ==
0
