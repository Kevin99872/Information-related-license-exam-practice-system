CPE Tower of Hanoi

難度：簡單
來源：原創（河內塔經典遞迴題型）

== 題目 ==
河內塔問題：共有 3 根柱子 A、B、C，n 個大小不同的盤子疊在柱子 A 上 (由大到小)，目標是全部移到柱子 C，每次只能移動一個盤子，且大盤不能疊在小盤上面。求最少移動次數，並輸出完整的移動順序。

輸入說明：每行一個整數 n (1<=n<=10)，以 0 結束。
輸出說明：每組輸出兩行：第一行為最少移動次數；第二行為移動順序，格式為 "X->Y" (由柱子 X 移到柱子 Y)，以空白分隔。

== 參考解法 (Python) ==
import sys

def hanoi(n, src, aux, dst, moves):
    if n == 0:
        return
    hanoi(n - 1, src, dst, aux, moves)
    moves.append(f"{src}->{dst}")
    hanoi(n - 1, aux, src, dst, moves)

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        if n == 0:
            break
        moves = []
        hanoi(n, 'A', 'B', 'C', moves)
        out.append(str(len(moves)))
        out.append(' '.join(moves))
    print('\n'.join(out))

main()
