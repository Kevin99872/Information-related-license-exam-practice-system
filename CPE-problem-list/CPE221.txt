CPE Longest Path in a DAG

難度：困難
來源：原創（拓樸排序 + 動態規劃：DAG 最長路徑）

== 題目 ==
給定一個含 n 個節點、m 條有向邊的「有向無環圖」，求圖中最長路徑經過的邊數。

輸入說明：每組第一行 n m，接著 m 行each 兩個整數 u v (代表邊 u→v)。n=0 且 m=0 表示輸入結束。
輸出說明：每組輸出最長路徑的邊數。

== 參考解法 (Python) ==
import sys
from collections import deque

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); m = int(data[idx + 1]); idx += 2
        if n == 0 and m == 0:
            break
        adj = [[] for _ in range(n)]
        indeg = [0] * n
        for _ in range(m):
            u = int(data[idx]); v = int(data[idx + 1]); idx += 2
            adj[u].append(v)
            indeg[v] += 1
        q = deque(i for i in range(n) if indeg[i] == 0)
        order = []
        indeg2 = indeg[:]
        while q:
            u = q.popleft()
            order.append(u)
            for v in adj[u]:
                indeg2[v] -= 1
                if indeg2[v] == 0:
                    q.append(v)
        dp = [0] * n
        for u in order:
            for v in adj[u]:
                dp[v] = max(dp[v], dp[u] + 1)
        out.append(str(max(dp) if dp else 0))
    print('\n'.join(out))

main()

0 1

3 4
4 5
0 0
== 範例 1 輸出 ==
4
