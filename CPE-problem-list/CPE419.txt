CPE Sum of Left Leaves

難度：簡單
來源：原創（二元樹：左葉節點總和）

== 題目 ==
給定一棵二元樹 (陣列表示，節點 0 為根，每個節點有值，left[i]/right[i] 為左右子節點索引，-1 表示不存在)，求所有「左葉節點」(是某節點的左子節點，且本身是葉節點) 的值總和。

輸入說明：每組第一行 n，接著 n 行each 三個整數 (節點 0~n-1 依序的 值、left、right)。n=0 表示輸入結束。
輸出說明：每組輸出左葉節點總和。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        val, left, right = [], [], []
        for _ in range(n):
            val.append(int(data[idx])); left.append(int(data[idx + 1])); right.append(int(data[idx + 2])); idx += 3
        total = [0]

        def dfs(u, is_left):
            if u == -1:
                return
            if left[u] == -1 and right[u] == -1:
                if is_left:
                    total[0] += val[u]
                return
            dfs(left[u], True)
            dfs(right[u], False)

        dfs(0, False)
        out.append(str(total[0]))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
3 1 2
9 -1 -1
20 3 4
15 -1 -1
7 -1 -1
0
== 範例 1 輸出 ==
24

== 範例 2 輸入 ==
1
1 -1 -1
0
== 範例 2 輸出 ==
0
