CPE 計算 0 到 N 的位元數

難度：簡單
來源：原創（動態規劃位元計數）

== 題目 ==
給定整數 n，請對 0 到 n 之間（含）的每個整數，計算其二進位表示中 1 的個數，
依序輸出（以空白分隔）。

輸入每行一個整數 n（0 <= n <= 100000），直到檔案結束。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        dp = [0] * (n + 1)
        for i in range(1, n + 1):
            dp[i] = dp[i >> 1] + (i & 1)
        out.append(' '.join(map(str, dp)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
2
5
== 範例 1 輸出 ==
0 1 1
0 1 1 2 1 2
