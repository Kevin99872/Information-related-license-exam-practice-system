CPE Combinations (Choose K from N)

難度：簡單
來源：原創（回溯法：從 1~N 選出 K 個數的所有組合）

== 題目 ==
給定 n 與 k，列出從 1~n 中選出 k 個數字的所有組合 (每個組合內數字由小到大排列，依字典序輸出)。

輸入說明：每行兩個整數 n k，讀到檔案結尾。
輸出說明：每行輸入先輸出組合總數，接著每行輸出一個組合 (以空白分隔)。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n, k = map(int, line.split())
        results = []

        def backtrack(start, path):
            if len(path) == k:
                results.append(' '.join(map(str, path)))
                return
            for i in range(start, n + 1):
                path.append(i)
                backtrack(i + 1, path)
                path.pop()

        backtrack(1, [])
        out.append(str(len(results)))
        out.extend(results)
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4 2
== 範例 1 輸出 ==
6
1 2
1 3
1 4
2 3
2 4
3 4

== 範例 2 輸入 ==
3 3
== 範例 2 輸出 ==
1
1 2 3
