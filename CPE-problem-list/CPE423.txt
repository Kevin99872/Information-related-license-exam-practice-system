CPE Pascal's Triangle (Full)

難度：簡單
來源：原創（巴斯卡三角形 (完整前 n 列)）

== 題目 ==
給定 n，輸出巴斯卡三角形的前 n+1 列 (第 0 列到第 n 列)。

輸入說明：每行一個整數 n (0<=n<=20)，讀到檔案結尾。
輸出說明：每組輸出 n+1 行，每行為對應列的二項式係數 (以空白分隔)；組與組之間空一行。

== 參考解法 (Python) ==
import sys

def main():
    blocks = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        rows = [[1]]
        for i in range(1, n + 1):
            prev = rows[-1]
            row = [1] + [prev[j] + prev[j + 1] for j in range(len(prev) - 1)] + [1]
            rows.append(row)
        blocks.append('\n'.join(' '.join(map(str, r)) for r in rows))
    print('\n\n'.join(blocks))

main()

== 範例 1 輸入 ==
4
== 範例 1 輸出 ==
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1

== 範例 2 輸入 ==
0
== 範例 2 輸出 ==
1
