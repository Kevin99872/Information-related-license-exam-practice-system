CPE Merge K Sorted Arrays

難度：中等
來源：原創（最小堆積：合併 K 個已排序陣列）

== 題目 ==
給定 k 個已由小到大排序的陣列，將它們合併成一個排序陣列 (使用最小堆積)。

輸入說明：每組第一行為 k，接著 k 行each 一個已排序陣列 (以空白分隔)。k=0 表示輸入結束。
輸出說明：每組輸出合併後的完整排序陣列 (以空白分隔)。

== 參考解法 (Python) ==
import sys
import heapq

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        k = int(line)
        if k == 0:
            break
        arrays = []
        for _ in range(k):
            arrays.append(list(map(int, data[idx].split()))); idx += 1
        heap = [(arr[0], i, 0) for i, arr in enumerate(arrays) if arr]
        heapq.heapify(heap)
        result = []
        while heap:
            val, ai, ei = heapq.heappop(heap)
            result.append(val)
            if ei + 1 < len(arrays[ai]):
                heapq.heappush(heap, (arrays[ai][ei + 1], ai, ei + 1))
        out.append(' '.join(map(str, result)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3
1 4 7
2 5
3 6 8 9
0
== 範例 1 輸出 ==
1 2 3 4 5 6 7 8 9

== 範例 2 輸入 ==
2
1 2 3
1 2 3
0
== 範例 2 輸出 ==
1 1 2 2 3 3
