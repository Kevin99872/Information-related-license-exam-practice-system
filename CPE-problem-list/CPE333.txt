CPE Single Number II

難度：中等
來源：原創（位元運算：找出恰出現一次的數字 (其餘皆出現三次)）

== 題目 ==
給定 n 個「非負」整數，除了「恰好一個」數字只出現一次外，其餘每個數字都恰好出現三次，求那個只出現一次的數字。

輸入說明：每組第一行 n，第二行 n 個非負整數。n=0 表示輸入結束。
輸出說明：每組輸出只出現一次的數字。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        ones = twos = 0
        for x in a:
            ones = (ones ^ x) & ~twos
            twos = (twos ^ x) & ~ones
        out.append(str(ones))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
2 2 3 2 5
0
== 範例 1 輸出 ==
6

== 範例 2 輸入 ==
7
0 1 0 1 0 1 99
0
== 範例 2 輸出 ==
99
