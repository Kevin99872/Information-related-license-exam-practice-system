CPE Island Count

難度：中等
來源：原創（DFS 連通區塊 / 島嶼數量經典題型）

== 題目 ==
給定 R*C 的地圖，'1' 代表陸地、'0' 代表海洋。上下左右相鄰的陸地視為同一座島嶼，求島嶼的數量。

輸入說明：每組第一行 R C，接著 R 行each C 個字元 (只含 '0'、'1')。R=0 且 C=0 表示輸入結束。
輸出說明：每組輸出島嶼數量。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        r, c = map(int, line.split())
        if r == 0 and c == 0:
            break
        grid = [data[idx + i] for i in range(r)]
        idx += r
        visited = [[False] * c for _ in range(r)]

        def flood(si, sj):
            stack = [(si, sj)]
            visited[si][sj] = True
            while stack:
                x, y = stack.pop()
                for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < r and 0 <= ny < c and not visited[nx][ny] and grid[nx][ny] == '1':
                        visited[nx][ny] = True
                        stack.append((nx, ny))

        count = 0
        for i in range(r):
            for j in range(c):
                if grid[i][j] == '1' and not visited[i][j]:
                    count += 1
                    flood(i, j)
        out.append(str(count))
    print('\n'.join(out))

main()
