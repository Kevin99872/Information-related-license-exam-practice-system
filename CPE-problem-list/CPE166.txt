CPE 10763 Foreign Exchange

難度：簡單
來源：改編自 UVa Online Judge #10763 (CPE 大學程式能力檢定經典題)

== 題目 ==
有 n 位交換學生，每人填寫「原本所在地」與「想去的地點」。若每個「A 想去 B」都能找到對應的「B 想去 A」(數量也要吻合)，則交換計畫可行。

輸入說明：每組第一行 n，接著 n 行each 兩個整數 (原地點、目標地點)。n=0 表示輸入結束。
輸出說明：每組輸出 YES 或 NO。

== 參考解法 (Python) ==
import sys
from collections import Counter

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        pairs = Counter()
        for _ in range(n):
            a = int(data[idx]); b = int(data[idx + 1]); idx += 2
            pairs[(a, b)] += 1
        ok = all(pairs[(a, b)] == pairs[(b, a)] for a, b in pairs)
        out.append('YES' if ok else 'NO')
    print('\n'.join(out))

main()
