CPE Set Matrix Zeroes

難度：中等
來源：原創（矩陣歸零：若某格為 0 則整列整行歸零）

== 題目 ==
給定 R*C 矩陣，若某個元素為 0，則將該元素所在的整列與整行都設為 0 (需基於原始矩陣判斷，而非逐步套用中間結果)。

輸入說明：每組第一行 R C，接著 R 行each C 個整數。R=0 且 C=0 表示輸入結束。
輸出說明：每組輸出處理後的矩陣 (R 行each C 個整數)；組與組之間空一行。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    blocks = []
    while idx < len(data):
        r = int(data[idx]); c = int(data[idx + 1]); idx += 2
        if r == 0 and c == 0:
            break
        grid = []
        for i in range(r):
            grid.append([int(data[idx + j]) for j in range(c)])
            idx += c
        rows, cols = set(), set()
        for i in range(r):
            for j in range(c):
                if grid[i][j] == 0:
                    rows.add(i)
                    cols.add(j)
        for i in range(r):
            for j in range(c):
                if i in rows or j in cols:
                    grid[i][j] = 0
        blocks.append('\n'.join(' '.join(map(str, row)) for row in grid))
    print('\n\n'.join(blocks))

main()

== 範例 1 輸入 ==
3 3
1 1 1
1 0 1
1 1 1
0 0
== 範例 1 輸出 ==
1 0 1
0 0 0
1 0 1

== 範例 2 輸入 ==
2 2
1 2
3 4
0 0
== 範例 2 輸出 ==
1 2
3 4
