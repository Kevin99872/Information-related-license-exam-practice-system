CPE Determinant of a Square Matrix

難度：困難
來源：原創（行列式 (餘因子展開)）

== 題目 ==
給定一個 n*n 矩陣 (n<=6)，求其行列式 (determinant) 的值。

輸入說明：每組第一行 n，接著 n 行each n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出行列式的值。

== 參考解法 (Python) ==
import sys

def det(m):
    n = len(m)
    if n == 1:
        return m[0][0]
    if n == 2:
        return m[0][0] * m[1][1] - m[0][1] * m[1][0]
    total = 0
    for j in range(n):
        minor = [row[:j] + row[j + 1:] for row in m[1:]]
        sign = 1 if j % 2 == 0 else -1
        total += sign * m[0][j] * det(minor)
    return total

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        m = [[int(data[idx + i * n + j]) for j in range(n)] for i in range(n)]
        idx += n * n
        out.append(str(det(m)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
2
1 2
3 4
0
== 範例 1 輸出 ==
-2

== 範例 2 輸入 ==

6 1 1
4 -2 5
2 8 7
0
== 範例 2 輸出 ==
