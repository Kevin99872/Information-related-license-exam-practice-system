CPE Majority Element

難度：簡單
來源：原創（Boyer-Moore 多數投票演算法）

== 題目 ==
給定 n 個整數，若存在一個數字出現次數「超過」n/2 次，輸出該數字；否則輸出 none。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出多數元素，或 none。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        nums = [int(data[idx + i]) for i in range(n)]
        idx += n
        cand = None
        count = 0
        for x in nums:
            if count == 0:
                cand = x
                count = 1
            elif x == cand:
                count += 1
            else:
                count -= 1
        out.append(str(cand) if nums.count(cand) > n // 2 else 'none')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
7
2 2 1 1 1 2 2
0
== 範例 1 輸出 ==
2

== 範例 2 輸入 ==
4
1 2 3 4
0
== 範例 2 輸出 ==
none
