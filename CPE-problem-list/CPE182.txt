CPE Climbing Stairs Ways

難度：簡單
來源：原創（動態規劃：爬樓梯走法數）

== 題目 ==
爬一座有 n 階的樓梯，每步可以走 1 階或 2 階，求走到頂端共有幾種不同的走法。

輸入說明：每行一個整數 n (1<=n<=80)，讀到檔案結尾。
輸出說明：每行輸出走法總數。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        a, b = 1, 1
        for _ in range(n):
            a, b = b, a + b
        out.append(str(a))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
2
3
== 範例 1 輸出 ==
2
3

== 範例 2 輸入 ==
5
10
== 範例 2 輸出 ==
8
89
