CPE Add Two Numbers (Linked List Simulation)

難度：簡單
來源：原創（鏈結串列模擬：逆序儲存數字相加）

== 題目 ==
兩個非負整數分別以「逆序」的鏈結串列表示 (個位數在前，以逗號分隔的數字序列表示)，求兩數之和，同樣以逆序、逗號分隔的形式輸出。

輸入說明：每行兩個以空白分隔的逆序數字序列 (各數字以逗號分隔)，讀到檔案結尾。
輸出說明：每行輸出兩數之和的逆序表示 (逗號分隔)。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        a, b = line.split()
        digits_a = list(map(int, a.split(',')))
        digits_b = list(map(int, b.split(',')))
        carry = 0
        result = []
        i = j = 0
        while i < len(digits_a) or j < len(digits_b) or carry:
            x = digits_a[i] if i < len(digits_a) else 0
            y = digits_b[j] if j < len(digits_b) else 0
            s = x + y + carry
            result.append(str(s % 10))
            carry = s // 10
            i += 1
            j += 1
        out.append(','.join(result))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
2,4,3 5,6,4
9,9 1
== 範例 1 輸出 ==
7,0,8
0,0,1

== 範例 2 輸入 ==
0 0
== 範例 2 輸出 ==
0
