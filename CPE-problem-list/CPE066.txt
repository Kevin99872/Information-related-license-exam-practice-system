== 題目 ==
地球半徑為 6440 公里，兩顆同軌道衛星與地心夾角為 a (可能以「度」或「分」給定)，衛星距地表高度為 s 公里。求兩衛星之間的弧長距離與弦長距離 (皆為公里)。

輸入說明：每行三個值 s a unit，unit 為 "deg" (度) 或 "min" (分)，讀到檔案結尾。
輸出說明：每行輸出弧長與弦長，四捨五入到小數點後 6 位，以空白分隔。

== 參考解法 (Python) ==
import sys
import math

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    r_earth = 6440.0
    while idx < len(data):
        s = float(data[idx]); a = float(data[idx + 1]); unit = data[idx + 2]
        idx += 3
        deg = a / 60.0 if unit == 'min' else a
        theta = math.radians(deg)
        r = r_earth + s
        arc = r * theta
        chord = 2 * r * math.sin(theta / 2)
        out.append(f"{arc:.6f} {chord:.6f}")
    print('\n'.join(out))

main()
