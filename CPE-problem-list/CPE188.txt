CPE Move Zeroes to End

難度：簡單
來源：原創（陣列分割：0 移到尾端）

== 題目 ==
給定 n 個整數，將所有非 0 元素依原本的相對順序移到前面，所有 0 移到後面。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出調整後的陣列 (以空白分隔)。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        nums = [int(data[idx + i]) for i in range(n)]
        idx += n
        nonzero = [x for x in nums if x != 0]
        result = nonzero + [0] * (n - len(nonzero))
        out.append(' '.join(map(str, result)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
6
0 1 0 3 12 0
0
== 範例 1 輸出 ==
1 3 12 0 0 0

== 範例 2 輸入 ==
4
1 2 3 4
0
== 範例 2 輸出 ==
1 2 3 4
