CPE Strong Number

難度：簡單
來源：原創（靈感來自 Strong Number / Krishnamurthy Number 經典數論主題）

== 題目 ==
若一個正整數「每一位數字的階乘」總和等於原數字本身，稱為強數 (Strong Number)。例如 145 = 1! + 4! + 5! = 1 + 24 + 120 = 145。

輸入說明：每行一個正整數 n (1<=n<=100000)，以 0 結束 (不處理)。
輸出說明：是強數輸出 N is a Strong Number.，否則輸出 N is not a Strong Number.

== 參考解法 (Python) ==
import sys

FACT = [1] * 10
for i in range(1, 10):
    FACT[i] = FACT[i - 1] * i

for line in sys.stdin:
    line = line.strip()
    if not line:
        continue
    n = int(line)
    if n == 0:
        break
    total = sum(FACT[int(d)] for d in str(n))
    if total == n:
        print(f"{n} is a Strong Number.")
    else:
        print(f"{n} is not a Strong Number.")

== 範例 1 輸入 ==
145
1
2
0
== 範例 1 輸出 ==
145 is a Strong Number.
1 is a Strong Number.
2 is a Strong Number.

== 範例 2 輸入 ==
40585
123
0
== 範例 2 輸出 ==
40585 is a Strong Number.
123 is not a Strong Number.
