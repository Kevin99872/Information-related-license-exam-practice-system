CPE 10919 Prerequisites?

難度：簡單
來源：改編自 UVa Online Judge #10919 (CPE 大學程式能力檢定經典題)

== 題目 ==
Freddie 選了 k 門課，畢業條件分成 m 個類別，每個類別要求「至少」修 r 門屬於該類別的課程 (類別內共列出 c 門課程供選)。判斷 Freddie 的選課是否能滿足全部類別的畢業條件。

輸入說明：每組第一行 k m，第二行 k 個 4 位數課程編號 (Freddie 選的課)；接著 m 個類別，每個類別第一行為 c r，接著 c 個 4 位數課程編號。k=0 表示輸入結束。
輸出說明：每組輸出 yes 或 no。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        k = int(data[idx]); idx += 1
        if k == 0:
            break
        m = int(data[idx]); idx += 1
        taken = set(data[idx + i] for i in range(k))
        idx += k
        ok = True
        for _ in range(m):
            c = int(data[idx]); r = int(data[idx + 1]); idx += 2
            courses = [data[idx + i] for i in range(c)]
            idx += c
            cnt = sum(1 for course in courses if course in taken)
            if cnt < r:
                ok = False
        out.append('yes' if ok else 'no')
    print('\n'.join(out))

main()
