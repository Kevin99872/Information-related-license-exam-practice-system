CPE Spiral Matrix Traversal

難度：中等
來源：原創（螺旋矩陣走訪）

== 題目 ==
給定 R*C 矩陣，依「順時針螺旋」順序輸出所有元素。

輸入說明：每組第一行 R C，接著 R 行each C 個整數。R=0 且 C=0 表示輸入結束。
輸出說明：每組輸出一行，依螺旋順序列出所有元素 (以空白分隔)。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        r = int(data[idx]); c = int(data[idx + 1]); idx += 2
        if r == 0:
            break
        grid = []
        for i in range(r):
            grid.append([int(data[idx + j]) for j in range(c)])
            idx += c
        res = []
        top, bottom, left, right = 0, r - 1, 0, c - 1
        while top <= bottom and left <= right:
            for j in range(left, right + 1):
                res.append(grid[top][j])
            top += 1
            for i in range(top, bottom + 1):
                res.append(grid[i][right])
            right -= 1
            if top <= bottom:
                for j in range(right, left - 1, -1):
                    res.append(grid[bottom][j])
                bottom -= 1
            if left <= right:
                for i in range(bottom, top - 1, -1):
                    res.append(grid[i][left])
                left += 1
        out.append(' '.join(map(str, res)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3 3
1 2 3
4 5 6
7 8 9
0 0
== 範例 1 輸出 ==
1 2 3 6 9 8 7 4 5

== 範例 2 輸入 ==
2 4
1 2 3 4
5 6 7 8
0 0
== 範例 2 輸出 ==
1 2 3 4 8 7 6 5
