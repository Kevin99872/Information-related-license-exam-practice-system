CPE Next Greater Element (Circular Array)

難度：中等
來源：原創（單調堆疊：環狀陣列的下一個更大元素）

== 題目 ==
給定一個「環狀」陣列 (最後一個元素的下一個是第一個元素)，對每個元素求「沿環狀方向」第一個比它大的元素；若不存在則輸出 -1。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出結果 (以空白分隔)。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        res = [-1] * n
        stack = []
        for i in range(2 * n):
            cur = i % n
            while stack and a[stack[-1]] < a[cur]:
                res[stack.pop()] = a[cur]
            if i < n:
                stack.append(cur)
        out.append(' '.join(map(str, res)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4
1 2 1 2
0
== 範例 1 輸出 ==
2 -1 2 -1

== 範例 2 輸入 ==
3
5 4 3
0
== 範例 2 輸出 ==
-1 5 5
