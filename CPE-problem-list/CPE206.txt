CPE 495 Fibonacci Freeze

難度：簡單
來源：改編自 UVa Online Judge #495 (CPE 大學程式能力檢定經典題)

== 題目 ==
計算費波那契數列第 n 項 (F0=0, F1=1)。由於 n 可能高達 5000，結果可能是超大整數。

輸入說明：每行一個整數 n (0<=n<=5000)，讀到檔案結尾。
輸出說明：每行輸出 "The Fibonacci number for n is F"。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        a, b = 0, 1
        for _ in range(n):
            a, b = b, a + b
        out.append(f"The Fibonacci number for {n} is {a}")
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
7
11
== 範例 1 輸出 ==
The Fibonacci number for 5 is 5
The Fibonacci number for 7 is 13
The Fibonacci number for 11 is 89

== 範例 2 輸入 ==
0
1
== 範例 2 輸出 ==
The Fibonacci number for 0 is 0
The Fibonacci number for 1 is 1
