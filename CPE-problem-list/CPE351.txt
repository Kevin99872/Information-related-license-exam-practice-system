CPE Maximal Square

難度：中等
來源：原創（動態規劃：矩陣中最大正方形面積）

== 題目 ==
給定一個由 '0'、'1' 組成的 R*C 矩陣，求只由 '1' 構成的最大正方形的面積。

輸入說明：每組第一行 R C，接著 R 行each C 個字元。R=0 且 C=0 表示輸入結束。
輸出說明：每組輸出最大正方形面積。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        r, c = map(int, line.split())
        if r == 0 and c == 0:
            break
        grid = [data[idx + i] for i in range(r)]
        idx += r
        dp = [[0] * c for _ in range(r)]
        best = 0
        for i in range(r):
            for j in range(c):
                if grid[i][j] == '1':
                    if i == 0 or j == 0:
                        dp[i][j] = 1
                    else:
                        dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1
                    best = max(best, dp[i][j])
        out.append(str(best * best))
    print('\n'.join(out))

main()
