CPE Best Time to Buy and Sell Stock with Cooldown

難度：中等
來源：原創（動態規劃：股票買賣含冷卻期）

== 題目 ==
給定 n 天的股票價格，可進行任意多次買賣 (同時最多持有一股)，但賣出後的隔一天不能買進 (冷卻期 1 天)，求最大總利潤。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出最大總利潤。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        prices = [int(data[idx + i]) for i in range(n)]
        idx += n
        hold = -prices[0]
        sold = 0
        rest = 0
        for i in range(1, n):
            prev_sold = sold
            sold = hold + prices[i]
            hold = max(hold, rest - prices[i])
            rest = max(rest, prev_sold)
        out.append(str(max(sold, rest)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
1 2 3 0 2
0
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
1
1
0
== 範例 2 輸出 ==
0
