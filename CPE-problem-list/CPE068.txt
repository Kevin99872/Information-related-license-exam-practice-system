== 題目 ==
給定一份樹木觀測清單 (每行一個樹種名稱)，計算每個樹種佔總數的百分比。

輸入說明：第一行為測試個數，之後空一行；每組資料為多行樹種名稱 (每行一種，最多 30 字元)，資料結尾以空行與下一組分隔。
輸出說明：每組依樹種名稱字母順序輸出 "樹種名稱 百分比" (百分比四捨五入到小數點後 4 位)；組與組之間空一行。

== 參考解法 (Python) ==
import sys
from collections import Counter

def main():
    blocks = sys.stdin.read().split('\n')
    idx = 0
    while idx < len(blocks) and blocks[idx].strip() == '':
        idx += 1
    t = int(blocks[idx].strip()); idx += 1
    out = []
    for case in range(t):
        while idx < len(blocks) and blocks[idx].strip() == '':
            idx += 1
        species = []
        while idx < len(blocks) and blocks[idx].strip() != '':
            species.append(blocks[idx].strip())
            idx += 1
        if case > 0:
            out.append('')
        c = Counter(species)
        total = len(species)
        for name in sorted(c):
            pct = c[name] / total * 100
            out.append(f"{name} {pct:.4f}")
    print('\n'.join(out))

main()
