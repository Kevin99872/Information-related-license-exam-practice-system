CPE Third Maximum Number

難度：簡單
來源：原創（陣列：第三大的相異數字）

== 題目 ==
給定 n 個整數，求「第三大」的相異數字；若相異數字不足 3 個，則輸出最大的數字。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出結果。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        distinct = sorted(set(a), reverse=True)
        out.append(str(distinct[2]) if len(distinct) >= 3 else str(distinct[0]))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3
3 2 1
0
== 範例 1 輸出 ==
1

== 範例 2 輸入 ==
2
1 2
0
== 範例 2 輸出 ==
2
