CPE Chinese Remainder Theorem

難度：中等
來源：原創（中國剩餘定理 (兩個同餘方程)）

== 題目 ==
給定兩個同餘方程 x≡a1 (mod m1)、x≡a2 (mod m2) (保證 m1、m2 互質)，求滿足兩式的「最小非負整數」x。

輸入說明：每行四個整數 a1 m1 a2 m2 (m1、m2 互質)，讀到檔案結尾。
輸出說明：每行輸出最小非負整數解 x。

== 參考解法 (Python) ==
import sys

def ext_gcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x1, y1 = ext_gcd(b, a % b)
    return g, y1, x1 - (a // b) * y1

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        a1, m1, a2, m2 = map(int, line.split())
        g, p, q = ext_gcd(m1, m2)
        lcm = m1 * m2
        diff = a2 - a1
        x = (a1 + m1 * (diff * p % m2)) % lcm
        out.append(str(x))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
2 3 3 5
== 範例 1 輸出 ==
8

== 範例 2 輸入 ==
1 4 3 7
== 範例 2 輸出 ==
17
