CPE 10057 A mid-summer night's dream

難度：困難
來源：改編自 UVa Online Judge #10057 (CPE 大學程式能力檢定經典題)

== 題目 ==
給定 n 個整數 X1,...,Xn，找出整數 A 使得 |X1-A|+|X2-A|+...+|Xn-A| 最小。若有多個 A 都能使總和最小，取「最小」的那個 A。

輸出三個數：(1) 使總和最小的最小整數 A；(2) 輸入中「數值等於 A」的個數；(3) 使總和達到最小值的相異整數 A 共有幾個 (不需要真的出現在輸入中)。

輸入說明：每個 case 第一行為 n (0<n<=1000000)，第二行為 n 個整數 (每個小於 65536)，讀到檔案結尾。
輸出說明：每個 case 輸出一行，依序為上述三個數，以空白分隔。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        arr = list(map(int, data[idx:idx + n]))
        idx += n
        arr.sort()
        if n % 2 == 1:
            lower = upper = arr[n // 2]
        else:
            lower = arr[n // 2 - 1]
            upper = arr[n // 2]
        a = lower
        count = arr.count(a)
        distinct = upper - lower + 1
        out.append(f"{a} {count} {distinct}")
    print('\n'.join(out))

main()
