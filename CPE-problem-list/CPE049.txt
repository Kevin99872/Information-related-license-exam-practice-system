CPE Longest Increasing Subsequence

難度：困難
來源：原創（動態規劃：最長遞增子序列經典題型）

== 題目 ==
給定一個整數序列，求其「嚴格遞增」最長子序列的長度 (子序列不要求連續)。

輸入說明：每組第一行為 n；第二行為 n 個整數。以 n=0 結束 (不處理)。
輸出說明：每組輸出最長遞增子序列的長度。

== 參考解法 (Python) ==
import sys
import bisect

data = sys.stdin.read().split('\n')
idx = 0
out = []
while idx < len(data):
    line = data[idx].strip()
    idx += 1
    if line == '':
        continue
    n = int(line)
    if n == 0:
        break
    nums = list(map(int, data[idx].split()))
    idx += 1
    tails = []
    for x in nums:
        pos = bisect.bisect_left(tails, x)
        if pos == len(tails):
            tails.append(x)
        else:
            tails[pos] = x
    out.append(str(len(tails)))
print('\n'.join(out))

0
== 範例 1 輸出 ==
4
