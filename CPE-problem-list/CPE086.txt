CPE Circular Queue Simulation

難度：中等
來源：原創（環狀佇列模擬）

== 題目 ==
模擬一個容量為 k 的佇列，支援以下指令：
ENQUEUE x：加入元素 x，若佇列已滿則輸出 full
DEQUEUE：移除並輸出隊首元素，若佇列為空則輸出 empty
FRONT：輸出目前隊首元素 (不移除)，若佇列為空則輸出 empty

輸入說明：每組第一行 k m (容量、指令數)，接著 m 行指令。k=0 且 m=0 表示輸入結束。
輸出說明：依序輸出每個 DEQUEUE / FRONT 指令的結果，以及每個失敗的 ENQUEUE 指令的 full。

== 參考解法 (Python) ==
import sys
from collections import deque

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip()
        idx += 1
        if line == '':
            continue
        k, m = map(int, line.split())
        if k == 0:
            break
        q = deque()
        for _ in range(m):
            parts = data[idx].split()
            idx += 1
            cmd = parts[0]
            if cmd == 'ENQUEUE':
                if len(q) >= k:
                    out.append('full')
                else:
                    q.append(parts[1])
            elif cmd == 'DEQUEUE':
                out.append(q.popleft() if q else 'empty')
            elif cmd == 'FRONT':
                out.append(q[0] if q else 'empty')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
2 5
ENQUEUE 1
ENQUEUE 2
ENQUEUE 3
FRONT
DEQUEUE
0 0
== 範例 1 輸出 ==
full
1
1

== 範例 2 輸入 ==

DEQUEUE
ENQUEUE 9
FRONT
0 0
== 範例 2 輸出 ==
