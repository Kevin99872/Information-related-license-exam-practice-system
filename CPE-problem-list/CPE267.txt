CPE Sliding Window Maximum (Deque)

難度：中等
來源：原創（單調佇列：滑動視窗最大值）

== 題目 ==
給定 n 個整數與視窗大小 k，求每個「連續 k 個元素」視窗中的最大值 (使用單調佇列，O(n) 求解)。

輸入說明：每組第一行 n k，第二行 n 個整數。n=0 且 k=0 表示輸入結束。
輸出說明：每組輸出所有視窗的最大值 (以空白分隔)。

== 參考解法 (Python) ==
import sys
from collections import deque

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); k = int(data[idx + 1]); idx += 2
        if n == 0 and k == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        dq = deque()
        res = []
        for i in range(n):
            while dq and a[dq[-1]] <= a[i]:
                dq.pop()
            dq.append(i)
            if dq[0] <= i - k:
                dq.popleft()
            if i >= k - 1:
                res.append(a[dq[0]])
        out.append(' '.join(map(str, res)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
8 3
1 3 -1 -3 5 3 6 7
0 0
== 範例 1 輸出 ==
3 3 5 5 6 7

== 範例 2 輸入 ==
5 1
4 3 2 1 5
0 0
== 範例 2 輸出 ==
4 3 2 1 5
