CPE Hamming Distance

難度：簡單
來源：原創（位元運算：兩整數的漢明距離）

== 題目 ==
給定兩個非負整數，求其二進位表示中不同位元的個數 (漢明距離)。

輸入說明：每行兩個非負整數，讀到檔案結尾。
輸出說明：每行輸出漢明距離。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        x, y = map(int, line.split())
        out.append(str(bin(x ^ y).count('1')))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4 1
0 0
== 範例 1 輸出 ==
2
0

== 範例 2 輸入 ==
1 4
== 範例 2 輸出 ==
2
