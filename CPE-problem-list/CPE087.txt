CPE Next Greater Element

難度：中等
來源：原創（單調堆疊 / Next Greater Element）

== 題目 ==
給定一個陣列，對每個元素求「其右側第一個比它大」的元素；若不存在則輸出 -1。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 結束。
輸出說明：每組輸出一行，依序列出每個元素對應的答案，以空白分隔。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        nums = [int(data[idx + i]) for i in range(n)]
        idx += n
        res = [-1] * n
        stack = []
        for i in range(n):
            while stack and nums[stack[-1]] < nums[i]:
                res[stack.pop()] = nums[i]
            stack.append(i)
        out.append(' '.join(map(str, res)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4
2 1 2 4
0
== 範例 1 輸出 ==
4 2 4 -1

== 範例 2 輸入 ==
5
5 4 3 2 1
0
== 範例 2 輸出 ==
-1 -1 -1 -1 -1
