CPE Job Sequencing with Deadlines

難度：中等
來源：原創（貪心：工作排程與截止時間）

== 題目 ==
給定 n 個工作，每個工作有截止時間 deadline 與利潤 profit，每個工作需要 1 單位時間完成，且必須在其 deadline 之前 (含) 完成 (同一時間只能做一個工作)。求可獲得的最大總利潤 (可以放棄部分工作)。

輸入說明：每組第一行 n，接著 n 行each 兩個整數 deadline profit。n=0 表示輸入結束。
輸出說明：每組輸出最大總利潤。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        jobs = []
        maxd = 0
        for _ in range(n):
            d = int(data[idx]); p = int(data[idx + 1]); idx += 2
            jobs.append((d, p))
            maxd = max(maxd, d)
        jobs.sort(key=lambda x: -x[1])
        slot = [False] * (maxd + 1)
        total = 0
        for d, p in jobs:
            for t in range(min(d, maxd), 0, -1):
                if not slot[t]:
                    slot[t] = True
                    total += p
                    break
        out.append(str(total))
    print('\n'.join(out))

main()
