CPE Minimum Path Sum in Grid

難度：簡單
來源：原創（動態規劃：格子最小路徑和）

== 題目 ==
給定 R*C 的非負整數矩陣，從左上角走到右下角 (每步只能向右或向下)，求路徑上所有數字總和的最小值。

輸入說明：每組第一行 R C，接著 R 行each C 個非負整數。R=0 且 C=0 表示輸入結束。
輸出說明：每組輸出最小路徑總和。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        r = int(data[idx]); c = int(data[idx + 1]); idx += 2
        if r == 0 and c == 0:
            break
        grid = []
        for i in range(r):
            grid.append([int(data[idx + j]) for j in range(c)])
            idx += c
        dp = [[0] * c for _ in range(r)]
        for i in range(r):
            for j in range(c):
                if i == 0 and j == 0:
                    dp[i][j] = grid[i][j]
                elif i == 0:
                    dp[i][j] = dp[i][j - 1] + grid[i][j]
                elif j == 0:
                    dp[i][j] = dp[i - 1][j] + grid[i][j]
                else:
                    dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]
        out.append(str(dp[r - 1][c - 1]))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3 3
1 3 1
1 5 1
4 2 1
0 0
== 範例 1 輸出 ==
7

== 範例 2 輸入 ==
1 3
1 2 3
0 0
== 範例 2 輸出 ==
6
