CPE Subarray Sum Equals K

難度：中等
來源：原創（前綴和 + 雜湊表：子陣列和等於 K 的個數）

== 題目 ==
給定 n 個整數 (可能為負) 與目標值 k，求總和恰為 k 的連續子陣列個數。

輸入說明：每組第一行 n k，第二行 n 個整數。n=0 且 k=0 表示輸入結束。
輸出說明：每組輸出符合條件的子陣列個數。

== 參考解法 (Python) ==
import sys
from collections import defaultdict

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); k = int(data[idx + 1]); idx += 2
        if n == 0 and k == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        count = defaultdict(int)
        count[0] = 1
        cur = 0
        total = 0
        for x in a:
            cur += x
            total += count[cur - k]
            count[cur] += 1
        out.append(str(total))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5 2
1 1 1 1 1
0 0
== 範例 1 輸出 ==
4

== 範例 2 輸入 ==
4 0
1 -1 1 -1
0 0
== 範例 2 輸出 ==
4
