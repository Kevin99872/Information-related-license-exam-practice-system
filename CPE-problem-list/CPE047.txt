CPE Narcissistic Numbers

難度：簡單
來源：原創（水仙花數經典數論主題）

== 題目 ==
水仙花數 (Narcissistic Number / Armstrong Number)：一個 d 位數，其每位數字的 d 次方和等於原數字本身。求區間 [a,b] 內水仙花數的個數。

輸入說明：每行兩個整數 a 與 b (1<=a<=b<=1000000)，處理到檔案結尾。
輸出說明：每行輸出個數。

== 參考解法 (Python) ==
import sys

for line in sys.stdin:
    line = line.strip()
    if not line:
        continue
    a, b = map(int, line.split())
    count = 0
    for n in range(a, b + 1):
        digits = str(n)
        d = len(digits)
        if sum(int(c) ** d for c in digits) == n:
            count += 1
    print(count)

== 範例 1 輸入 ==
1 10
1 1000
== 範例 1 輸出 ==
9
13

== 範例 2 輸入 ==
100 10000
9 9
== 範例 2 輸出 ==
7
1
