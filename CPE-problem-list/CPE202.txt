CPE Permutation in String

難度：中等
來源：原創（滑動視窗：字串排列比對）

== 題目 ==
給定字串 s1、s2，判斷 s2 中是否存在一段「連續」子字串是 s1 的某種排列 (anagram)。

輸入說明：每行兩個以空白分隔的字串 s1 s2，讀到檔案結尾。
輸出說明：每行輸出 Yes 或 No。

== 參考解法 (Python) ==
import sys
from collections import Counter

def main():
    out = []
    for line in sys.stdin:
        line = line.rstrip('\n')
        if not line:
            continue
        s1, s2 = line.split()
        n, m = len(s1), len(s2)
        if n > m:
            out.append('No')
            continue
        need = Counter(s1)
        window = Counter(s2[:n])
        found = window == need
        for i in range(n, m):
            window[s2[i]] += 1
            left = s2[i - n]
            window[left] -= 1
            if window[left] == 0:
                del window[left]
            if window == need:
                found = True
                break
        out.append('Yes' if found else 'No')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
ab eidbaooo
ab eidboaoo
== 範例 1 輸出 ==
Yes
No

== 範例 2 輸入 ==
abc cba
== 範例 2 輸出 ==
Yes
