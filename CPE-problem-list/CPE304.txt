CPE 574 Sum It Up

難度：中等
來源：改編自 UVa Online Judge #574 (CPE 大學程式能力檢定經典題)

== 題目 ==
給定目標總和 t 與 n 個整數 (由大到小給定，可能重複)，找出所有「使用清單中的數字 (可依清單中出現次數重複使用)」加總恰為 t 的相異組合。

輸入說明：每行為一筆資料：t n 接著 n 個整數 (由大到小)。n=0 表示輸入結束。
輸出說明：每組先輸出 "Sums of t:"；接著依「組合內數字由大到小排列、組合之間依第一個數字由大到小、其後數字依序比較」的順序輸出各組合 (數字間以 '+' 相連)；若無解輸出 NONE。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        t = int(data[idx]); n = int(data[idx + 1]); idx += 2
        if n == 0:
            break
        nums = [int(data[idx + i]) for i in range(n)]
        idx += n
        results = []

        def backtrack(start, remain, path):
            if remain == 0:
                results.append(list(path))
                return
            for i in range(start, n):
                if nums[i] > remain:
                    continue
                if i > start and nums[i] == nums[i - 1]:
                    continue
                path.append(nums[i])
                backtrack(i + 1, remain - nums[i], path)
                path.pop()

        backtrack(0, t, [])
        out.append(f"Sums of {t}:")
        if not results:
            out.append('NONE')
        else:
            for r in results:
                out.append('+'.join(map(str, r)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4 6 4 3 2 2 1 1
5 3 2 1 1

0 0

Sums of 4:
4
3+1

2+1+1
Sums of 5:
NONE
Sums of 400:
50+50+50+50+50+50+25+25+25+25
50+50+50+50+50+25+25+25+25+25+25

== 範例 2 輸入 ==
10 4 5 5 3 3

== 範例 2 輸出 ==
Sums of 10:
5+5
