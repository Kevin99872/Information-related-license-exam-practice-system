CPE 386 Perfect Cubes

難度：簡單
來源：改編自 UVa Online Judge #386 (CPE 大學程式能力檢定經典題)

== 題目 ==
求所有滿足 a^3 = b^3 + c^3 + d^3 (1 < b <= c <= d < a) 且 a 不超過給定上限的整數組合，依 a 由小到大 (相同 a 時依 b 由小到大) 輸出。

輸入說明：每行一個整數 max_a (上限，2<=max_a<=200)，讀到檔案結尾。
輸出說明：每行輸出 "Cube = a, Triple = (b,c,d)"。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        max_a = int(line)
        for a in range(2, max_a + 1):
            a3 = a ** 3
            for b in range(2, a):
                b3 = b ** 3
                if b3 >= a3:
                    break
                for c in range(b, a):
                    c3 = c ** 3
                    bc3 = b3 + c3
                    if bc3 >= a3:
                        break
                    d3 = a3 - bc3
                    d = round(d3 ** (1 / 3))
                    for dd in (d - 1, d, d + 1):
                        if dd >= c and dd ** 3 == d3:
                            out.append(f"Cube = {a}, Triple = ({b},{c},{dd})")
                            break
    print('\n'.join(out))

main()
