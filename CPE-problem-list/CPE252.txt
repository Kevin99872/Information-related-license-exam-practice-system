CPE Candy Distribution

難度：中等
來源：原創（貪心：糖果分配經典題型）

== 題目 ==
有 n 個小孩排成一列，每人有一個評分。每人至少分到 1 顆糖果，且評分較高的小孩必須比「左右相鄰」評分較低的小孩拿到更多糖果。求所需糖果總數的最小值。

輸入說明：每組第一行 n，第二行 n 個整數評分。n=0 表示輸入結束。
輸出說明：每組輸出所需糖果總數的最小值。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        ratings = [int(data[idx + i]) for i in range(n)]
        idx += n
        candies = [1] * n
        for i in range(1, n):
            if ratings[i] > ratings[i - 1]:
                candies[i] = candies[i - 1] + 1
        for i in range(n - 2, -1, -1):
            if ratings[i] > ratings[i + 1]:
                candies[i] = max(candies[i], candies[i + 1] + 1)
        out.append(str(sum(candies)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3
1 0 2
0
== 範例 1 輸出 ==
5

== 範例 2 輸入 ==
4
1 2 2 1
0
== 範例 2 輸出 ==
6
