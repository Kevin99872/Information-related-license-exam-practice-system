CPE Sort Colors (Dutch National Flag)

難度：簡單
來源：原創（荷蘭國旗問題：三色排序）

== 題目 ==
給定 n 個元素，每個元素值為 0、1 或 2，將陣列原地排序，使 0 都在前面、1 在中間、2 在後面。

輸入說明：每組第一行 n，第二行 n 個 0/1/2 組成的整數。n=0 表示輸入結束。
輸出說明：每組輸出排序後的陣列 (以空白分隔)。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        low, mid, high = 0, 0, n - 1
        while mid <= high:
            if a[mid] == 0:
                a[low], a[mid] = a[mid], a[low]
                low += 1; mid += 1
            elif a[mid] == 1:
                mid += 1
            else:
                a[mid], a[high] = a[high], a[mid]
                high -= 1
        out.append(' '.join(map(str, a)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
6
2 0 2 1 1 0
0
== 範例 1 輸出 ==
0 0 1 1 2 2

== 範例 2 輸入 ==
3
1 1 1
0
== 範例 2 輸出 ==
1 1 1
