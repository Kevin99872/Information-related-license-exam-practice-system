CPE Dijkstra Shortest Path

難度：中等
來源：原創（Dijkstra 最短路徑演算法）

== 題目 ==
給定一個含 n 個節點、m 條「無向」邊的加權圖 (邊權重皆為非負整數)，求從起點 src 到每個節點的最短距離；若無法到達則輸出 -1。

輸入說明：每組第一行 n m src，接著 m 行each 三個整數 u v w (節點 u、v 間有一條權重 w 的邊)。n=0 表示輸入結束。
輸出說明：每組輸出一行，依節點 0~n-1 順序列出最短距離 (或 -1)，以空白分隔。

== 參考解法 (Python) ==
import sys
import heapq

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); m = int(data[idx + 1]); src = int(data[idx + 2]); idx += 3
        if n == 0:
            break
        adj = [[] for _ in range(n)]
        for _ in range(m):
            u = int(data[idx]); v = int(data[idx + 1]); w = int(data[idx + 2]); idx += 3
            adj[u].append((v, w))
            adj[v].append((u, w))
        dist = [float('inf')] * n
        dist[src] = 0
        pq = [(0, src)]
        while pq:
            d, u = heapq.heappop(pq)
            if d > dist[u]:
                continue
            for v, w in adj[u]:
                if d + w < dist[v]:
                    dist[v] = d + w
                    heapq.heappush(pq, (dist[v], v))
        out.append(' '.join('-1' if dist[i] == float('inf') else str(dist[i]) for i in range(n)))
    print('\n'.join(out))

main()

5 6 0

1 3 1
2 3 5
3 4 3
0 0 0
== 範例 1 輸出 ==
0 3 1 4 7
