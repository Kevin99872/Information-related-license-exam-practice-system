CPE Longest Common Subsequence Reconstruction

難度：中等
來源：原創（動態規劃：最長共同子序列還原）

== 題目 ==
給定兩個字串，求其最長共同子序列的長度，並輸出該子序列本身 (若有多解，輸出任一組)。

輸入說明：每組兩行分別為字串 s1、s2，直到出現單獨一行 "#" 為止 (不處理)。
輸出說明：每組輸出兩行：長度，以及該子序列。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        if line == '#':
            break
        s1 = line
        s2 = data[idx].strip(); idx += 1
        n, m = len(s1), len(s2)
        dp = [[0] * (m + 1) for _ in range(n + 1)]
        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if s1[i - 1] == s2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        i, j = n, m
        seq = []
        while i > 0 and j > 0:
            if s1[i - 1] == s2[j - 1]:
                seq.append(s1[i - 1])
                i -= 1; j -= 1
            elif dp[i - 1][j] >= dp[i][j - 1]:
                i -= 1
            else:
                j -= 1
        seq.reverse()
        out.append(str(len(seq)))
        out.append(''.join(seq))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
ABCBDAB
BDCABA
#
== 範例 1 輸出 ==
4
BCBA

== 範例 2 輸入 ==
abc
abc
#
== 範例 2 輸出 ==
3
abc
