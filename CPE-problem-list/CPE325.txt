CPE Diameter of a Tree

難度：中等
來源：原創（樹的直徑 (兩次 BFS 法)）

== 題目 ==
給定一棵含 n 個節點的樹 (n-1 條邊)，求樹的直徑 (樹上任兩節點間最長路徑的邊數)。

輸入說明：每組第一行 n，接著 n-1 行each 兩個整數 u v (邊)。n=0 表示輸入結束。
輸出說明：每組輸出樹的直徑。

== 參考解法 (Python) ==
import sys
from collections import deque

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        adj = [[] for _ in range(n)]
        for _ in range(n - 1):
            u = int(data[idx]); v = int(data[idx + 1]); idx += 2
            adj[u].append(v)
            adj[v].append(u)

        def bfs(src):
            dist = [-1] * n
            dist[src] = 0
            q = deque([src])
            far = src
            while q:
                u = q.popleft()
                if dist[u] > dist[far]:
                    far = u
                for v in adj[u]:
                    if dist[v] == -1:
                        dist[v] = dist[u] + 1
                        q.append(v)
            return far, dist[far]

        a, _ = bfs(0)
        _, d = bfs(a)
        out.append(str(d))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
0 1
1 2
2 3
3 4
0
== 範例 1 輸出 ==
4

== 範例 2 輸入 ==
4
0 1
0 2
0 3
0
== 範例 2 輸出 ==
2
