CPE Binary Tree Right Side View

難度：中等
來源：原創（BFS：二元樹右側視圖）

== 題目 ==
給定一棵二元樹 (陣列表示，節點 0 為根，每個節點有值，left[i]/right[i] 為左右子節點索引，-1 表示不存在)，求從右側觀察此樹時，每一層最右邊可見的節點值 (由上到下)。

輸入說明：每組第一行 n，接著 n 行each 三個整數 (節點 0~n-1 依序的 值、left、right)。n=0 表示輸入結束。
輸出說明：每組輸出右側視圖 (以空白分隔)。

== 參考解法 (Python) ==
import sys
from collections import deque

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        val, left, right = [], [], []
        for _ in range(n):
            val.append(int(data[idx])); left.append(int(data[idx + 1])); right.append(int(data[idx + 2])); idx += 3
        result = []
        q = deque([0])
        while q:
            size = len(q)
            for i in range(size):
                u = q.popleft()
                if i == size - 1:
                    result.append(val[u])
                if left[u] != -1:
                    q.append(left[u])
                if right[u] != -1:
                    q.append(right[u])
        out.append(' '.join(map(str, result)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4
1 1 2
2 -1 3
3 -1 -1
4 -1 -1
0
== 範例 1 輸出 ==
1 3 4

== 範例 2 輸入 ==
1
1 -1 -1
0
== 範例 2 輸出 ==
1
