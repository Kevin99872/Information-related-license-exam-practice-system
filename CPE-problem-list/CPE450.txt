CPE Isomorphic Strings

難度：簡單
來源：原創（同構字串判斷 (一對一字元映射)）

== 題目 ==
判斷兩個等長字串 s、t 是否同構：存在一個「一對一」的字元對應關係，將 s 中每個字元替換成對應字元後可以得到 t。

輸入說明：每行兩個以空白分隔的字串 s t，讀到檔案結尾。
輸出說明：每行輸出 Yes 或 No。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        line = line.rstrip('\n')
        if not line:
            continue
        s, t = line.split()
        if len(s) != len(t):
            out.append('No')
            continue
        map_st = {}
        map_ts = {}
        ok = True
        for a, b in zip(s, t):
            if a in map_st and map_st[a] != b:
                ok = False
                break
            if b in map_ts and map_ts[b] != a:
                ok = False
                break
            map_st[a] = b
            map_ts[b] = a
        out.append('Yes' if ok else 'No')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
egg add
foo bar
== 範例 1 輸出 ==
Yes
No

== 範例 2 輸入 ==
paper title
== 範例 2 輸出 ==
Yes
