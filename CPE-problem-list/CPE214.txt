CPE 10229 Modular Fibonacci

難度：困難
來源：改編自 UVa Online Judge #10229 (CPE 大學程式能力檢定經典題)

== 題目 ==
給定 n 與 m，求 Fn mod 2^m (F0=0,F1=1)。0<=n<=2147483647，0<=m<20。

輸入說明：每行兩個整數 n m，讀到檔案結尾。
輸出說明：每行輸出 Fn mod 2^m。

== 參考解法 (Python) ==
import sys

def fib_pair(k, m):
    if k == 0:
        return (0, 1)
    a, b = fib_pair(k >> 1, m)
    c = (a * ((2 * b - a) % m)) % m
    d = (a * a + b * b) % m
    if k & 1:
        return (d, (c + d) % m)
    return (c, d)

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n, mexp = map(int, line.split())
        m = 1 << mexp
        out.append(str(fib_pair(n, m)[0] if m > 1 else 0))
    print('\n'.join(out))

main()

25
