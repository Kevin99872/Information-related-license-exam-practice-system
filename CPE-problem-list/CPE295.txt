CPE Queue Using Two Stacks

難度：簡單
來源：原創（資料結構設計：用兩個堆疊實作佇列）

== 題目 ==
使用兩個堆疊實作一個佇列，支援 PUSH x (加入尾端) 與 POP (取出並移除隊首元素，若佇列為空輸出 empty)。

輸入說明：每組第一行為指令數 q，接著 q 行指令。q=0 表示輸入結束。
輸出說明：依序輸出每個 POP 指令的結果。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        q = int(line)
        if q == 0:
            break
        in_stack = []
        out_stack = []
        for _ in range(q):
            parts = data[idx].split(); idx += 1
            if parts[0] == 'PUSH':
                in_stack.append(int(parts[1]))
            else:
                if not out_stack:
                    while in_stack:
                        out_stack.append(in_stack.pop())
                out.append(str(out_stack.pop()) if out_stack else 'empty')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
6
PUSH 1
PUSH 2
POP
PUSH 3
POP
POP
0
== 範例 1 輸出 ==
1
2
3

== 範例 2 輸入 ==
2
POP
PUSH 5
0
== 範例 2 輸出 ==
