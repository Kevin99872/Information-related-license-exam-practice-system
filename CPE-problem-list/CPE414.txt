CPE Subset Sum Reconstruction

難度：中等
來源：原創（動態規劃：子集合和還原實際子集合）

== 題目 ==
給定 n 個正整數與目標值 target，判斷是否存在子集合使其和恰為 target，若存在則輸出其中一組子集合。

輸入說明：每組第一行 n target，第二行 n 個正整數。n=0 且 target=0 表示輸入結束。
輸出說明：每組先輸出 Yes 或 No；若為 Yes，接著輸出一行該子集合 (以空白分隔)。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); target = int(data[idx + 1]); idx += 2
        if n == 0 and target == 0:
            break
        nums = [int(data[idx + i]) for i in range(n)]
        idx += n
        dp = [[False] * (target + 1) for _ in range(n + 1)]
        for i in range(n + 1):
            dp[i][0] = True
        for i in range(1, n + 1):
            for t in range(target + 1):
                dp[i][t] = dp[i - 1][t]
                if not dp[i][t] and nums[i - 1] <= t:
                    dp[i][t] = dp[i - 1][t - nums[i - 1]]
        if not dp[n][target]:
            out.append('No')
            continue
        result = []
        t = target
        for i in range(n, 0, -1):
            if not dp[i - 1][t]:
                result.append(nums[i - 1])
                t -= nums[i - 1]
        out.append('Yes')
        out.append(' '.join(map(str, result)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5 9
3 34 4 12 5
0 0
== 範例 1 輸出 ==
Yes
5 4

== 範例 2 輸入 ==
4 11
1 2 3 4
0 0
== 範例 2 輸出 ==
No
