CPE KMP String Matching

難度：中等
來源：原創（KMP 字串比對演算法）

== 題目 ==
給定文字 text 與樣式 pattern，使用 KMP 演算法計算 pattern 在 text 中出現的次數 (可重疊)。

輸入說明：每行兩個以空白分隔的字串 text pattern，讀到檔案結尾。
輸出說明：每行輸出出現次數。

== 參考解法 (Python) ==
import sys

def build_lps(p):
    lps = [0] * len(p)
    length = 0
    i = 1
    while i < len(p):
        if p[i] == p[length]:
            length += 1
            lps[i] = length
            i += 1
        elif length:
            length = lps[length - 1]
        else:
            lps[i] = 0
            i += 1
    return lps

def kmp_count(text, pattern):
    lps = build_lps(pattern)
    i = j = 0
    count = 0
    while i < len(text):
        if text[i] == pattern[j]:
            i += 1; j += 1
            if j == len(pattern):
                count += 1
                j = lps[j - 1]
        elif j:
            j = lps[j - 1]
        else:
            i += 1
    return count

def main():
    out = []
    for line in sys.stdin:
        line = line.rstrip('\n')
        if not line:
            continue
        text, pattern = line.split()
        out.append(str(kmp_count(text, pattern)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
ababcababc abc
aaaaa aa
== 範例 1 輸出 ==
2
4

== 範例 2 輸入 ==
abcabcabc abcabc
== 範例 2 輸出 ==
2
