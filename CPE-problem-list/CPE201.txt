CPE Single Number (XOR Trick)

難度：簡單
來源：原創（位元運算：找出唯一不成對的數字）

== 題目 ==
給定 n 個整數，除了「恰好一個」數字只出現一次外，其餘每個數字都恰好出現兩次，求那個只出現一次的數字。

輸入說明：每組第一行 n (奇數)，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出只出現一次的數字。

== 參考解法 (Python) ==
import sys
from functools import reduce

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        nums = [int(data[idx + i]) for i in range(n)]
        idx += n
        out.append(str(reduce(lambda a, b: a ^ b, nums)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
4 1 2 1 2
0
== 範例 1 輸出 ==
4

== 範例 2 輸入 ==
3
7 7 9
0
== 範例 2 輸出 ==
9
