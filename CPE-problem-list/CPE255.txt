== 題目 ==
給定一個單字 (可能含重複字母)，列出所有由這些字母組成的相異排列，依字典序 (大小寫視為不同字元，'A'<'a') 由小到大輸出。

輸入說明：第一行為測試個數，之後每行一個單字 (只含英文字母)。
輸出說明：每個單字輸出其所有相異排列 (每個一行)，依字典序排列。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    while data[idx].strip() == '':
        idx += 1
    t = int(data[idx].strip()); idx += 1
    out = []
    for _ in range(t):
        while data[idx].strip() == '':
            idx += 1
        w = data[idx].strip(); idx += 1
        perms = set()

        def backtrack(path, remaining):
            if not remaining:
                perms.add(path)
                return
            seen = set()
            for i in range(len(remaining)):
                if remaining[i] in seen:
                    continue
                seen.add(remaining[i])
                backtrack(path + remaining[i], remaining[:i] + remaining[i + 1:])

        backtrack('', w)
        out.extend(sorted(perms))
    print('\n'.join(out))

main()
