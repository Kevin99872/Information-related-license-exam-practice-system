CPE Maximum Gap

難度：簡單
來源：原創（排序後相鄰元素最大差值）

== 題目 ==
給定 n 個整數，將其排序後，求「相鄰兩數之差」的最大值；若 n<2 則輸出 0。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出最大差值。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        if n < 2:
            out.append('0')
            continue
        a.sort()
        out.append(str(max(a[i + 1] - a[i] for i in range(n - 1))))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4
3 6 9 1
0
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
1
5
0
== 範例 2 輸出 ==
0
