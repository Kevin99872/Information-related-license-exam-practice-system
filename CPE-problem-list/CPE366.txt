CPE Symmetric Tree Check

難度：中等
來源：原創（二元樹鏡像對稱判斷）

== 題目 ==
給定一棵二元樹 (陣列表示，節點 0 為根，每個節點有值，left[i]/right[i] 為左右子節點索引，-1 表示不存在)，判斷是否左右鏡像對稱。

輸入說明：每組第一行 n，接著 n 行each 三個整數 (節點 0~n-1 依序的 值、left、right)。n=0 表示輸入結束。
輸出說明：每組輸出 Yes 或 No。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        val, left, right = [], [], []
        for _ in range(n):
            val.append(int(data[idx])); left.append(int(data[idx + 1])); right.append(int(data[idx + 2])); idx += 3

        def mirror(u, v):
            if u == -1 and v == -1:
                return True
            if u == -1 or v == -1:
                return False
            return val[u] == val[v] and mirror(left[u], right[v]) and mirror(right[u], left[v])

        result = mirror(left[0], right[0]) if n > 0 else True
        out.append('Yes' if result else 'No')
    print('\n'.join(out))

main()

7
1 1 2
2 3 4

3 -1 -1
4 -1 -1
4 -1 -1
3 -1 -1
0
== 範例 1 輸出 ==
Yes
