CPE Rotate Array by K

難度：簡單
來源：原創（陣列旋轉）

== 題目 ==
給定 n 個整數與正整數 k，將陣列「向右旋轉」k 個位置 (最後 k 個元素移到最前面)。

輸入說明：每組第一行 n k，第二行 n 個整數。n=0 且 k=0 表示輸入結束。
輸出說明：每組輸出旋轉後的陣列 (以空白分隔)。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); k = int(data[idx + 1]); idx += 2
        if n == 0 and k == 0:
            break
        nums = [int(data[idx + i]) for i in range(n)]
        idx += n
        k %= n
        rotated = nums[-k:] + nums[:-k] if k else nums
        out.append(' '.join(map(str, rotated)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
7 3
1 2 3 4 5 6 7
0 0
== 範例 1 輸出 ==
5 6 7 1 2 3 4

== 範例 2 輸入 ==
3 4
1 2 3
0 0
== 範例 2 輸出 ==
3 1 2
