CPE Longest Arithmetic Subsequence

難度：中等
來源：原創（動態規劃：最長等差子序列）

== 題目 ==
給定 n 個整數，求最長「等差子序列」的長度 (子序列中相鄰元素差值皆相同，不要求連續)。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出最長等差子序列長度。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        dp = [dict() for _ in range(n)]
        best = 1 if n > 0 else 0
        for i in range(n):
            for j in range(i):
                d = a[i] - a[j]
                dp[i][d] = dp[j].get(d, 1) + 1
                best = max(best, dp[i][d])
        out.append(str(best))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
6
3 6 9 12 15 2
0
== 範例 1 輸出 ==
5

== 範例 2 輸入 ==
4
9 4 7 2
0
== 範例 2 輸出 ==
2
