CPE Palindrome Partitioning Minimum Cuts

難度：中等
來源：原創（動態規劃：回文分割最少切割次數）

== 題目 ==
給定一個字串，將其切割成數段，使每段都是回文，求最少的切割次數。

輸入說明：每行一個字串，讀到檔案結尾。
輸出說明：每行輸出最少切割次數。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        s = line.strip()
        if not s:
            out.append('0')
            continue
        n = len(s)
        is_pal = [[False] * n for _ in range(n)]
        for i in range(n):
            is_pal[i][i] = True
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if s[i] == s[j] and (length == 2 or is_pal[i + 1][j - 1]):
                    is_pal[i][j] = True
        cuts = [0] * n
        for i in range(n):
            if is_pal[0][i]:
                cuts[i] = 0
                continue
            best = i
            for j in range(1, i + 1):
                if is_pal[j][i]:
                    best = min(best, cuts[j - 1] + 1)
            cuts[i] = best
        out.append(str(cuts[n - 1]))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
aab
abcde
== 範例 1 輸出 ==
1
4

== 範例 2 輸入 ==
racecar
== 範例 2 輸出 ==
0
