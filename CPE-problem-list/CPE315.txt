CPE Nim Game

難度：簡單
來源：原創（組合遊戲論：Nim 遊戲勝負判斷）

== 題目 ==
Nim 遊戲：有 n 堆石頭，兩人輪流從「任一堆」取走「至少一顆」石頭，無法行動 (所有堆皆空) 者輸。給定初始石頭數，判斷先手 (First) 或後手 (Second) 獲勝 (雙方採最佳策略)。

輸入說明：每組第一行 n，第二行 n 個正整數。n=0 表示輸入結束。
輸出說明：每組輸出 First 或 Second。

== 參考解法 (Python) ==
import sys
from functools import reduce

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        piles = [int(data[idx + i]) for i in range(n)]
        idx += n
        xor_sum = reduce(lambda a, b: a ^ b, piles)
        out.append('First' if xor_sum != 0 else 'Second')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3
1 2 3
0
== 範例 1 輸出 ==
Second

== 範例 2 輸入 ==
2
4 4
0
== 範例 2 輸出 ==
Second
