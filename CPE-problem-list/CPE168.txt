難度：簡單

== 題目 ==
新聞社依「字元價值表」支付稿費：文章中每個字元 (若不在表中則價值為 0) 的價值總和即為稿費 (單位：分)。

輸入說明：第一行為測試個數 N。每組第一行為表中字元數 K，接著 K 行each 一個字元與其價值 (以空白分隔)；再接著一行文章行數 M，接著 M 行文章內容。
輸出說明：每組輸出稿費，格式為 "x.yy$" (yy 為兩位數，不足補 0)。

== 參考解法 (Python) ==
import sys
from collections import Counter

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    n = int(data[idx].strip()); idx += 1
    out = []
    for _ in range(n):
        k = int(data[idx].strip()); idx += 1
        values = {}
        for _ in range(k):
            parts = data[idx].split()
            idx += 1
            values[parts[0]] = int(parts[1])
        m = int(data[idx].strip()); idx += 1
        text = []
        for _ in range(m):
            text.append(data[idx])
            idx += 1
        c = Counter(''.join(text))
        cents = sum(values.get(ch, 0) * cnt for ch, cnt in c.items())
        out.append(f"{cents // 100}.{cents % 100:02d}$")
    print('\n'.join(out))

main()
