CPE Count Inversions (Merge Sort)

難度：中等
來源：原創（分治法：逆序數統計）

== 題目 ==
給定 n 個整數，求「逆序對」的數量 (i<j 但 a[i]>a[j] 的配對數)，使用合併排序 (Merge Sort) 的分治法求解。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出逆序對數量。

== 參考解法 (Python) ==
import sys

def merge_count(arr):
    n = len(arr)
    if n <= 1:
        return arr, 0
    mid = n // 2
    left, cl = merge_count(arr[:mid])
    right, cr = merge_count(arr[mid:])
    merged = []
    i = j = 0
    inv = cl + cr
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            merged.append(left[i]); i += 1
        else:
            merged.append(right[j]); j += 1
            inv += len(left) - i
    merged.extend(left[i:])
    merged.extend(right[j:])
    return merged, inv

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        arr = [int(data[idx + i]) for i in range(n)]
        idx += n
        _, inv = merge_count(arr)
        out.append(str(inv))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
2 4 1 3 5
0
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
4
4 3 2 1
0
== 範例 2 輸出 ==
6
