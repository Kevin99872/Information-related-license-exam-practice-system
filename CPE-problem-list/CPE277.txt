CPE LRU Cache Simulation

難度：中等
來源：原創（LRU (最近最少使用) 快取模擬）

== 題目 ==
模擬容量為 cap 的 LRU 快取，支援指令 "PUT k v" (寫入/更新鍵值，若超過容量則淘汰最久未使用者) 與 "GET k" (讀取鍵值，若不存在輸出 -1，否則輸出該值並將其標記為最近使用)。

輸入說明：每組第一行為容量 cap，第二行為指令數 q，接著 q 行指令。cap=0 表示輸入結束。
輸出說明：依序輸出每個 GET 指令的結果。

== 參考解法 (Python) ==
import sys
from collections import OrderedDict

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        cap = int(line)
        if cap == 0:
            break
        cache = OrderedDict()
        q = int(data[idx].strip()); idx += 1
        for _ in range(q):
            parts = data[idx].split(); idx += 1
            if parts[0] == 'PUT':
                k, v = int(parts[1]), int(parts[2])
                if k in cache:
                    del cache[k]
                cache[k] = v
                if len(cache) > cap:
                    cache.popitem(last=False)
            else:
                k = int(parts[1])
                if k in cache:
                    v = cache.pop(k)
                    cache[k] = v
                    out.append(str(v))
                else:
                    out.append('-1')
    print('\n'.join(out))

main()
