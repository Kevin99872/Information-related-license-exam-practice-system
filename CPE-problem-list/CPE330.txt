CPE Maximum Sum Increasing Subsequence

難度：中等
來源：原創（動態規劃：最大和遞增子序列）

== 題目 ==
給定 n 個整數，求「嚴格遞增」子序列中，元素總和最大的值。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出最大總和。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        dp = a[:]
        for i in range(n):
            for j in range(i):
                if a[j] < a[i]:
                    dp[i] = max(dp[i], dp[j] + a[i])
        out.append(str(max(dp)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
1 101 2 3 100
0
== 範例 1 輸出 ==
106

== 範例 2 輸入 ==
4
3 4 5 10
0
== 範例 2 輸出 ==
22
