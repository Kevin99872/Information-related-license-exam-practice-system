CPE Longest Bitonic Subsequence

難度：中等
來源：原創（動態規劃：最長雙調子序列）

== 題目 ==
雙調子序列是指先嚴格遞增、後嚴格遞減的子序列 (允許只遞增或只遞減)。給定 n 個整數，求最長雙調子序列的長度。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出最長雙調子序列長度。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        inc = [1] * n
        dec = [1] * n
        for i in range(n):
            for j in range(i):
                if a[j] < a[i]:
                    inc[i] = max(inc[i], inc[j] + 1)
        for i in range(n - 1, -1, -1):
            for j in range(i + 1, n):
                if a[j] < a[i]:
                    dec[i] = max(dec[i], dec[j] + 1)
        out.append(str(max(inc[i] + dec[i] - 1 for i in range(n))))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
8
1 11 2 10 4 5 2 1
0
== 範例 1 輸出 ==
6

== 範例 2 輸入 ==
5
1 2 3 4 5
0
== 範例 2 輸出 ==
5
