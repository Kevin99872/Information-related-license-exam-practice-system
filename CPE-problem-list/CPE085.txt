CPE Matrix Transpose

難度：簡單
來源：原創（矩陣轉置）

== 題目 ==
給定 R*C 矩陣，輸出其轉置矩陣 (C*R)。

輸入說明：每組第一行 R C，接著 R 行each C 個整數。R=0 且 C=0 表示輸入結束。
輸出說明：每組輸出轉置後的矩陣 (C 行each R 個整數，以空白分隔)；組與組之間空一行。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    blocks = []
    while idx < len(data):
        r = int(data[idx]); c = int(data[idx + 1]); idx += 2
        if r == 0:
            break
        grid = []
        for i in range(r):
            grid.append([int(data[idx + j]) for j in range(c)])
            idx += c
        rows = [' '.join(str(grid[i][j]) for i in range(r)) for j in range(c)]
        blocks.append('\n'.join(rows))
    print('\n\n'.join(blocks))

main()

== 範例 1 輸入 ==
2 3
1 2 3
4 5 6
0 0
== 範例 1 輸出 ==
1 4
2 5
3 6

== 範例 2 輸入 ==
3 1
7
8
9
0 0
== 範例 2 輸出 ==
7 8 9
