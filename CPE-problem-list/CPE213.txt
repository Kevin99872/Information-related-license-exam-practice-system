CPE 10183 How many Fibs?

難度：中等
來源：改編自 UVa Online Judge #10183 (CPE 大學程式能力檢定經典題)

== 題目 ==
定義 f1=1, f2=2, fn=f(n-1)+f(n-2) (n>=3)。給定兩個大整數 a、b，求落在區間 [a,b] 內的費波那契數個數。

輸入說明：每行兩個非負整數 a b (a<=b<=10^100)，"0 0" 表示輸入結束。
輸出說明：每行輸出區間內的費波那契數個數。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    fibs = [1, 2]
    while fibs[-1] <= 10 ** 100:
        fibs.append(fibs[-1] + fibs[-2])
    while idx < len(data):
        a = int(data[idx]); b = int(data[idx + 1]); idx += 2
        if a == 0 and b == 0:
            break
        out.append(str(sum(1 for f in fibs if a <= f <= b)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
10 100
1234567890 9876543210
0 0
== 範例 1 輸出 ==
5
4

== 範例 2 輸入 ==
1 2
0 0
== 範例 2 輸出 ==
2
