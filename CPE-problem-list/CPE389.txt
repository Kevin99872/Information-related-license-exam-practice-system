CPE Jump Game II

難度：中等
來源：原創（貪心：跳躍遊戲最少跳躍次數）

== 題目 ==
給定 n 個非負整數 (保證能到達終點)，第 i 個表示從該位置最多能往前跳的步數，起點在索引 0，求到達最後一個索引所需的最少跳躍次數。

輸入說明：每組第一行 n，第二行 n 個非負整數。n=0 表示輸入結束。
輸出說明：每組輸出最少跳躍次數。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        jumps = 0
        cur_end = 0
        farthest = 0
        for i in range(n - 1):
            farthest = max(farthest, i + a[i])
            if i == cur_end:
                jumps += 1
                cur_end = farthest
        out.append(str(jumps))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
2 3 1 1 4
0
== 範例 1 輸出 ==
2

== 範例 2 輸入 ==
4
1 1 1 1
0
== 範例 2 輸出 ==
3
