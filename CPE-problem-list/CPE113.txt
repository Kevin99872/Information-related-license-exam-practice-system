難度：簡單

== 題目 ==
給定 N 個正整數，將它們首尾相接組成一個大整數，求能組成的「最大」整數。

輸入說明：每組第一行 N (<=50)，第二行 N 個正整數。N=0 結束。
輸出說明：每組輸出能組成的最大整數。

== 參考解法 (Python) ==
import sys
from functools import cmp_to_key

def cmp(a, b):
    if a + b > b + a:
        return -1
    if a + b < b + a:
        return 1
    return 0

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        nums = [data[idx + i] for i in range(n)]
        idx += n
        nums.sort(key=cmp_to_key(cmp))
        out.append(''.join(nums).lstrip('0') or '0')
    print('\n'.join(out))

main()
