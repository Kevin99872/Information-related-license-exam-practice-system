CPE 最長震盪子陣列

難度：中等
來源：原創（狀態追蹤動態規劃）

== 題目 ==
給定一個長度為 n 的整數陣列，「震盪子陣列」指相鄰元素的大小關係交替出現（一大一小一大一小...）
的連續子陣列。請求出最長震盪子陣列的長度。

輸入格式：第一行為 n（n=0 代表輸入結束）；第二行為 n 個整數。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        if n == 1:
            out.append('1')
            continue
        best = 1
        up = 1
        down = 1
        for i in range(1, n):
            if a[i] > a[i - 1]:
                up = down + 1
                down = 1
            elif a[i] < a[i - 1]:
                down = up + 1
                up = 1
            else:
                up = down = 1
            best = max(best, up, down)
        out.append(str(best))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
9 4 2 10 7
== 範例 1 輸出 ==
4

== 範例 2 輸入 ==
4
4 8 12 16
== 範例 2 輸出 ==
2
