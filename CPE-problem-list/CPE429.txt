CPE Best Time to Buy and Sell Stock III

難度：中等
來源：原創（動態規劃：股票買賣最多兩次交易）

== 題目 ==
給定 n 天的股票價格，最多可進行「兩次」交易 (先買後賣算一次，不能同時持有超過一股)，求最大總利潤。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出最大總利潤。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        prices = [int(data[idx + i]) for i in range(n)]
        idx += n
        buy1 = buy2 = float('-inf')
        sell1 = sell2 = 0
        for p in prices:
            buy1 = max(buy1, -p)
            sell1 = max(sell1, buy1 + p)
            buy2 = max(buy2, sell1 - p)
            sell2 = max(sell2, buy2 + p)
        out.append(str(sell2))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
8
3 3 5 0 0 3 1 4
0
== 範例 1 輸出 ==
6

== 範例 2 輸入 ==
5
1 2 3 4 5
0
== 範例 2 輸出 ==
4
