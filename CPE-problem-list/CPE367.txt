CPE Invert Binary Tree

難度：簡單
來源：原創（二元樹翻轉 (左右子樹互換)）

== 題目 ==
給定一棵二元樹 (陣列表示，節點 0 為根，每個節點有值，left[i]/right[i] 為左右子節點索引，-1 表示不存在)，將每個節點的左右子樹互換，輸出翻轉後樹的前序走訪結果。

輸入說明：每組第一行 n，接著 n 行each 三個整數 (節點 0~n-1 依序的 值、left、right)。n=0 表示輸入結束。
輸出說明：每組輸出翻轉後的前序走訪結果 (以空白分隔)。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        val, left, right = [], [], []
        for _ in range(n):
            val.append(int(data[idx])); left.append(int(data[idx + 1])); right.append(int(data[idx + 2])); idx += 3

        def invert(u):
            if u == -1:
                return
            left[u], right[u] = right[u], left[u]
            invert(left[u])
            invert(right[u])

        invert(0)
        result = []

        def preorder(u):
            if u == -1:
                return
            result.append(val[u])
            preorder(left[u])
            preorder(right[u])

        preorder(0)
        out.append(' '.join(map(str, result)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3
4 1 2
2 -1 -1
7 -1 -1
0
== 範例 1 輸出 ==
4 7 2

== 範例 2 輸入 ==
1
5 -1 -1
0
== 範例 2 輸出 ==
5
