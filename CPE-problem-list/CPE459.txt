CPE 3xN 骨牌鋪磚

難度：中等
來源：原創（遞迴 / 動態規劃計數）

== 題目 ==
給定一個 3 x n 的長方形棋盤，使用 1x2 的骨牌（可橫放或直放）完全鋪滿棋盤，
請問共有幾種不同的鋪法？

已知：當 n 為奇數時無法鋪滿，答案為 0；當 n 為偶數時，設 f(n) 為鋪法數，
則 f(0)=1, f(2)=3，且 f(n) = 4*f(n-2) - f(n-4)（n>=4）。

輸入為一系列整數 n（每行一個，0 <= n <= 60），直到檔案結束。對每個 n 輸出鋪法數。

== 參考解法 (Python) ==
import sys

def main():
    maxn = 60
    f = [0] * (maxn + 1)
    f[0] = 1
    if maxn >= 2:
        f[2] = 3
    for n in range(4, maxn + 1, 2):
        f[n] = 4 * f[n - 2] - f[n - 4]
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        out.append(str(f[n]) if n % 2 == 0 else '0')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
0
2
4
6
7
== 範例 1 輸出 ==
1
3
11
41
0
