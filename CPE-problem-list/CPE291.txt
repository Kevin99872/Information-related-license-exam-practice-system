CPE Point in Polygon Test

難度：中等
來源：原創（計算幾何：點是否在多邊形內 (射線法)）

== 題目 ==
給定一個簡單多邊形 (n 個頂點依邊界順序給定) 與 q 個查詢點，判斷每個查詢點是否在多邊形「內部」(邊界上視為 Outside，使用射線法判斷)。

輸入說明：每組第一行 n，接著 n 行each 兩個整數 x y (多邊形頂點)；接著一行查詢數 q，再 q 行each 兩個整數 x y。n=0 表示輸入結束。
輸出說明：每個查詢輸出 Inside 或 Outside。

== 參考解法 (Python) ==
import sys

def point_in_polygon(pt, poly):
    x, y = pt
    n = len(poly)
    inside = False
    j = n - 1
    for i in range(n):
        xi, yi = poly[i]
        xj, yj = poly[j]
        if (yi > y) != (yj > y):
            x_cross = (xj - xi) * (y - yi) / (yj - yi) + xi
            if x < x_cross:
                inside = not inside
        j = i
    return inside

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        poly = []
        for _ in range(n):
            x = int(data[idx]); y = int(data[idx + 1]); idx += 2
            poly.append((x, y))
        q = int(data[idx]); idx += 1
        for _ in range(q):
            x = int(data[idx]); y = int(data[idx + 1]); idx += 2
            out.append('Inside' if point_in_polygon((x, y), poly) else 'Outside')
    print('\n'.join(out))

main()
