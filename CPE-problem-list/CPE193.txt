CPE Next Permutation

難度：中等
來源：原創（下一個排列 (字典序)）

== 題目 ==
給定一個由整數組成的排列，求「字典序中下一個」排列；若已是最大排列，則輸出「最小排列」(由小到大排序的結果)。

輸入說明：每行為一個以空白分隔的整數排列，讀到檔案結尾。
輸出說明：每行輸出下一個排列。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        nums = list(map(int, line.split()))
        n = len(nums)
        i = n - 2
        while i >= 0 and nums[i] >= nums[i + 1]:
            i -= 1
        if i < 0:
            nums.reverse()
        else:
            j = n - 1
            while nums[j] <= nums[i]:
                j -= 1
            nums[i], nums[j] = nums[j], nums[i]
            nums[i + 1:] = reversed(nums[i + 1:])
        out.append(' '.join(map(str, nums)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
1 2 3
3 2 1
== 範例 1 輸出 ==
1 3 2
1 2 3

== 範例 2 輸入 ==
1 1 5
== 範例 2 輸出 ==
1 5 1
