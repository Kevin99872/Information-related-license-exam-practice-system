CPE Non-overlapping Intervals Removal Count

難度：中等
來源：原創（貪心：使區間不重疊所需的最少移除數）

== 題目 ==
給定 n 個區間，求最少需要移除幾個區間，才能讓剩下的區間彼此不重疊 (允許端點相接)。

輸入說明：每組第一行 n，接著 n 行each 兩個整數 l r。n=0 表示輸入結束。
輸出說明：每組輸出最少移除數量。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        intervals = []
        for _ in range(n):
            l = int(data[idx]); r = int(data[idx + 1]); idx += 2
            intervals.append((l, r))
        intervals.sort(key=lambda x: x[1])
        removed = 0
        last_end = float('-inf')
        for l, r in intervals:
            if l >= last_end:
                last_end = r
            else:
                removed += 1
        out.append(str(removed))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4
1 2
2 3
3 4
1 3
0
== 範例 1 輸出 ==
1

== 範例 2 輸入 ==
3
1 100
11 22
1 11
0
== 範例 2 輸出 ==
1
