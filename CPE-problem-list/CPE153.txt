CPE Nth Fibonacci mod m

難度：簡單
來源：原創（費波那契數取模）

== 題目 ==
給定 n 與 m，求費波那契數列第 n 項 (F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)) 對 m 取餘數的結果。

輸入說明：每行兩個整數 n m (0<=n<=10^7, 1<=m<=10^9)，讀到檔案結尾。
輸出說明：每行輸出 F(n) mod m。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n, m = map(int, line.split())
        a, b = 0, 1
        for _ in range(n):
            a, b = b, (a + b) % m
        out.append(str(a))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
10 1000
0 5
== 範例 1 輸出 ==
55
0

== 範例 2 輸入 ==
1 7
20 100
== 範例 2 輸出 ==
1
65
