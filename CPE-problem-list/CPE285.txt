CPE Generate Valid Parentheses

難度：中等
來源：原創（回溯法：生成合法括號組合）

== 題目 ==
給定 n，列出所有由 n 對括號組成的合法括號序列 (依生成順序輸出)。

輸入說明：每行一個整數 n (1<=n<=8)，讀到檔案結尾。
輸出說明：每行輸出所有合法括號序列，以空白分隔。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        results = []

        def backtrack(s, open_cnt, close_cnt):
            if len(s) == 2 * n:
                results.append(s)
                return
            if open_cnt < n:
                backtrack(s + '(', open_cnt + 1, close_cnt)
            if close_cnt < open_cnt:
                backtrack(s + ')', open_cnt, close_cnt + 1)

        backtrack('', 0, 0)
        out.append(' '.join(results))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3
== 範例 1 輸出 ==
((())) (()()) (())() ()(()) ()()()

== 範例 2 輸入 ==
1
2
== 範例 2 輸出 ==
()
(()) ()()
