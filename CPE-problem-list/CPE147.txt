CPE Minimum Coins for Change

難度：中等
來源：原創（動態規劃：找零錢最少硬幣數）

== 題目 ==
給定 n 種硬幣面額與目標金額 target，求湊出 target 所需的最少硬幣數 (每種硬幣可使用無限次)；若無法湊出則輸出 -1。

輸入說明：每組第一行 n target，第二行 n 個正整數面額。n=0 且 target=0 表示輸入結束。
輸出說明：每組輸出最少硬幣數，或 -1。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); target = int(data[idx + 1]); idx += 2
        if n == 0 and target == 0:
            break
        coins = [int(data[idx + i]) for i in range(n)]
        idx += n
        INF = float('inf')
        dp = [0] + [INF] * target
        for i in range(1, target + 1):
            for coin in coins:
                if coin <= i and dp[i - coin] + 1 < dp[i]:
                    dp[i] = dp[i - coin] + 1
        out.append(str(dp[target]) if dp[target] != INF else '-1')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3 11
1 2 5
0 0
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
1 3
2
0 0
== 範例 2 輸出 ==
-1
