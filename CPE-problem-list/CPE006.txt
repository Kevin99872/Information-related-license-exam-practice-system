CPE 10035 Primary Arithmetic

難度：中等
來源：改編自 UVa Online Judge #10035 (CPE 大學程式能力檢定經典題)

== 題目 ==
小學直式加法中，每次進位都是一項運算。給定兩個數，計算相加時的進位次數。

輸入說明：每行兩個不超過十位的非負整數，以 0 0 結束 (不處理)。
輸出說明：無進位輸出 No carry operation.；一次輸出 1 carry operation.；多次輸出 N carry operations.

== 範例 1 輸入 ==
123 456
555 555
123 594
0 0
== 範例 1 輸出 ==
No carry operation.
3 carry operations.
1 carry operation.

== 範例 2 輸入 ==
99999 1
0 0
== 範例 2 輸出 ==
5 carry operations.
