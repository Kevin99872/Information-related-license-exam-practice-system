CPE Binary Search Tree Delete Node

難度：困難
來源：原創（二元搜尋樹刪除節點）

== 題目 ==
依序將 n 個相異數字插入一棵二元搜尋樹 (BST)，接著刪除數值為 target 的節點 (保證存在)，輸出刪除後的中序走訪結果。

輸入說明：每組第一行 n，第二行 n 個整數 (插入順序)，第三行為 target。n=0 表示輸入結束。
輸出說明：每組輸出刪除後的中序走訪結果 (以空白分隔)。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        vals = [int(data[idx + i]) for i in range(n)]
        idx += n
        target = int(data[idx]); idx += 1
        tree = {}
        root = None
        for v in vals:
            if root is None:
                root = v
                tree[v] = [None, None]
                continue
            node = root
            while True:
                if v < node:
                    if tree[node][0] is None:
                        tree[node][0] = v
                        tree[v] = [None, None]
                        break
                    node = tree[node][0]
                else:
                    if tree[node][1] is None:
                        tree[node][1] = v
                        tree[v] = [None, None]
                        break
                    node = tree[node][1]

        def delete(node, val):
            if node is None:
                return None
            if val < node:
                tree[node][0] = delete(tree[node][0], val)
                return node
            if val > node:
                tree[node][1] = delete(tree[node][1], val)
                return node
            if tree[node][0] is None:
                return tree[node][1]
            if tree[node][1] is None:
                return tree[node][0]
            succ = tree[node][1]
            while tree[succ][0] is not None:
                succ = tree[succ][0]
            tree[node][1] = delete(tree[node][1], succ)
            tree[succ] = tree[node]
            return succ

        root = delete(root, target)
        result = []

        def inorder(u):
            if u is None:
                return
            inorder(tree[u][0])
            result.append(u)
            inorder(tree[u][1])

        inorder(root)
        out.append(' '.join(map(str, result)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
7
5 3 8 1 4 7 9
3
0
== 範例 1 輸出 ==
1 4 5 7 8 9

== 範例 2 輸入 ==
3
2 1 3
2
0
== 範例 2 輸出 ==
1 3
