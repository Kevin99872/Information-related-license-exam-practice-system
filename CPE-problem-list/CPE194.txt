CPE Diagonal Matrix Traversal

難度：中等
來源：原創（矩陣對角線走訪）

== 題目 ==
給定 R*C 矩陣，依「對角線」順序輸出所有元素：先輸出從左上到右下方向編號最小的對角線，方向在「左下到右上」與「右上到左下」之間交替 (第一條對角線方向為左下到右上)。

輸入說明：每組第一行 R C，接著 R 行each C 個整數。R=0 且 C=0 表示輸入結束。
輸出說明：每組輸出一行，依對角線走訪順序列出所有元素 (以空白分隔)。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        r = int(data[idx]); c = int(data[idx + 1]); idx += 2
        if r == 0 and c == 0:
            break
        grid = []
        for i in range(r):
            grid.append([int(data[idx + j]) for j in range(c)])
            idx += c
        result = []
        for d in range(r + c - 1):
            diag = []
            ri = 0 if d < c else d - c + 1
            ci = d if d < c else c - 1
            while ri < r and ci >= 0:
                diag.append(grid[ri][ci])
                ri += 1
                ci -= 1
            if d % 2 == 0:
                diag.reverse()
            result.extend(diag)
        out.append(' '.join(map(str, result)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3 3
1 2 3
4 5 6
7 8 9
0 0
== 範例 1 輸出 ==
1 2 4 7 5 3 6 8 9

== 範例 2 輸入 ==
2 3
1 2 3
4 5 6
0 0
== 範例 2 輸出 ==
1 2 4 5 3 6
