CPE Happy Number Check

難度：簡單
來源：原創（快樂數判斷）

== 題目 ==
一個正整數若「反覆將各位數字平方後相加」最終會變成 1，則稱為快樂數；若最終陷入循環 (不含 1)，則不是快樂數。判斷給定數字是否為快樂數。

輸入說明：每行一個正整數 n，讀到檔案結尾。
輸出說明：每行輸出 Happy 或 Not Happy。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        x = int(line)
        seen = set()
        while x != 1 and x not in seen:
            seen.add(x)
            x = sum(int(d) ** 2 for d in str(x))
        out.append('Happy' if x == 1 else 'Not Happy')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
19
2
== 範例 1 輸出 ==
Happy
Not Happy

== 範例 2 輸入 ==
7
4
== 範例 2 輸出 ==
Happy
Not Happy
