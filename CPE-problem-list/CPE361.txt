CPE Two-Dimensional Knapsack

難度：中等
來源：原創（動態規劃：二維背包 (重量與體積雙限制)）

== 題目 ==
給定 n 個物品，每個物品有重量 w、體積 v 與價值 val；背包同時有重量上限 w_cap 與體積上限 v_cap，求不超過限制下能獲得的最大總價值。

輸入說明：每組第一行 n w_cap v_cap，接著 n 行each 三個整數 w v val。n=0 表示輸入結束。
輸出說明：每組輸出最大總價值。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); w_cap = int(data[idx + 1]); v_cap = int(data[idx + 2]); idx += 3
        if n == 0 and w_cap == 0 and v_cap == 0:
            break
        items = []
        for _ in range(n):
            w = int(data[idx]); v = int(data[idx + 1]); val = int(data[idx + 2]); idx += 3
            items.append((w, v, val))
        dp = [[0] * (v_cap + 1) for _ in range(w_cap + 1)]
        for w, v, val in items:
            for wc in range(w_cap, w - 1, -1):
                for vc in range(v_cap, v - 1, -1):
                    dp[wc][vc] = max(dp[wc][vc], dp[wc - w][vc - v] + val)
        out.append(str(dp[w_cap][v_cap]))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3 10 10
3 4 5
4 5 6
5 3 7
0 0 0
== 範例 1 輸出 ==
13

== 範例 2 輸入 ==
2 5 5
2 2 3
3 3 4
0 0 0
== 範例 2 輸出 ==
7
