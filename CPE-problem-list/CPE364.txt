CPE Validate Binary Search Tree

難度：中等
來源：原創（二元搜尋樹合法性驗證）

== 題目 ==
給定一棵二元樹 (陣列表示，節點 0 為根，每個節點有值，left[i]/right[i] 為左右子節點索引，-1 表示不存在)，判斷是否為合法的二元搜尋樹 (左子樹所有值皆小於節點值，右子樹所有值皆大於節點值)。

輸入說明：每組第一行 n，接著 n 行each 三個整數 (節點 0~n-1 依序的 值、left、right)。n=0 表示輸入結束。
輸出說明：每組輸出 Yes 或 No。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        val, left, right = [], [], []
        for _ in range(n):
            val.append(int(data[idx])); left.append(int(data[idx + 1])); right.append(int(data[idx + 2])); idx += 3

        def check(u, lo, hi):
            if u == -1:
                return True
            if not (lo < val[u] < hi):
                return False
            return check(left[u], lo, val[u]) and check(right[u], val[u], hi)

        out.append('Yes' if check(0, float('-inf'), float('inf')) else 'No')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3
2 1 2
1 -1 -1
3 -1 -1
0
== 範例 1 輸出 ==
Yes

== 範例 2 輸入 ==
3
5 1 2
1 -1 -1
4 -1 -1
0
== 範例 2 輸出 ==
No
