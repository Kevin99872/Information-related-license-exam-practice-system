CPE Count Univalue Subtrees

難度：中等
來源：原創（二元樹：單值子樹計數）

== 題目 ==
給定一棵二元樹 (陣列表示，節點 0 為根，每個節點有值，left[i]/right[i] 為左右子節點索引，-1 表示不存在)，單值子樹是指子樹中所有節點的值都相同。求單值子樹的數量。

輸入說明：每組第一行 n，接著 n 行each 三個整數 (節點 0~n-1 依序的 值、left、right)。n=0 表示輸入結束。
輸出說明：每組輸出單值子樹的數量。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        val, left, right = [], [], []
        for _ in range(n):
            val.append(int(data[idx])); left.append(int(data[idx + 1])); right.append(int(data[idx + 2])); idx += 3
        count = [0]

        def dfs(u):
            if u == -1:
                return True
            l_ok = dfs(left[u])
            r_ok = dfs(right[u])
            ok = l_ok and r_ok
            if ok and left[u] != -1 and val[left[u]] != val[u]:
                ok = False
            if ok and right[u] != -1 and val[right[u]] != val[u]:
                ok = False
            if ok:
                count[0] += 1
            return ok

        dfs(0)
        out.append(str(count[0]))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
5 1 2
1 -1 -1
5 3 4
5 -1 -1
5 -1 -1
0
== 範例 1 輸出 ==
4

== 範例 2 輸入 ==
1
1 -1 -1
0
== 範例 2 輸出 ==
1
