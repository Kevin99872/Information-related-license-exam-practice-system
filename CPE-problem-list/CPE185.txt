CPE Trapping Rain Water

難度：中等
來源：原創（雙指標：接雨水經典題型）

== 題目 ==
給定 n 個非負整數代表一排柱子的高度 (寬度皆為 1)，下雨後求柱子之間總共能積多少雨水。

輸入說明：每組第一行 n，第二行 n 個非負整數。n=0 表示輸入結束。
輸出說明：每組輸出總積水量。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        h = [int(data[idx + i]) for i in range(n)]
        idx += n
        l, r = 0, n - 1
        lmax = rmax = 0
        water = 0
        while l < r:
            if h[l] < h[r]:
                lmax = max(lmax, h[l])
                water += lmax - h[l]
                l += 1
            else:
                rmax = max(rmax, h[r])
                water += rmax - h[r]
                r -= 1
        out.append(str(water))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
12
0 1 0 2 1 0 1 3 2 1 2 1
0
== 範例 1 輸出 ==
6

== 範例 2 輸入 ==
6
4 2 0 3 2 5
0
== 範例 2 輸出 ==
9
