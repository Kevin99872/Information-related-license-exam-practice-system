CPE Minimum Insertions to Balance Parentheses

難度：中等
來源：原創（堆疊：括號配對最少插入次數）

== 題目 ==
給定一個只含 '(' 與 ')' 的字串，求最少需要插入幾個括號，才能使其變成合法的括號序列。

輸入說明：每行一個括號字串，讀到檔案結尾。
輸出說明：每行輸出最少插入次數。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        s = line.strip()
        if not s:
            continue
        open_needed = 0
        close_needed = 0
        for c in s:
            if c == '(':
                open_needed += 1
            elif open_needed > 0:
                open_needed -= 1
            else:
                close_needed += 1
        out.append(str(open_needed + close_needed))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
(()
()())(
== 範例 1 輸出 ==
1
2

== 範例 2 輸入 ==
()))((
== 範例 2 輸出 ==
4
