CPE 最長遞增子序列個數

難度：中等
來源：原創（動態規劃計數）

== 題目 ==
給定一個長度為 n 的整數陣列，請求出其最長嚴格遞增子序列的「個數」
（不同索引組合視為不同子序列，即使數值序列相同）。

輸入格式：第一行為 n（n=0 代表輸入結束）；第二行為 n 個整數。
對每組測試資料輸出一行最長遞增子序列個數。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        length = [1] * n
        count = [1] * n
        for i in range(n):
            for j in range(i):
                if a[j] < a[i]:
                    if length[j] + 1 > length[i]:
                        length[i] = length[j] + 1
                        count[i] = count[j]
                    elif length[j] + 1 == length[i]:
                        count[i] += count[j]
        best = max(length)
        total = sum(c for l, c in zip(length, count) if l == best)
        out.append(str(total))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
6
1 3 5 4 7 6
== 範例 1 輸出 ==
4

== 範例 2 輸入 ==
5
2 2 2 2 2
== 範例 2 輸出 ==
5
