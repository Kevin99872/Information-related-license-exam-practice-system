CPE 最接近原點的 K 個點

難度：簡單
來源：原創（排序 / 堆積篩選）

== 題目 ==
給定平面上 n 個點的座標，請找出距離原點最近的 k 個點（依歐幾里得距離平方排序，
若距離相同則依 x 座標較小者優先，再依 y 座標較小者優先）。

輸入格式：第一行為 n k（n=0 且 k=0 代表輸入結束）；接下來 n 行each 為 x y。
輸出最近的 k 個點，格式 "(x,y)"，以空白分隔，依距離由近到遠排序。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); k = int(data[idx + 1]); idx += 2
        if n == 0 and k == 0:
            break
        pts = []
        for _ in range(n):
            x = int(data[idx]); y = int(data[idx + 1]); idx += 2
            pts.append((x * x + y * y, x, y))
        pts.sort()
        out.append(' '.join(f"({x},{y})" for _, x, y in pts[:k]))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4 2
1 3
-2 2
5 8
0 1
== 範例 1 輸出 ==
(0,1) (-2,2)

== 範例 2 輸入 ==
3 3
3 3
5 -1
-2 4
== 範例 2 輸出 ==
(3,3) (-2,4) (5,-1)
