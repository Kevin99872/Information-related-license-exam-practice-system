CPE Lowest Common Ancestor

難度：中等
來源：原創（最近共同祖先 (LCA)：父節點陣列走訪法）

== 題目 ==
給定一棵樹的父節點陣列表示 (parent[i] 為節點 i 的父節點，根節點為 -1)，回答 q 個查詢：節點 u 與 v 的最近共同祖先 (LCA)。

輸入說明：每組第一行 n，第二行 n 個整數 (parent 陣列)；接著一行查詢數 q，再 q 行each 兩個整數 u v。n=0 表示輸入結束。
輸出說明：每個查詢輸出 LCA 節點編號。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        parent = [int(data[idx + i]) for i in range(n)]
        idx += n
        depth = [-1] * n
        root = parent.index(-1)
        depth[root] = 0

        def get_depth(u):
            if depth[u] != -1:
                return depth[u]
            depth[u] = get_depth(parent[u]) + 1
            return depth[u]

        for i in range(n):
            get_depth(i)
        q = int(data[idx]); idx += 1
        for _ in range(q):
            u = int(data[idx]); v = int(data[idx + 1]); idx += 2
            while depth[u] > depth[v]:
                u = parent[u]
            while depth[v] > depth[u]:
                v = parent[v]
            while u != v:
                u = parent[u]
                v = parent[v]
            out.append(str(u))
    print('\n'.join(out))

main()
