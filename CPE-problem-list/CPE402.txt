CPE Diameter of Binary Tree

難度：中等
來源：原創（樹狀動態規劃：二元樹直徑）

== 題目 ==
給定一棵二元樹 (陣列表示，節點 0 為根，left[i]/right[i] 為左右子節點索引，-1 表示不存在)，求樹的直徑 (任兩節點間最長路徑所經過的邊數)。

輸入說明：每組第一行 n，接著 n 行each 兩個整數 (節點 0~n-1 依序的 left、right)。n=0 表示輸入結束。
輸出說明：每組輸出樹的直徑。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        left, right = [], []
        for _ in range(n):
            left.append(int(data[idx])); right.append(int(data[idx + 1])); idx += 2
        best = [0]

        def height(u):
            if u == -1:
                return 0
            lh = height(left[u])
            rh = height(right[u])
            best[0] = max(best[0], lh + rh)
            return 1 + max(lh, rh)

        height(0)
        out.append(str(best[0]))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
1 2
3 4
-1 -1
-1 -1
-1 -1
0
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
1
-1 -1
0
== 範例 2 輸出 ==
0
