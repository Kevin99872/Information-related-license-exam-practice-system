CPE Container With Most Water

難度：中等
來源：原創（雙指標：最大容器盛水量）

== 題目 ==
給定 n 個非負整數，第 i 個代表座標 i 處垂直線的高度。從中選兩條線與 x 軸構成容器，求能容納的最大水量 (容量 = min(高度) * 兩線距離)。

輸入說明：每組第一行 n，第二行 n 個非負整數。n=0 表示輸入結束。
輸出說明：每組輸出最大容量。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        h = [int(data[idx + i]) for i in range(n)]
        idx += n
        l, r = 0, n - 1
        best = 0
        while l < r:
            best = max(best, (r - l) * min(h[l], h[r]))
            if h[l] < h[r]:
                l += 1
            else:
                r -= 1
        out.append(str(best))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
9
1 8 6 2 5 4 8 3 7
0
== 範例 1 輸出 ==
49

== 範例 2 輸入 ==
2
1 1
0
== 範例 2 輸出 ==
1
