CPE Task Scheduler

難度：中等
來源：原創（貪心：CPU 任務排程含冷卻時間）

== 題目 ==
給定一串工作 (以大寫字母表示種類) 與冷卻時間 n_cool，相同種類的兩個工作之間至少要間隔 n_cool 個單位時間 (可用閒置或執行其他工作填補)，求完成所有工作所需的最少總時間單位。

輸入說明：每行為 "工作字串 n_cool"，"#" 表示輸入結束。
輸出說明：每行輸出所需的最少總時間單位。

== 參考解法 (Python) ==
import sys
from collections import Counter

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        parts = line.split()
        tasks = parts[0]
        if tasks == '#':
            break
        n_cool = int(parts[1])
        counts = Counter(tasks)
        max_freq = max(counts.values())
        num_max = sum(1 for v in counts.values() if v == max_freq)
        total = (max_freq - 1) * (n_cool + 1) + num_max
        out.append(str(max(total, len(tasks))))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
AAABBB 2
#
== 範例 1 輸出 ==
8

== 範例 2 輸入 ==
AAAAA 0
#
== 範例 2 輸出 ==
5
