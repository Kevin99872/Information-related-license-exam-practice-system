CPE 10061 How Many Zeros and How Many Digits?

難度：困難
來源：改編自 UVa Online Judge #10061 (CPE 大學程式能力檢定經典題)

== 題目 ==
給定 n 與進制 b，求 n! (n 的階乘) 在 b 進制表示下，結尾共有幾個 0。

輸入說明：每行兩個整數 n 與 b (0<=n<=1000000000000, 2<=b<=1000)，處理到檔案結尾。
輸出說明：每行輸出 n! 在 b 進制下結尾 0 的個數。

== 參考解法 (Python) ==
import sys

def factorize(b):
    factors = {}
    d = 2
    while d * d <= b:
        while b % d == 0:
            factors[d] = factors.get(d, 0) + 1
            b //= d
        d += 1
    if b > 1:
        factors[b] = factors.get(b, 0) + 1
    return factors

def legendre(n, p):
    count = 0
    power = p
    while power <= n:
        count += n // power
        power *= p
    return count

for line in sys.stdin:
    line = line.strip()
    if not line:
        continue
    n, b = map(int, line.split())
    factors = factorize(b)
    if n == 0:
        print(0)
        continue
    ans = min(legendre(n, p) // e for p, e in factors.items())
    print(ans)
