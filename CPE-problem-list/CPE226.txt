CPE Wildcard Pattern Matching

難度：困難
來源：原創（動態規劃：萬用字元比對 (? 與 *)）

== 題目 ==
給定字串 s 與樣式 p (p 中 '?' 可匹配任意一個字元，'*' 可匹配任意長度 (含 0) 的任意字元序列)，判斷 s 是否完全符合 p。

輸入說明：每行兩個以空白分隔的字串 s p，讀到檔案結尾。
輸出說明：每行輸出 Yes 或 No。

== 參考解法 (Python) ==
import sys

def is_match(s, p):
    n, m = len(s), len(p)
    dp = [[False] * (m + 1) for _ in range(n + 1)]
    dp[0][0] = True
    for j in range(1, m + 1):
        if p[j - 1] == '*':
            dp[0][j] = dp[0][j - 1]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if p[j - 1] == '*':
                dp[i][j] = dp[i - 1][j] or dp[i][j - 1]
            elif p[j - 1] == '?' or p[j - 1] == s[i - 1]:
                dp[i][j] = dp[i - 1][j - 1]
    return dp[n][m]

def main():
    out = []
    for line in sys.stdin:
        line = line.rstrip('\n')
        if not line:
            continue
        s, p = line.split()
        out.append('Yes' if is_match(s, p) else 'No')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
aa a
aa *
cb ?a
== 範例 1 輸出 ==
No
Yes
No

== 範例 2 輸入 ==
adceb *a*b
== 範例 2 輸出 ==
Yes
