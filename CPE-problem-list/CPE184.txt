CPE Maximum Product Subarray

難度：中等
來源：原創（動態規劃：最大連續子陣列乘積）

== 題目 ==
給定 n 個整數 (可能為負或 0)，求連續子陣列的最大乘積 (子陣列長度至少為 1)。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出最大乘積。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        nums = [int(data[idx + i]) for i in range(n)]
        idx += n
        best = cur_max = cur_min = nums[0]
        for x in nums[1:]:
            candidates = (x, cur_max * x, cur_min * x)
            cur_max = max(candidates)
            cur_min = min(candidates)
            best = max(best, cur_max)
        out.append(str(best))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4
2 3 -2 4
0
== 範例 1 輸出 ==
6

== 範例 2 輸入 ==
3
-2 0 -1
0
== 範例 2 輸出 ==
0
