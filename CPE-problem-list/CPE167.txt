CPE 11078 Open Credit System

難度：簡單
來源：改編自 UVa Online Judge #11078 (CPE 大學程式能力檢定經典題)

== 題目 ==
有 n 位學生依序編號 1~n (編號小者為學長姐)，第 i 個學生分數為 score[i]。求「學長姐分數減學弟妹分數」的最大值 (即找 i<j 使 score[i]-score[j] 最大，可能為負)。

輸入說明：每組第一行 n (2<=n<=100000)，接著 n 個整數分數。測試個數 T 於第一行給定。
輸出說明：每組輸出最大差值。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    t = int(data[idx]); idx += 1
    out = []
    for _ in range(t):
        n = int(data[idx]); idx += 1
        scores = [int(data[idx + i]) for i in range(n)]
        idx += n
        best = -10 ** 9
        run_max = scores[0]
        for j in range(1, n):
            best = max(best, run_max - scores[j])
            run_max = max(run_max, scores[j])
        out.append(str(best))
    print('\n'.join(out))

main()
