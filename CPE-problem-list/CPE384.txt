CPE Range Sum Query 2D - Immutable

難度：中等
來源：原創（二維前綴和：不可變矩陣的子矩形和查詢）

== 題目 ==
給定 R*C 矩陣 (不會更動)，回答 q 個查詢：子矩形 (r1,c1) 到 (r2,c2) (0-indexed，含兩端) 內所有元素的總和。

輸入說明：每組第一行 R C，接著 R 行each C 個整數；接著一行查詢數 q，再 q 行each 四個整數 r1 c1 r2 c2。R=0 且 C=0 表示輸入結束。
輸出說明：每個查詢輸出對應的子矩形總和。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        r, c = map(int, line.split())
        if r == 0 and c == 0:
            break
        grid = []
        for i in range(r):
            grid.append(list(map(int, data[idx].split()))); idx += 1
        prefix = [[0] * (c + 1) for _ in range(r + 1)]
        for i in range(r):
            for j in range(c):
                prefix[i + 1][j + 1] = prefix[i][j + 1] + prefix[i + 1][j] - prefix[i][j] + grid[i][j]
        q = int(data[idx].strip()); idx += 1
        for _ in range(q):
            r1, c1, r2, c2 = map(int, data[idx].split()); idx += 1
            total = prefix[r2 + 1][c2 + 1] - prefix[r1][c2 + 1] - prefix[r2 + 1][c1] + prefix[r1][c1]
            out.append(str(total))
    print('\n'.join(out))

main()
