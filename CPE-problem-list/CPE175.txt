CPE 3Sum Triple Count

難度：中等
來源：原創（雙指標：三數之和計數）

== 題目 ==
給定 n 個整數與目標值 target，求有多少組「相異索引」的三元組 (i,j,k)，i<j<k，使得 a[i]+a[j]+a[k]=target (三元組的「值組合」不重複計數，即相同的三個數值只算一次)。

輸入說明：每組第一行 n target，第二行 n 個整數。n=0 且 target=0 表示輸入結束。
輸出說明：每組輸出符合條件的三元組數量。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); target = int(data[idx + 1]); idx += 2
        if n == 0 and target == 0:
            break
        nums = sorted(int(data[idx + i]) for i in range(n))
        idx += n
        count = 0
        for i in range(n - 2):
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            l, r = i + 1, n - 1
            while l < r:
                s = nums[i] + nums[l] + nums[r]
                if s == target:
                    count += 1
                    l += 1
                    r -= 1
                    while l < r and nums[l] == nums[l - 1]:
                        l += 1
                    while l < r and nums[r] == nums[r + 1]:
                        r -= 1
                elif s < target:
                    l += 1
                else:
                    r -= 1
        out.append(str(count))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
6 0
-1 0 1 2 -1 -4
0 0
== 範例 1 輸出 ==
2

== 範例 2 輸入 ==
3 6
1 2 3
0 0
== 範例 2 輸出 ==
1
