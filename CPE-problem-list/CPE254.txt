CPE 156 Ananagrams

難度：中等
來源：改編自 UVa Online Judge #156 (CPE 大學程式能力檢定經典題)

== 題目 ==
給定一份單字字典 (不分大小寫比對是否為變位詞，例如 'tIeD' 與 'EdiT'視為彼此的變位詞)，找出「沒有任何變位詞夥伴」的單字 (稱為相對非變位詞)。

輸入說明：多行文字，每行含任意數量、以空白分隔的單字 (最多 1000 個單字)，直到出現單獨一行 "#" 為止 (不處理)。
輸出說明：依「字典序 (區分大小寫)」輸出所有沒有變位詞夥伴的單字，每行一個。

== 參考解法 (Python) ==
import sys
from collections import defaultdict

def main():
    words = []
    for line in sys.stdin:
        line = line.strip()
        if line == '#':
            break
        if not line:
            continue
        words.extend(line.split())
    groups = defaultdict(list)
    for w in words:
        key = ''.join(sorted(w.lower()))
        groups[key].append(w)
    result = [w for ws in groups.values() if len(ws) == 1 for w in ws]
    result.sort()
    print('\n'.join(result))

main()
