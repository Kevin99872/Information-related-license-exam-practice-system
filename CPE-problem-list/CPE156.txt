CPE 455 Periodic Strings

難度：簡單
來源：改編自 UVa Online Judge #455 (CPE 大學程式能力檢定經典題)

== 題目 ==
若一個字串可以由「某個長度 k 的字串」重複串接一次以上組成，則稱該字串的週期為 k。求給定字串的「最小」週期。

輸入說明：第一行為測試個數，之後空一行；每個 case 一行字串 (長度<=80)，case 之間空一行。
輸出說明：每個 case 輸出最小週期；case 之間空一行。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    while data[idx].strip() == '':
        idx += 1
    n = int(data[idx].strip()); idx += 1
    out = []
    for case in range(n):
        while data[idx].strip() == '':
            idx += 1
        s = data[idx].strip(); idx += 1
        L = len(s)
        period = L
        for k in range(1, L + 1):
            if L % k == 0 and s[:k] * (L // k) == s:
                period = k
                break
        if case > 0:
            out.append('')
        out.append(str(period))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
1

HoHoHo
== 範例 1 輸出 ==
2

== 範例 2 輸入 ==
2

abcabcabcabc

abcd
== 範例 2 輸出 ==
3
