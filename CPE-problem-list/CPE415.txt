CPE 0/1 Knapsack Item Reconstruction

難度：中等
來源：原創（動態規劃：0/1 背包還原所選物品）

== 題目 ==
給定 n 個物品 (各有重量與價值) 與背包容量 cap，求最大總價值，並輸出所選物品的編號 (0-indexed，依原順序)。

輸入說明：每組第一行 n cap，接著 n 行each 兩個整數 w v。n=0 且 cap=0 表示輸入結束。
輸出說明：每組輸出最大總價值，以及所選物品編號 (以空白分隔)。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); cap = int(data[idx + 1]); idx += 2
        if n == 0 and cap == 0:
            break
        items = []
        for _ in range(n):
            w = int(data[idx]); v = int(data[idx + 1]); idx += 2
            items.append((w, v))
        dp = [[0] * (cap + 1) for _ in range(n + 1)]
        for i in range(1, n + 1):
            w, v = items[i - 1]
            for c in range(cap + 1):
                dp[i][c] = dp[i - 1][c]
                if w <= c:
                    dp[i][c] = max(dp[i][c], dp[i - 1][c - w] + v)
        chosen = []
        c = cap
        for i in range(n, 0, -1):
            if dp[i][c] != dp[i - 1][c]:
                chosen.append(i - 1)
                c -= items[i - 1][0]
        chosen.reverse()
        out.append(str(dp[n][cap]))
        out.append(' '.join(map(str, chosen)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3 50
10 60
20 100
30 120
0 0
== 範例 1 輸出 ==
220
1 2

== 範例 2 輸入 ==
2 5
2 3

== 範例 2 輸出 ==
8
