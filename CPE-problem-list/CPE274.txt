CPE Find Peak Element

難度：中等
來源：原創（二分搜尋：尋找峰值元素）

== 題目 ==
給定 n 個整數 (相鄰元素不相等)，峰值元素定義為「嚴格大於左右相鄰元素」的元素 (陣列頭尾視為只有一側相鄰)。用二分搜尋法求任一個峰值元素的索引。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出一個峰值元素的索引。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        lo, hi = 0, n - 1
        while lo < hi:
            mid = (lo + hi) // 2
            if a[mid] > a[mid + 1]:
                hi = mid
            else:
                lo = mid + 1
        out.append(str(lo))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4
1 2 3 1
0
== 範例 1 輸出 ==
2

== 範例 2 輸入 ==
6
1 2 1 3 5 6
0
== 範例 2 輸出 ==
5
