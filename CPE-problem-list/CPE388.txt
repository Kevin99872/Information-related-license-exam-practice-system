CPE Jump Game

難度：簡單
來源：原創（貪心：跳躍遊戲可達性判斷）

== 題目 ==
給定 n 個非負整數，第 i 個表示從該位置最多能往前跳的步數，起點在索引 0，判斷是否能到達最後一個索引。

輸入說明：每組第一行 n，第二行 n 個非負整數。n=0 表示輸入結束。
輸出說明：每組輸出 Yes 或 No。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        reach = 0
        ok = True
        for i in range(n):
            if i > reach:
                ok = False
                break
            reach = max(reach, i + a[i])
        out.append('Yes' if ok else 'No')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
2 3 1 1 4
0
== 範例 1 輸出 ==
Yes

== 範例 2 輸入 ==
5
3 2 1 0 4
0
== 範例 2 輸出 ==
No
