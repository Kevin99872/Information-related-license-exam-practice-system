CPE Design Circular Deque

難度：中等
來源：原創（資料結構設計：環狀雙端佇列）

== 題目 ==
實作容量為 cap 的雙端佇列，支援 PUSH_FRONT x、PUSH_BACK x、POP_FRONT、POP_BACK、FRONT、BACK 六種指令。

輸入說明：每組第一行為容量 cap，第二行為指令數 q，接著 q 行指令。cap=0 表示輸入結束。
輸出說明：PUSH/POP 指令輸出 true 或 false (成功與否)；FRONT/BACK 指令輸出對應元素，若佇列為空輸出 -1。

== 參考解法 (Python) ==
import sys
from collections import deque

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        cap = int(line)
        if cap == 0:
            break
        dq = deque()
        q = int(data[idx].strip()); idx += 1
        for _ in range(q):
            parts = data[idx].split(); idx += 1
            cmd = parts[0]
            if cmd == 'PUSH_FRONT':
                if len(dq) < cap:
                    dq.appendleft(int(parts[1]))
                    out.append('true')
                else:
                    out.append('false')
            elif cmd == 'PUSH_BACK':
                if len(dq) < cap:
                    dq.append(int(parts[1]))
                    out.append('true')
                else:
                    out.append('false')
            elif cmd == 'POP_FRONT':
                if dq:
                    dq.popleft()
                    out.append('true')
                else:
                    out.append('false')
            elif cmd == 'POP_BACK':
                if dq:
                    dq.pop()
                    out.append('true')
                else:
                    out.append('false')
            elif cmd == 'FRONT':
                out.append(str(dq[0]) if dq else '-1')
            elif cmd == 'BACK':
                out.append(str(dq[-1]) if dq else '-1')
    print('\n'.join(out))

main()
