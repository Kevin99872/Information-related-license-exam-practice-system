CPE Product of Array Except Self

難度：簡單
來源：原創（陣列：除自身以外元素的乘積）

== 題目 ==
給定 n 個整數，對每個位置求「除了該位置以外」所有元素的乘積 (不可使用除法)。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出結果陣列 (以空白分隔)。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        result = [1] * n
        left = 1
        for i in range(n):
            result[i] = left
            left *= a[i]
        right = 1
        for i in range(n - 1, -1, -1):
            result[i] *= right
            right *= a[i]
        out.append(' '.join(map(str, result)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4
1 2 3 4
0
== 範例 1 輸出 ==
24 12 8 6

== 範例 2 輸入 ==
3
2 0 3
0
== 範例 2 輸出 ==
0 6 0
