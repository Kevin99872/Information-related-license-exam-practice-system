CPE 10050 Hartals

難度：中等
來源：改編自 UVa Online Judge #10050 (CPE 大學程式能力檢定經典題)

== 題目 ==
某地政黨會發動罷工（hartal）。第 i 個政黨每隔 h_i 天罷工一次（也就是在第 h_i, 2*h_i, 3*h_i, ... 天罷工），但週五、週六為公休日，即使當天輪到罷工也不會造成損失（因為本來就不上班）。模擬從第 1 天（星期日）開始的 N 天，求有多少個工作天因罷工而損失（只要當天有任一政黨罷工且非週五六，就算損失一天，不重複計算）。

輸入說明：第一行測試個數 T。每個 case：第一行 N (7<=N<=3650)；第二行政黨數 P (1<=P<=100)；接著 P 行，每行一個 h_i（保證不是 7 的倍數）。
輸出說明：每個 case 輸出損失的工作天數。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    t = int(data[idx]); idx += 1
    out = []
    for _ in range(t):
        n = int(data[idx]); idx += 1
        p = int(data[idx]); idx += 1
        hs = [int(data[idx + i]) for i in range(p)]
        idx += p
        lost = 0
        for d in range(1, n + 1):
            weekday = (d - 1) % 7
            if weekday in (5, 6):
                continue
            if any(d % h == 0 for h in hs):
                lost += 1
        out.append(str(lost))
    print('\n'.join(out))

main()
