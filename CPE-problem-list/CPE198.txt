CPE Longest Consecutive Sequence

難度：中等
來源：原創（雜湊集合：最長連續數字序列）

== 題目 ==
給定 n 個整數 (可能不連續、可能有重複)，求其中「數值連續」的最長子序列長度 (例如 [100,4,200,1,3,2] 中最長連續序列為 1,2,3,4，長度為 4)。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出最長連續序列的長度。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        nums = set(int(data[idx + i]) for i in range(n))
        idx += n
        best = 0
        for x in nums:
            if x - 1 not in nums:
                length = 1
                while x + length in nums:
                    length += 1
                best = max(best, length)
        out.append(str(best))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
6
100 4 200 1 3 2
0
== 範例 1 輸出 ==
4

== 範例 2 輸入 ==
5
0 3 7 2 5
0
== 範例 2 輸出 ==
2
