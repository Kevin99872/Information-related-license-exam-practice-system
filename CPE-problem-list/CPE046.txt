CPE Perfect Number

難度：簡單
來源：原創（完全數經典數論主題）

== 題目 ==
若一個正整數等於其所有真因數 (不含自身) 之和，稱為完全數 (Perfect Number)。例如 6=1+2+3。

輸入說明：每行一個正整數 n，以 0 結束 (不處理)。
輸出說明：是完全數輸出 N is a perfect number.，否則輸出 N is not a perfect number.

== 參考解法 (Python) ==
import sys

def divisor_sum(n):
    total = 0
    i = 1
    while i * i <= n:
        if n % i == 0:
            if i != n:
                total += i
            j = n // i
            if j != i and j != n:
                total += j
        i += 1
    return total

for line in sys.stdin:
    line = line.strip()
    if not line:
        continue
    n = int(line)
    if n == 0:
        break
    if divisor_sum(n) == n:
        print(f"{n} is a perfect number.")
    else:
        print(f"{n} is not a perfect number.")

== 範例 1 輸入 ==
6
28
10
0
== 範例 1 輸出 ==
6 is a perfect number.
28 is a perfect number.
10 is not a perfect number.

== 範例 2 輸入 ==
496
8128
100
0
== 範例 2 輸出 ==
496 is a perfect number.
8128 is a perfect number.
100 is not a perfect number.
