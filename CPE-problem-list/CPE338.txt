CPE Round Robin CPU Scheduling

難度：中等
來源：原創（輪詢排程 (Round Robin) 模擬）

== 題目 ==
給定 n 個工作的執行時間與時間片長度 q，使用輪詢排程 (依序取隊首工作執行最多 q 單位時間，若未完成則放回佇列尾端)，求所有工作的平均完成時間。

輸入說明：每組第一行 n q，第二行 n 個正整數 (各工作所需執行時間)。n=0 且 q=0 表示輸入結束。
輸出說明：每組輸出平均完成時間，四捨五入到小數點後 2 位。

== 參考解法 (Python) ==
import sys
from collections import deque

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); q = int(data[idx + 1]); idx += 2
        if n == 0 and q == 0:
            break
        burst = [int(data[idx + i]) for i in range(n)]
        idx += n
        remain = burst[:]
        finish = [0] * n
        queue = deque(range(n))
        time = 0
        while queue:
            i = queue.popleft()
            run = min(q, remain[i])
            time += run
            remain[i] -= run
            if remain[i] > 0:
                queue.append(i)
            else:
                finish[i] = time
        out.append(f"{sum(finish) / n:.2f}")
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3 4
5 3 8
0 0
== 範例 1 輸出 ==
11.67

== 範例 2 輸入 ==
2 2
4 4

== 範例 2 輸出 ==
