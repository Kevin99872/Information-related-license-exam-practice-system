CPE N 皇后輸出所有解

難度：困難
來源：原創（回溯法列舉所有解）

== 題目 ==
給定整數 n，請在 n x n 的棋盤上擺放 n 個皇后，使任兩個皇后都不在同一行、同一列、
同一對角線上。請輸出解的總數，以及每個解的擺放方式：以長度 n 的序列表示，第 i 個數字代表第 i 列
（0-indexed）皇后所在的行（column，0-indexed）。解的輸出順序依回溯搜尋（列由小到大、行由小到大）的順序。

輸入每行一個整數 n（1 <= n <= 8），直到檔案結束。
對每個 n，先輸出解的總數，再依序輸出每個解（每行一個，以空白分隔）。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        solutions = []
        cols = set(); d1 = set(); d2 = set()
        placement = []

        def backtrack(row):
            if row == n:
                solutions.append(list(placement))
                return
            for col in range(n):
                if col in cols or (row - col) in d1 or (row + col) in d2:
                    continue
                cols.add(col); d1.add(row - col); d2.add(row + col)
                placement.append(col)
                backtrack(row + 1)
                placement.pop()
                cols.remove(col); d1.remove(row - col); d2.remove(row + col)

        backtrack(0)
        out.append(str(len(solutions)))
        for sol in solutions:
            out.append(' '.join(map(str, sol)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4
1
== 範例 1 輸出 ==
2
1 3 0 2
2 0 3 1
1
0
