CPE Infix to Postfix Conversion

難度：中等
來源：原創（堆疊：中序轉後序表示法 (Shunting-yard)）

== 題目 ==
給定一個中序算式 (以空白分隔的數字、運算子 +、-、*、/ 與括號)，轉換成後序 (逆波蘭) 表示法。

輸入說明：每行一個以空白分隔的中序算式，讀到檔案結尾。
輸出說明：每行輸出轉換後的後序表示法 (以空白分隔)。

== 參考解法 (Python) ==
import sys

PREC = {'+': 1, '-': 1, '*': 2, '/': 2}

def main():
    out = []
    for line in sys.stdin:
        tokens = line.strip().split()
        if not tokens:
            continue
        output = []
        ops = []
        for tok in tokens:
            if tok not in PREC and tok not in '()':
                output.append(tok)
            elif tok == '(':
                ops.append(tok)
            elif tok == ')':
                while ops and ops[-1] != '(':
                    output.append(ops.pop())
                ops.pop()
            else:
                while ops and ops[-1] != '(' and PREC[ops[-1]] >= PREC[tok]:
                    output.append(ops.pop())
                ops.append(tok)
        while ops:
            output.append(ops.pop())
        out.append(' '.join(output))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3 + 4 * 2
( 1 + 2 ) * 3
== 範例 1 輸出 ==
3 4 2 * +
1 2 + 3 *

== 範例 2 輸入 ==
a + b * ( c - d )
== 範例 2 輸出 ==
a b c d - * +
