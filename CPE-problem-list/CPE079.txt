CPE Prime Count in Range

難度：簡單
來源：原創（埃拉托斯特尼篩法 / Sieve of Eratosthenes）

== 題目 ==
給定區間 [a,b]，計算此區間內 (含兩端) 質數的個數。

輸入說明：每行兩個整數 a b (1<=a<=b<=200000)，以 "0 0" 結束。
輸出說明：每行輸出區間內質數的個數。

== 參考解法 (Python) ==
import sys

LIMIT = 200000
is_prime = bytearray([1]) * (LIMIT + 1)
is_prime[0] = is_prime[1] = 0
for i in range(2, int(LIMIT ** 0.5) + 1):
    if is_prime[i]:
        for j in range(i * i, LIMIT + 1, i):
            is_prime[j] = 0
prefix = [0] * (LIMIT + 1)
cnt = 0
for i in range(LIMIT + 1):
    if is_prime[i]:
        cnt += 1
    prefix[i] = cnt

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        a = int(data[idx]); b = int(data[idx + 1]); idx += 2
        if a == 0 and b == 0:
            break
        out.append(str(prefix[b] - (prefix[a - 1] if a > 0 else 0)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
1 10
10 50
0 0
== 範例 1 輸出 ==
4
11

== 範例 2 輸入 ==
2 2
100 100
0 0
== 範例 2 輸出 ==
1
0
