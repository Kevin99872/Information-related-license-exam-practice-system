CPE Median of Two Sorted Arrays

難度：中等
來源：原創（兩個已排序陣列的中位數）

== 題目 ==
給定兩個已由小到大排序的陣列，求合併後的中位數 (元素總數為奇數時輸出中間值；為偶數時輸出中間兩數的平均，取到小數點後 1 位)。

輸入說明：每組第一行 n m，第二行 n 個整數 (陣列 A)，第三行 m 個整數 (陣列 B)。n=0 且 m=0 表示輸入結束。
輸出說明：每組輸出中位數。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); m = int(data[idx + 1]); idx += 2
        if n == 0 and m == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        b = [int(data[idx + i]) for i in range(m)]
        idx += m
        merged = sorted(a + b)
        total = n + m
        if total % 2 == 1:
            out.append(str(merged[total // 2]))
        else:
            out.append(f"{(merged[total // 2 - 1] + merged[total // 2]) / 2:.1f}")
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
2 2
1 3
2 4
0 0
== 範例 1 輸出 ==
2.5

== 範例 2 輸入 ==
3 0
1 2 3

0 0
== 範例 2 輸出 ==
2
