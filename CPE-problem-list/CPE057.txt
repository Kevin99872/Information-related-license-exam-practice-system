CPE 10019 Funny Encryption Method

難度：簡單
來源：改編自 UVa Online Judge #10019 (CPE 大學程式能力檢定經典題)

== 題目 ==
給定一個十進位整數 M，將它分別解讀為「十進位」與「十六進位」兩種寫法（也就是把 M 的十進位數字字串直接當成十六進位數字字串），並各自轉成二進位表示。b1 為十進位版本二進位表示中 1 的個數，b2 為十六進位版本二進位表示中 1 的個數。

例如 M=265：十進位 265 的二進位為 100001001，b1=3。把字串 "265" 當十六進位得到 0x265=613，613 的二進位為 1001100101，b2=5。

輸入說明：第一行為測試個數 N，之後 N 行每行一個整數 M (0<M<=9999)。
輸出說明：每行輸出 b1 與 b2，以空白分隔。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    out = []
    for i in range(1, n + 1):
        m = data[i]
        b1 = bin(int(m)).count('1')
        b2 = bin(int(m, 16)).count('1')
        out.append(f"{b1} {b2}")
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3
265
111
1234
== 範例 1 輸出 ==
3 5
6 3
5 5

== 範例 2 輸入 ==
2
1
9999
== 範例 2 輸出 ==
1 1
8 8
