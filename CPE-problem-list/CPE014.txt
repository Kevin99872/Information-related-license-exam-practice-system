CPE 11461 Square Numbers

難度：簡單
來源：改編自 UVa Online Judge #11461 (CPE 大學程式能力檢定經典題)

== 題目 ==
完全平方數是可寫成某整數平方的數。求區間 [a,b] 內完全平方數的個數。

輸入說明：每行兩個整數 a 與 b (0<a<=b<=100000)，以 0 0 結束 (不處理)。
輸出說明：每行輸出該區間完全平方數的個數。

== 範例 1 輸入 ==
1 4
1 10
35 70
0 0
== 範例 1 輸出 ==
2
3
3

== 範例 2 輸入 ==
100 100
1 100000
0 0
== 範例 2 輸出 ==
1
316
