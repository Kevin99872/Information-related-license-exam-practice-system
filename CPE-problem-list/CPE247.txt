CPE Longest Palindromic Subsequence

難度：中等
來源：原創（動態規劃：最長回文子序列）

== 題目 ==
給定一個字串，求其「最長回文子序列」的長度 (子序列不要求連續)。

輸入說明：每行一個字串，讀到檔案結尾。
輸出說明：每行輸出最長回文子序列長度。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        s = line.strip()
        if not s:
            continue
        n = len(s)
        dp = [[0] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):
            dp[i][i] = 1
            for j in range(i + 1, n):
                if s[i] == s[j]:
                    dp[i][j] = dp[i + 1][j - 1] + 2
                else:
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
        out.append(str(dp[0][n - 1]))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
bbbab
cbbd
== 範例 1 輸出 ==
4
2

== 範例 2 輸入 ==
agbdba
== 範例 2 輸出 ==
5
