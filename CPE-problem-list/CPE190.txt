CPE Missing Number in 1..N

難度：簡單
來源：原創（遺失數字查找）

== 題目 ==
給定 1 到 N 中缺少「一個」數字後剩下的 N-1 個數字 (順序打亂)，求缺少的那個數字。

輸入說明：每組第一行 N，第二行 N-1 個整數。N=0 表示輸入結束。
輸出說明：每組輸出缺少的數字。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        nums = [int(data[idx + i]) for i in range(n - 1)]
        idx += n - 1
        out.append(str(n * (n + 1) // 2 - sum(nums)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
1 2 4 5
0
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
3
1 3
0
== 範例 2 輸出 ==
2
