CPE Longest Common Subsequence of Three Strings

難度：中等
來源：原創（動態規劃：三個字串的最長共同子序列）

== 題目 ==
給定三個字串，求其最長共同子序列的長度。

輸入說明：每組三行分別為字串 s1、s2、s3，直到出現單獨一行 "#" 為止 (不處理)。
輸出說明：每組輸出最長共同子序列長度。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        if line == '#':
            break
        s1 = line
        s2 = data[idx].strip(); idx += 1
        s3 = data[idx].strip(); idx += 1
        n1, n2, n3 = len(s1), len(s2), len(s3)
        dp = [[[0] * (n3 + 1) for _ in range(n2 + 1)] for _ in range(n1 + 1)]
        for i in range(1, n1 + 1):
            for j in range(1, n2 + 1):
                for k in range(1, n3 + 1):
                    if s1[i - 1] == s2[j - 1] == s3[k - 1]:
                        dp[i][j][k] = dp[i - 1][j - 1][k - 1] + 1
                    else:
                        dp[i][j][k] = max(dp[i - 1][j][k], dp[i][j - 1][k], dp[i][j][k - 1])
        out.append(str(dp[n1][n2][n3]))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
abcd1e2
bc12ea
bd1ea
#
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
abc
abc
abc
#
== 範例 2 輸出 ==
3
