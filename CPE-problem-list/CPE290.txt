CPE Polygon Area (Shoelace Formula)

難度：簡單
來源：原創（計算幾何：多邊形面積 (鞋帶公式)）

== 題目 ==
給定一個簡單多邊形的 n 個頂點 (依順序排列，順時針或逆時針皆可)，求其面積。

輸入說明：每組第一行 n，接著 n 行each 兩個整數 x y (依邊界順序給定)。n=0 表示輸入結束。
輸出說明：每組輸出面積，四捨五入到小數點後 1 位。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        pts = []
        for _ in range(n):
            x = int(data[idx]); y = int(data[idx + 1]); idx += 2
            pts.append((x, y))
        area2 = 0
        for i in range(n):
            x1, y1 = pts[i]
            x2, y2 = pts[(i + 1) % n]
            area2 += x1 * y2 - x2 * y1
        out.append(f"{abs(area2) / 2:.1f}")
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4
0 0
4 0
4 4
0 4
0
== 範例 1 輸出 ==
16.0

== 範例 2 輸入 ==
3
0 0
4 0
0 3
0
== 範例 2 輸出 ==
6.0
