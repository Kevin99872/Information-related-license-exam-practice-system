CPE Non-decreasing Array Check

難度：中等
來源：原創（貪心：最多修改一個元素使陣列非遞減）

== 題目 ==
給定 n 個整數，判斷是否能「最多修改一個元素」使整個陣列變成非遞減排序。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出 Yes 或 No。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        count = 0
        ok = True
        for i in range(1, n):
            if a[i - 1] > a[i]:
                count += 1
                if count > 1:
                    ok = False
                    break
                if i >= 2 and a[i - 2] > a[i]:
                    a[i] = a[i - 1]
                else:
                    a[i - 1] = a[i]
        out.append('Yes' if ok else 'No')
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3
4 2 3
0
== 範例 1 輸出 ==
Yes

== 範例 2 輸入 ==
3
4 2 1
0
== 範例 2 輸出 ==
No
