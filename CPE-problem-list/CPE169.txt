CPE 12100 Printer Queue

難度：簡單
來源：改編自 UVa Online Judge #12100 (CPE 大學程式能力檢定經典題)

== 題目 ==
印表機佇列依以下規則運作：取出佇列最前面的工作 J；若佇列中還有優先權比 J 高的工作，則把 J 放到佇列尾端 (不列印)；否則列印 J (並將其移除)。每次列印花費 1 分鐘，判斷／移動視為瞬間完成。給定佇列與自己工作所在位置，求自己的工作被列印所需的時間。

輸入說明：第一行為測試個數；每組第一行 n m (工作數、自己工作的位置，位置由 0 開始)，第二行為 n 個優先權 (1~9，9 最高)。
輸出說明：每組輸出所需的分鐘數。

== 參考解法 (Python) ==
import sys
from collections import deque

def main():
    data = sys.stdin.read().split()
    idx = 0
    t = int(data[idx]); idx += 1
    out = []
    for _ in range(t):
        n = int(data[idx]); m = int(data[idx + 1]); idx += 2
        prios = [int(data[idx + i]) for i in range(n)]
        idx += n
        q = deque((i, p) for i, p in enumerate(prios))
        time = 0
        while True:
            i, p = q.popleft()
            if any(pp > p for _, pp in q):
                q.append((i, p))
            else:
                time += 1
                if i == m:
                    break
        out.append(str(time))
    print('\n'.join(out))

main()
