CPE Matrix Rotation

難度：中等
來源：原創（二維陣列 / 矩陣旋轉基礎題型）

== 題目 ==
給定一個 n x n 矩陣，將其順時針旋轉 90 度後輸出。

輸入說明：每組第一行為 n；接著 n 行，每行 n 個以空白分隔的整數。以 n=0 結束 (不處理)。
輸出說明：每組輸出旋轉後的矩陣 (n 行，每行 n 個整數，以空白分隔)；各組之間以一個空行分隔。

== 參考解法 (Python) ==
import sys

data = sys.stdin.read().split('\n')
idx = 0
blocks = []
while idx < len(data):
    line = data[idx].strip()
    idx += 1
    if line == '':
        continue
    n = int(line)
    if n == 0:
        break
    mat = []
    for _ in range(n):
        mat.append(list(map(int, data[idx].split())))
        idx += 1
    rotated = [[mat[n - 1 - c][r] for c in range(n)] for r in range(n)]
    blocks.append('\n'.join(' '.join(map(str, row)) for row in rotated))
print('\n\n'.join(blocks))

3
1 2 3
4 5 6
7 8 9
0
== 範例 1 輸出 ==
7 4 1
8 5 2
9 6 3
