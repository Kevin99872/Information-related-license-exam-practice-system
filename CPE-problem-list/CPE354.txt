== 題目 ==
一根長度 l 公分的木桿上有若干隻螞蟻，每隻以每秒 1 公分的速度往左或往右走 (方向未知)，走到桿的任一端就掉落。兩隻螞蟻相遇時會同時掉頭 (等同於直接穿過彼此，不影響整體掉落時間的極值)。給定每隻螞蟻的初始位置，求「所有螞蟻都掉落」所需時間的最早與最晚可能值 (依方向指派的不同而異)。

輸入說明：第一行為測試個數。每組第一行為 l n (木桿長度、螞蟻數)，接著 n 個整數 (各螞蟻與左端的距離)。
輸出說明：每組輸出最早與最晚掉落時間，以空白分隔。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    t = int(data[idx]); idx += 1
    out = []
    for _ in range(t):
        l = int(data[idx]); n = int(data[idx + 1]); idx += 2
        pos = [int(data[idx + i]) for i in range(n)]
        idx += n
        earliest = max(min(p, l - p) for p in pos)
        latest = max(max(p, l - p) for p in pos)
        out.append(f"{earliest} {latest}")
    print('\n'.join(out))

main()
