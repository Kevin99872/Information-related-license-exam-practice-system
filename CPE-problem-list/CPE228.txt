CPE Gray Code Generation

難度：簡單
來源：原創（格雷碼生成）

== 題目 ==
給定位元數 n，輸出 n 位元的格雷碼序列 (相鄰兩個編碼只相差一個位元，共 2^n 個編碼，由 0 開始)。

輸入說明：每行一個整數 n (1<=n<=10)，讀到檔案結尾。
輸出說明：每行輸出該 n 對應的完整格雷碼序列 (以空白分隔，每個編碼固定 n 位元、不足補 0)。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        codes = []
        for i in range(1 << n):
            g = i ^ (i >> 1)
            codes.append(format(g, f'0{n}b'))
        out.append(' '.join(codes))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
2
1
== 範例 1 輸出 ==
00 01 11 10
0 1

== 範例 2 輸入 ==
3
== 範例 2 輸出 ==
000 001 011 010 110 111 101 100
