CPE Maximum Flow (Edmonds-Karp)

難度：困難
來源：原創（Edmonds-Karp 演算法：最大流量）

== 題目 ==
給定一個含 n 個節點、m 條有向邊 (各有容量) 的流量網路，求從來源 s 到匯點 t 的最大流量。

輸入說明：每組第一行 n m s t，接著 m 行each 三個整數 u v cap。n=0 且 m=0 且 s=0 且 t=0 表示輸入結束。
輸出說明：每組輸出最大流量。

== 參考解法 (Python) ==
import sys
from collections import deque

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); m = int(data[idx + 1]); s = int(data[idx + 2]); t = int(data[idx + 3]); idx += 4
        if n == 0 and m == 0:
            break
        cap = [[0] * n for _ in range(n)]
        for _ in range(m):
            u = int(data[idx]); v = int(data[idx + 1]); c = int(data[idx + 2]); idx += 3
            cap[u][v] += c

        def bfs():
            parent = [-1] * n
            parent[s] = s
            q = deque([s])
            while q:
                u = q.popleft()
                for v in range(n):
                    if parent[v] == -1 and cap[u][v] > 0:
                        parent[v] = u
                        q.append(v)
            return parent

        total = 0
        while True:
            parent = bfs()
            if parent[t] == -1:
                break
            push = float('inf')
            v = t
            while v != s:
                u = parent[v]
                push = min(push, cap[u][v])
                v = u
            v = t
            while v != s:
                u = parent[v]
                cap[u][v] -= push
                cap[v][u] += push
                v = u
            total += push
        out.append(str(total))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4 5 0 3
0 1 3
0 2 2
1 2 1
1 3 2
2 3 3
0 0 0 0
== 範例 1 輸出 ==
5
