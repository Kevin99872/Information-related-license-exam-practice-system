CPE Word Ladder

難度：中等
來源：原創（BFS：詞梯問題 (單字接龍最短變換次數)）

== 題目 ==
給定起始單字 begin、目標單字 end 與一份單字字典，每次只能改變一個字母 (改變後的單字必須存在於字典中)，求從 begin 變換到 end 的最短序列「所含單字總數」(含 begin 與 end 本身；begin 不需要在字典中)；若無法變換到 end 則輸出 0。

輸入說明：每組第一行為 begin end (等長字串)；第二行為字典大小 n；接著 n 行each 一個字典單字。begin=="0" 表示輸入結束。
輸出說明：每組輸出最短序列的單字總數，或 0。

== 參考解法 (Python) ==
import sys
from collections import deque

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        parts = line.split()
        if parts[0] == '0':
            break
        begin, end = parts[0], parts[1]
        n = int(data[idx].strip()); idx += 1
        words = set()
        for _ in range(n):
            words.add(data[idx].strip()); idx += 1
        words.discard(begin)
        q = deque([(begin, 1)])
        visited = {begin}
        found = 0
        while q:
            word, steps = q.popleft()
            if word == end:
                found = steps
                break
            for i in range(len(word)):
                for c in 'abcdefghijklmnopqrstuvwxyz':
                    if c == word[i]:
                        continue
                    nw = word[:i] + c + word[i + 1:]
                    if nw in words and nw not in visited:
                        visited.add(nw)
                        q.append((nw, steps + 1))
        out.append(str(found))
    print('\n'.join(out))

main()
