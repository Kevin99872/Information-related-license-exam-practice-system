CPE First Missing Positive

難度：中等
來源：原創（陣列：第一個缺失的正整數）

== 題目 ==
給定 n 個整數 (可能含負數、0、重複值)，求「未出現在陣列中」的最小正整數。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出未出現的最小正整數。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        s = set(a)
        i = 1
        while i in s:
            i += 1
        out.append(str(i))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
3
1 2 0
0
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
3
3 4 -1
0
== 範例 2 輸出 ==
1
