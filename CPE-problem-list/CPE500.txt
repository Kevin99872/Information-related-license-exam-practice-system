CPE 相對排序陣列

難度：簡單
來源：原創（自訂排序鍵值）

== 題目 ==
給定兩個陣列 arr1 與 arr2，其中 arr2 中的元素皆不重複，且都存在於 arr1 中。
請將 arr1 中的元素依 arr2 所指定的相對順序排序；arr1 中未出現在 arr2 的元素，
則放在結果陣列最後，並依由小到大排序。

輸入格式：第一行為 arr1 長度 n1（n1=0 代表輸入結束）；第二行為 arr1 的 n1 個整數；
第三行為 arr2（以空白分隔，可能為空行代表 arr2 為空陣列）。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        n1 = int(line)
        if n1 == 0:
            break
        arr1 = list(map(int, data[idx].split())); idx += 1
        arr2 = list(map(int, data[idx].split())); idx += 1
        rank = {v: i for i, v in enumerate(arr2)}
        result = sorted(arr1, key=lambda x: (rank.get(x, len(arr2)), x))
        out.append(' '.join(map(str, result)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
11
2 3 1 3 2 4 6 7 9 2 19
2 1 4 3 9 6
== 範例 1 輸出 ==
2 2 2 1 4 3 3 9 6 7 19
