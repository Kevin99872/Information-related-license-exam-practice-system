CPE Maximum Overlapping Intervals

難度：中等
來源：原創（掃描線：最大重疊區間數 (會議室問題)）

== 題目 ==
給定 n 個時間區間 [l,r)，求同一時刻「最多」有幾個區間重疊 (區間包含左端點、不包含右端點)。

輸入說明：每組第一行 n，接著 n 行each 兩個整數 l r。n=0 表示輸入結束。
輸出說明：每組輸出最大重疊數。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        events = []
        for _ in range(n):
            l = int(data[idx]); r = int(data[idx + 1]); idx += 2
            events.append((l, 1))
            events.append((r, -1))
        events.sort(key=lambda e: (e[0], e[1]))
        cur = 0
        best = 0
        for _, delta in events:
            cur += delta
            best = max(best, cur)
        out.append(str(best))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4
1 5
2 6
4 8
7 9
0
== 範例 1 輸出 ==
3

== 範例 2 輸入 ==
3
1 2
2 3
3 4
0
== 範例 2 輸出 ==
1
