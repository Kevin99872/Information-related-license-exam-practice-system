CPE 展開二元樹為鏈結串列

難度：簡單
來源：原創（樹的前序走訪）

== 題目 ==
給定一棵二元樹（n 個節點，節點 0 為根），請將其「展開」為一個單向鏈結串列
（依先序走訪順序，只使用右子指標），輸出展開後每個節點的值依序排列。

輸入格式：第一行為 n（n=0 代表輸入結束）；
接下來 n 行each 為 val left right。

輸出：一行，展開後的節點值序列（等同前序走訪結果）。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        val, left, right = [], [], []
        for _ in range(n):
            val.append(int(data[idx])); left.append(int(data[idx + 1])); right.append(int(data[idx + 2])); idx += 3
        result = []

        def preorder(u):
            if u == -1:
                return
            result.append(val[u])
            preorder(left[u])
            preorder(right[u])

        preorder(0)
        out.append(' '.join(map(str, result)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
6
1 1 2
2 3 4
5 -1 5
3 -1 -1
4 -1 -1
6 -1 -1
== 範例 1 輸出 ==
1 2 3 4 5 6
