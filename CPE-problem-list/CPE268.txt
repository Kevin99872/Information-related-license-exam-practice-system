CPE Heap Sort

難度：簡單
來源：原創（堆積排序法）

== 題目 ==
給定 n 個整數，使用堆積排序法 (heap sort) 由小到大排序。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出排序後的結果 (以空白分隔)。

== 參考解法 (Python) ==
import sys
import heapq

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        heapq.heapify(a)
        result = [heapq.heappop(a) for _ in range(n)]
        out.append(' '.join(map(str, result)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
6
5 2 9 1 5 6
0
== 範例 1 輸出 ==
1 2 5 5 6 9

== 範例 2 輸入 ==
4
4 3 2 1
0
== 範例 2 輸出 ==
1 2 3 4
