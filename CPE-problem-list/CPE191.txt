CPE Find Duplicate Number

難度：簡單
來源：原創（重複數字查找）

== 題目 ==
給定 n 個整數，其中恰有一個數字重複出現 (其餘皆不重複)，求該重複的數字。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出重複的數字。

== 參考解法 (Python) ==
import sys
from collections import Counter

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        nums = [int(data[idx + i]) for i in range(n)]
        idx += n
        c = Counter(nums)
        out.append(str(next(x for x in nums if c[x] > 1)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
1 3 4 2 2
0
== 範例 1 輸出 ==
2

== 範例 2 輸入 ==
4
3 1 3 4
0
== 範例 2 輸出 ==
3
