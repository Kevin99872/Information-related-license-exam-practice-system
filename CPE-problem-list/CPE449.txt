CPE Move All Negatives to One Side

難度：簡單
來源：原創（陣列：負數移到前面 (保持相對順序)）

== 題目 ==
給定 n 個整數，將所有負數移到陣列前面、非負數移到後面 (各自保持原相對順序)。

輸入說明：每組第一行 n，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出調整後的陣列 (以空白分隔)。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        neg = [x for x in a if x < 0]
        nonneg = [x for x in a if x >= 0]
        out.append(' '.join(map(str, neg + nonneg)))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
6
1 -2 3 -4 5 -6
0
== 範例 1 輸出 ==
-2 -4 -6 1 3 5

== 範例 2 輸入 ==
3
1 2 3
0
== 範例 2 輸出 ==
1 2 3
