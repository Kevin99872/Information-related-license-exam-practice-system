CPE House Robber

難度：簡單
來源：原創（動態規劃：不能偷相鄰房屋的最大金額）

== 題目 ==
給定 n 間房屋各自的財物金額，一個小偷要偷竊，但「不能偷相鄰的兩間房屋」(否則會觸發警報)，求能偷到的最大總金額。

輸入說明：每組第一行 n，第二行 n 個非負整數。n=0 表示輸入結束。
輸出說明：每組輸出最大總金額。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        prev, cur = 0, 0
        for x in a:
            prev, cur = cur, max(cur, prev + x)
        out.append(str(cur))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4
1 2 3 1
0
== 範例 1 輸出 ==
4

== 範例 2 輸入 ==
5
2 7 9 3 1
0
== 範例 2 輸出 ==
12
