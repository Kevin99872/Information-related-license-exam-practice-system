== 題目 ==
一個鎮上有 N 位居民，某些人互為朋友，「朋友的朋友也是朋友」。求最大朋友群的人數。

輸入說明：第一行為測試個數；每組第一行 N M，接著 M 行each 兩個整數 (互為朋友的兩人編號，1<=編號<=N)。
輸出說明：每組輸出最大朋友群的人數。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    t = int(data[idx]); idx += 1
    out = []
    for _ in range(t):
        n = int(data[idx]); m = int(data[idx + 1]); idx += 2
        parent = list(range(n + 1))
        size = [1] * (n + 1)

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        for _ in range(m):
            a = int(data[idx]); b = int(data[idx + 1]); idx += 2
            ra, rb = find(a), find(b)
            if ra != rb:
                if size[ra] < size[rb]:
                    ra, rb = rb, ra
                parent[rb] = ra
                size[ra] += size[rb]
        out.append(str(max(size[find(i)] for i in range(1, n + 1))))
    print('\n'.join(out))

main()
