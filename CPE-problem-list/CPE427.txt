CPE Triangle Minimum Path Sum

難度：中等
來源：原創（動態規劃：三角形數陣最小路徑和）

== 題目 ==
給定一個三角形數陣 (第 i 列有 i+1 個數，0-indexed)，從頂端走到底端 (每步只能移動到下一列相鄰或右鄰的位置)，求路徑總和的最小值。

輸入說明：每組第一行 n (列數)，接著 n 行，第 i 行 (0-indexed) 有 i+1 個整數。n=0 表示輸入結束。
輸出說明：每組輸出最小路徑總和。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    out = []
    while idx < len(data):
        line = data[idx].strip(); idx += 1
        if line == '':
            continue
        n = int(line)
        if n == 0:
            break
        triangle = []
        for i in range(n):
            triangle.append(list(map(int, data[idx].split()))); idx += 1
        dp = triangle[-1][:]
        for i in range(n - 2, -1, -1):
            for j in range(i + 1):
                dp[j] = triangle[i][j] + min(dp[j], dp[j + 1])
        out.append(str(dp[0]))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4
2
3 4
6 5 7
4 1 8 3
0
== 範例 1 輸出 ==
11

== 範例 2 輸入 ==
1
-1
0
== 範例 2 輸出 ==
-1
