== 題目 ==
一份測驗結果以 'O' (答對) 與 'X' (答錯) 表示。第 i 題的得分為：若答錯得 0 分；若答對，得分為「自己與往前連續答對的題數」，例如連續答對 3 題時第 3 題得 3 分。求整份測驗的總分。

輸入說明：第一行為測試個數 T，之後每行一個由 O、X 組成的字串 (長度 1~79)。
輸出說明：每行輸出總分。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    t = int(data[idx]); idx += 1
    out = []
    for _ in range(t):
        s = data[idx]; idx += 1
        total = 0
        streak = 0
        for c in s:
            if c == 'O':
                streak += 1
                total += streak
            else:
                streak = 0
        out.append(str(total))
    print('\n'.join(out))

main()
