CPE Longest Substring with At Most K Distinct Characters

難度：中等
來源：原創（滑動視窗：最多 K 種相異字元的最長子字串）

== 題目 ==
給定字串 s 與整數 k，求「最多包含 k 種相異字元」的最長連續子字串長度。

輸入說明：每行為 "字串 k"，讀到檔案結尾。
輸出說明：每行輸出最長子字串長度。

== 參考解法 (Python) ==
import sys
from collections import defaultdict

def main():
    out = []
    for line in sys.stdin:
        line = line.rstrip('\n')
        if not line:
            continue
        s, k = line.rsplit(' ', 1)
        k = int(k)
        freq = defaultdict(int)
        left = 0
        best = 0
        for right, c in enumerate(s):
            freq[c] += 1
            while len(freq) > k:
                lc = s[left]
                freq[lc] -= 1
                if freq[lc] == 0:
                    del freq[lc]
                left += 1
            best = max(best, right - left + 1)
        out.append(str(best))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
eceba 2
aabbcc 1
== 範例 1 輸出 ==
3
2

== 範例 2 輸入 ==
aa 1
== 範例 2 輸出 ==
2
