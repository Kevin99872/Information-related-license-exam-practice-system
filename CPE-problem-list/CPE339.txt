CPE Minimum Swaps to Sort Array

難度：中等
來源：原創（環狀分解：排序陣列所需最少交換次數）

== 題目 ==
給定 n 個相異整數，求將其排序為由小到大所需的最少「交換」次數 (每次可交換任意兩個位置)。

輸入說明：每組第一行 n，第二行 n 個相異整數。n=0 表示輸入結束。
輸出說明：每組輸出最少交換次數。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        pos = sorted(range(n), key=lambda i: a[i])
        visited = [False] * n
        swaps = 0
        for i in range(n):
            if visited[i] or pos[i] == i:
                continue
            cycle_len = 0
            j = i
            while not visited[j]:
                visited[j] = True
                j = pos[j]
                cycle_len += 1
            swaps += cycle_len - 1
        out.append(str(swaps))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
4
4 3 2 1
0
== 範例 1 輸出 ==
2

== 範例 2 輸入 ==
5
2 3 4 1 5
0
== 範例 2 輸出 ==
3
