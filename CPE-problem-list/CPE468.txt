CPE 基本計算機

難度：中等
來源：原創（堆疊運算式求值）

== 題目 ==
給定一個包含非負整數、加號 '+'、減號 '-'、括號 '(' ')' 以及空白的算術運算式字串，
請計算其結果（不含乘除法）。

輸入每行一個運算式，直到檔案結束。

== 參考解法 (Python) ==
import sys

def main():
    out = []
    for line in sys.stdin:
        s = line.strip()
        if not s:
            continue
        stack = [1]
        sign = 1
        result = 0
        num = 0
        i = 0
        n = len(s)
        while i < n:
            c = s[i]
            if c.isdigit():
                num = 0
                while i < n and s[i].isdigit():
                    num = num * 10 + int(s[i])
                    i += 1
                result += sign * num * stack[-1]
                continue
            elif c == '+':
                sign = 1
            elif c == '-':
                sign = -1
            elif c == '(':
                stack.append(sign * stack[-1])
                sign = 1
            elif c == ')':
                stack.pop()
                sign = 1
            i += 1
        out.append(str(result))
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
1 + 1
2-(5-6)
(1+(4+5+2)-3)+(6+8)
== 範例 1 輸出 ==
2
3
23
