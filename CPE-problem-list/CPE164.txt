CPE 10370 Above Average

難度：簡單
來源：改編自 UVa Online Judge #10370 (CPE 大學程式能力檢定經典題)

== 題目 ==
給定一個班級 N 位學生的成績，計算「成績高於平均」的學生所佔的百分比。

輸入說明：第一行為測試個數 C；每組第一行為學生數 N (1<=N<=1000)，接著 N 個 0~100 的整數成績。
輸出說明：每組輸出百分比 (四捨五入到小數點後 3 位)，格式為 "xx.xxx%"。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    c = int(data[idx]); idx += 1
    out = []
    for _ in range(c):
        n = int(data[idx]); idx += 1
        grades = [int(data[idx + i]) for i in range(n)]
        idx += n
        avg = sum(grades) / n
        above = sum(1 for g in grades if g > avg)
        out.append(f"{above / n * 100:.3f}%")
    print('\n'.join(out))

main()

== 範例 1 輸入 ==
5
5 50 50 70 80 100
7 100 95 90 80 70 60 50
3 70 90 80
3 70 90 81
9 100 99 98 97 96 95 94 93 91
== 範例 1 輸出 ==
40.000%
57.143%
33.333%
66.667%
55.556%

== 範例 2 輸入 ==
1
2 10 20
== 範例 2 輸出 ==
50.000%
