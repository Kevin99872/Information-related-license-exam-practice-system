CPE 10891 Game of Sum

難度：困難
來源：改編自 UVa Online Judge #10891 (CPE 大學程式能力檢定經典題)

== 題目 ==
兩人輪流從一列 n 個整數的兩端取數 (每次可從左端或右端取走「一個以上」連續的數字，但不能同時取兩端)，直到全部取完。雙方都採取最佳策略、目標是讓「自己總分減對方總分」最大。求先手玩家 A 能贏對方多少分 (可能為負)。

輸入說明：每組第一行 n (0<n<=100)，第二行 n 個整數。n=0 表示輸入結束。
輸出說明：每組輸出 A 與 B 的最大分差。

== 參考解法 (Python) ==
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx]); idx += 1
        if n == 0:
            break
        a = [int(data[idx + i]) for i in range(n)]
        idx += n
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + a[i]
        dp = [[0] * n for _ in range(n)]
        for i in range(n):
            dp[i][i] = a[i]
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                best = -10 ** 18
                for k in range(1, length + 1):
                    left_take = prefix[i + k] - prefix[i]
                    rest = dp[i + k][j] if i + k <= j else 0
                    best = max(best, left_take - rest)
                    right_take = prefix[j + 1] - prefix[j - k + 1]
                    rest2 = dp[i][j - k] if j - k >= i else 0
                    best = max(best, right_take - rest2)
                dp[i][j] = best
        out.append(str(dp[0][n - 1]))
    print('\n'.join(out))

main()
